## Data Types

ข้อมูลมีหลายประเภท

### String (ข้อความ)

```python
name = "Tom"
```

### Integer (จำนวนเต็ม)

```python
age = 11
```

### Float (เลขทศนิยม)

```python
height = 145.5
```

### Boolean (จริง / เท็จ)

```python
is_student = True
```
