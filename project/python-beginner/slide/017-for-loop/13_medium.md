# 💰 for-loop — ข้อ 13: รวมเงินโบนัสเลขคู่

**Difficulty:** 🟡 Medium

---

## โจทย์

บริษัทจ่ายโบนัสเฉพาะรอบเลขคู่: รอบ 2 ได้ 2 บาท รอบ 4 ได้ 4 บาท …
จนถึงรอบ n (สมมติ n เป็นเลขคู่เสมอในชุดทดสอบ)

เขียนโปรแกรมรับ `n` แล้วหาผลรวมของเลขคู่ตั้งแต่ 2 ถึง n

---

## Input

จำนวนเต็ม n (เลขคู่) 1 บรรทัด

## Output

บรรทัดเดียว Bonus: <ผลรวม>

---

## ตัวอย่าง

**Input:**

```text
10
```

**Output:**

```text
Bonus: 30
```

---

## 💡 Hint

ใช้ range(2, n + 1, 2) แล้วสะสมผลรวม

---

## Starter Code

```python
n = int(input())

# เขียนโค้ดตรงนี้
```
