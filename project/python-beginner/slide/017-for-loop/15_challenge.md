# ✅ for-loop — ข้อ 15: แสตมป์เข้าเรียน n วัน

**Difficulty:** 🔴 Challenge

---

## โจทย์

ครูประจำชั้นแสตมป์คำว่า `Present` ให้ทุกวันที่มีเรียน
รับจำนวนวัน `n` แล้วพิมพ์รายงานการเข้าเรียนในกรอบ
แสดงบรรทัด `Day k : Present` สำหรับทุกวัน 1 ถึง n

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

กรอบรายงาน ตามตัวอย่าง

---

## ตัวอย่าง

**Input:**

```text
3
```

**Output:**

```text
========================
     ATTENDANCE
========================
Day 1 : Present
Day 2 : Present
Day 3 : Present
========================
```

---

## 💡 Hint

พิมพ์หัวกรอบก่อน แล้วค่อยวน for พิมพ์แต่ละวัน สุดท้ายปิดกรอบ

---

## Starter Code

```python
n = int(input())

# เขียนโค้ดตรงนี้
```
