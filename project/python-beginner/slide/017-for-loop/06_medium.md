# ➕ for-loop — ข้อ 6: รวมแต้มสะสม 1 ถึง n

**Difficulty:** 🟡 Medium

---

## โจทย์

เกมสะสมแต้มให้คะแนนตามรอบ: รอบที่ 1 ได้ 1 แต้ม รอบที่ 2 ได้ 2 แต้ม …
จนถึงรอบที่ n ได้ n แต้ม

เขียนโปรแกรมรับ `n` แล้วหาผลรวมแต้มทั้งหมด (1+2+…+n)

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

บรรทัดเดียว แสดงผลรวมในรูปแบบ Total: <ค่า>

---

## ตัวอย่าง

**Input:**

```text
5
```

**Output:**

```text
Total: 15
```

---

## 💡 Hint

สร้างตัวแปร total = 0 ก่อนเข้า loop แล้วบวกค่า i เข้าไปทีละรอบ

---

## Starter Code

```python
n = int(input())

# เขียนโค้ดตรงนี้
```
