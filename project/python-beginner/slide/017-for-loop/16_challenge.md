# 🌡️ for-loop — ข้อ 16: นับวันที่อากาศร้อน

**Difficulty:** 🔴 Challenge

---

## โจทย์

สถานีอากาศบันทึกอุณหภูมิรายวันเป็นจำนวนเต็ม
วันที่อุณหภูมิ `>= 30` นับเป็นวันร้อน

รับจำนวนวัน `n` แล้วรับอุณหภูมิตามมาอีก n บรรทัด
นับว่ามีวันร้อนกี่วัน แล้วแสดงผล

**เงื่อนไข:**

- อุณหภูมิ `>= 30` → นับเป็นวันร้อน

---

## Input

บรรทัดแรกคือ n ตามด้วยอุณหภูมิ n บรรทัด

## Output

บรรทัดเดียว Hot Days: <จำนวน>

---

## ตัวอย่าง

**Input:**

```text
5
28
31
30
25
35
```

**Output:**

```text
Hot Days: 3
```

---

## 💡 Hint

วน for ตามจำนวนวัน ในแต่ละรอบรับอุณหภูมิใหม่ด้วย int(input()) แล้วค่อยตัดสินใจนับ

---

## Starter Code

```python
n = int(input())

# เขียนโค้ดตรงนี้
```
