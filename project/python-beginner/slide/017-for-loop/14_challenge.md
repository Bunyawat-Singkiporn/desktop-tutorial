# 📊 for-loop — ข้อ 14: สรุปเลขคี่ในช่วง 1 ถึง n

**Difficulty:** 🔴 Challenge

---

## โจทย์

แผนกสถิติอยากได้รายงานเลขคี่ในช่วง 1 ถึง n
ต้องนับว่ามีเลขคี่กี่ตัว และผลรวมของเลขคี่เหล่านั้นเท่าไร

เขียนโปรแกรมรับ `n` แล้วออกใบสรุปในกรอบ

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

ใบสรุปในกรอบ แสดง Count และ Sum

---

## ตัวอย่าง

**Input:**

```text
10
```

**Output:**

```text
========================
      ODD REPORT
========================
Count : 5
Sum   : 25
========================
```

---

## 💡 Hint

ใช้ตัวแปรสองตัว (count กับ total) ใน loop เดียว ตรวจด้วย if i % 2 != 0

---

```python
n = int(input())
```
