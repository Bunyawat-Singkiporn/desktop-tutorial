# 📦 for-loop — ข้อ 10: นับกล่องที่หาร 4 ลงตัว

**Difficulty:** 🟡 Medium

---

## โจทย์

โกดังติดป้ายหมายเลขกล่อง 1 ถึง n
กล่องที่หมายเลขหารด้วย 4 ลงตัวจะถูกส่งไปแผนกพิเศษ

เขียนโปรแกรมรับ `n` แล้วนับว่ามีกล่องพิเศษกี่ใบ ในช่วง 1 ถึง n

**เงื่อนไข:**

- ถ้าหมายเลข `i` หารด้วย 4 ลงตัว (`i % 4 == 0`) → นับเพิ่ม 1

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

บรรทัดเดียว Special Boxes: <จำนวน>

---

## ตัวอย่าง

**Input:**

```text
20
```

**Output:**

```text
Special Boxes: 5
```

---

## 💡 Hint

ใช้ตัวแปรนับ count = 0 แล้ววน for ตรวจด้วย if ทีละหมายเลข

---

## Starter Code

```python
n = int(input())

# เขียนโค้ดตรงนี้
```
