# 🧩 for-loop — ข้อ 5: หาตัวประกอบของ n

**Difficulty:** 🔴 Challenge

---

## โจทย์

ครูคณิตให้นักเรียนหาตัวประกอบของจำนวนเต็ม n
ตัวประกอบคือเลข i ที่อยู่ระหว่าง 1 ถึง n และ n หารด้วย i ลงตัว

เขียนโปรแกรมรับ `n` แล้วพิมพ์ตัวประกอบทั้งหมดทีละบรรทัด จากน้อยไปมาก

**เงื่อนไข:**

- ถ้า `n % i == 0` → พิมพ์ i

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

ตัวประกอบทีละบรรทัด

---

## ตัวอย่าง

**Input:**

```text
12
```

**Output:**

```text
1
2
3
4
6
12
```

---

## 💡 Hint

วน i จาก 1 ถึง n แล้วใช้ if ตรวจว่าหารลงตัวหรือไม่ก่อนพิมพ์

---

## Starter Code

```python
n = int(input())

# เขียนโค้ดตรงนี้
```
