# 📐 range() — กำหนดช่วงตัวเลข

---

## รูปแบบ

```
range(start, stop)
range(start, stop, step)
```

| พารามิเตอร์ | ความหมาย |
|------------|----------|
| `start` | เริ่มต้นที่ตัวเลขนี้ |
| `stop` | หยุด **ก่อน** ถึงตัวเลขนี้ |
| `step` | กระโดดทีละเท่าไหร่ (ค่าเริ่มต้น = 1) |

---

## ตัวอย่าง — กำหนด start และ stop

```python
for i in range(1, 6):
    print(i)
```

**ผลลัพธ์:**
```
1
2
3
4
5
```

> เริ่มที่ 1 หยุดก่อน 6

---

## ตัวอย่าง — กำหนด step

```python
for i in range(2, 11, 2):
    print(i)
```

**ผลลัพธ์:**
```
2
4
6
8
10
```

> เริ่มที่ 2 หยุดก่อน 11 กระโดดทีละ 2

---

## เปรียบเทียบ

| range | ผลลัพธ์ |
|-------|---------|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(2, 11, 2)` | 2, 4, 6, 8, 10 |
