# 🚪 for-loop — ข้อ 12: หมายเลขห้องระหว่างสองชั้น

**Difficulty:** 🟡 Medium

---

## โจทย์

อาคารมีหมายเลขห้องต่อเนื่อง รับเลขห้องเริ่มต้นและเลขห้องสุดท้าย (ไม่รวมห้องสุดท้าย)
แล้วพิมพ์หมายเลขห้องในช่วงนั้นทีละบรรทัด

เช่น เริ่ม 3 สิ้นสุด 7 → พิมพ์ 3 4 5 6 (ไม่พิมพ์ 7)

---

## Input

2 บรรทัด — เลขเริ่ม และเลขสิ้นสุด (stop แบบ range คือไม่รวม)

## Output

หมายเลขห้องทีละบรรทัด

---

## ตัวอย่าง

**Input:**

```text
3
7
```

**Output:**

```text
3
4
5
6
```

---

## 💡 Hint

ใช้ range(start, stop) โดย stop คือค่าที่รับมาบรรทัดที่สอง

---

## Starter Code

```python
start = int(input())
stop = int(input())

# เขียนโค้ดตรงนี้
```
