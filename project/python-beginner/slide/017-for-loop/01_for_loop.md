# 🔁 for Loop — การวนซ้ำ

---

## Loop คืออะไร?

Loop คือการให้คอมพิวเตอร์ **ทำงานซ้ำ** โดยไม่ต้องเขียนโค้ดซ้ำหลาย ๆ ครั้ง

**แทนที่จะเขียนแบบนี้...**

```python
print("Hello")
print("Hello")
print("Hello")
print("Hello")
print("Hello")
```

**เราเขียนแบบนี้แทนได้!**

```python
for i in range(5):
    print("Hello")
```

---

## `range(5)` คืออะไร?

`range(5)` สร้างตัวเลข **0 ถึง 4** รวม 5 รอบ

> ⚠️ เริ่มที่ **0** เสมอ และหยุดก่อนถึงตัวเลขที่กำหนด

```python
for i in range(5):
    print(i)
```

**ผลลัพธ์:**
```
0
1
2
3
4
```

---

## สรุป

| โค้ด | ความหมาย |
|------|----------|
| `for i in range(5):` | วน 5 รอบ (i = 0, 1, 2, 3, 4) |
| `    print(i)` | พิมพ์ค่า i ในแต่ละรอบ |
