# 💻 Programming คืออะไร?

---

## ลองนึกภาพนี้...

สมมติคุณมี **หุ่นยนต์** เป็นเพื่อน 🤖

หุ่นยนต์จะทำตามที่คุณสั่งทุกอย่าง แต่มันไม่เข้าใจภาษาไทย!

> คุณต้องพูดกับมันเป็น **ภาษาพิเศษ** ที่มันเข้าใจ
> ภาษาพิเศษนั้นคือ... **ภาษาโปรแกรม** 🎯

---

## Programming คืออะไร?

**Programming** คือการเขียนคำสั่งให้คอมพิวเตอร์ทำงาน

เหมือนการเขียน **สูตรอาหาร** 🍳 ให้คนทำตาม:

| สูตรอาหาร (ชีวิตจริง) | โปรแกรม (คอมพิวเตอร์) |
|----------------------|----------------------|
| "เปิดเตาไฟ" | เริ่มโปรแกรม |
| "เอาไข่ใส่กระทะ" | รับข้อมูล |
| "รอ 3 นาที" | ประมวลผล |
| "เสิร์ฟในจาน" | แสดงผลลัพธ์ |

---

## Python คืออะไร?

**Python** คือภาษาโปรแกรมภาษาหนึ่ง

มีภาษาโปรแกรมหลายภาษา เหมือนภาษาคน:

| ภาษาคน | ภาษาโปรแกรม |
|--------|------------|
| ภาษาไทย | Python |
| ภาษาอังกฤษ | JavaScript |
| ภาษาญี่ปุ่น | Java |

> Python เป็นภาษาที่ **อ่านง่าย เรียนง่าย** เหมาะมากสำหรับผู้เริ่มต้น!

## คำสั่งแรกของคุณ — `print()`

`print()` คือคำสั่งให้คอมพิวเตอร์ **แสดงข้อความบนหน้าจอ**

```python
print("Hello, World!")
```

ผลลัพธ์:
```
Hello, World!
```

> ข้อความต้องอยู่ในเครื่องหมาย `"..."` เสมอ

---

## ตัวอย่าง: print() หลายครั้ง

```python
print("สวัสดี!")
print("ฉันชื่อ Python")
print("ยินดีที่ได้รู้จัก")
```

ผลลัพธ์:
```
สวัสดี!
ฉันชื่อ Python
ยินดีที่ได้รู้จัก
```

> แต่ละ `print()` ขึ้นบรรทัดใหม่อัตโนมัติ
