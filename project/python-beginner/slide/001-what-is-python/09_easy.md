# 📃 รู้จัก Python — ข้อ 5: เว้นบรรทัดให้อ่านง่าย

**Difficulty:** 🟢 Easy

---

## โจทย์

ป้ายประกาศที่มีข้อความติดกันพรืดอ่านยาก ควรเว้นบรรทัดคั่นระหว่างหัวข้อ

`print()` ที่ไม่ใส่อะไรข้างในเลย จะพิมพ์ **บรรทัดว่าง** 1 บรรทัด

เขียนโปรแกรมแสดงประกาศ 2 ท่อน โดยคั่นกลางด้วยบรรทัดว่าง 1 บรรทัด

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ประกาศ 2 ท่อน มีบรรทัดว่างคั่นกลาง รวม 5 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
LIBRARY NOTICE
Open 08:00 - 17:00

BOOK RETURN
Return books within 7 days
```

## 💡 Hint
