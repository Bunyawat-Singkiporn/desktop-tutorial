# 🏧 รู้จัก Python — ข้อ 15: หน้าจอตู้ ATM 3 หน้า

**Difficulty:** 🔴 Challenge

---

## โจทย์

ทีมออกแบบตู้ ATM อยากเห็นหน้าจอทั้ง 3 หน้าเรียงต่อกันในหน้าเดียว เพื่อดูภาพรวม

เขียนโปรแกรมแสดงหน้าจอทั้ง 3 หน้า โดยคั่นระหว่างหน้าด้วยบรรทัดว่าง 1 บรรทัด

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

หน้าจอ 3 หน้า แต่ละหน้ามีกรอบของตัวเอง คั่นด้วยบรรทัดว่าง

---

## ตัวอย่าง

**Output:**

```text
[ SCREEN 1 ]
+--------------------+
|  INSERT YOUR CARD  |
+--------------------+

[ SCREEN 2 ]
+--------------------+
|  ENTER PIN         |
|  * * * *           |
+--------------------+

[ SCREEN 3 ]
+--------------------+
|  SELECT SERVICE    |
|  1. Withdraw       |
|  2. Balance        |
+--------------------+
```
