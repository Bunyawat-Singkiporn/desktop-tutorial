# 🎫 รู้จัก Python — ข้อ 9: บัตรคิวโรงพยาบาล

**Difficulty:** 🟡 Medium

---

## โจทย์

โรงพยาบาลอยากได้หน้าตาบัตรคิวที่มีกรอบล้อมรอบทั้งสี่ด้าน

เขียนโปรแกรมแสดงบัตรคิวตามตัวอย่าง สังเกตว่าทุกบรรทัดต้องมี `|` ปิดหัวท้าย และความกว้างเท่ากันหมด

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

บัตรคิวที่มีกรอบครบสี่ด้าน

---

## ตัวอย่าง

**Output:**

```text
+----------------------+
|     QUEUE TICKET     |
+----------------------+
|  Number : A045       |
|  Room   : 3          |
|  Floor  : 2          |
+----------------------+
```

---

## 💡 Hint

ความยากอยู่ที่ทำให้ `|` ด้านขวาตรงกันทุกบรรทัด
ลองเขียนบรรทัดบนสุดก่อน แล้วนับความกว้างจากบรรทัดนั้น
