## โจทย์

เกมหนึ่งอยากได้หน้าเมนูเริ่มเกมที่ดูเท่ๆ มีกรอบสองชั้น

เขียนโปรแกรมแสดงหน้าเมนูตามตัวอย่าง ข้อความ `SPACE ADVENTURE` ต้องอยู่กึ่งกลางกรอบพอดี

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

หน้าเมนูที่มีกรอบสองชั้นและรายการเมนู 3 ข้อ

---

## ตัวอย่าง

**Output:**

```text
############################
#                          #
#     SPACE ADVENTURE      #
#                          #
############################
#   1. New Game            #
#   2. Continue            #
#   3. Exit                #
############################
Press a number to select
```
