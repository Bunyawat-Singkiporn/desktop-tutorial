# ☕ รู้จัก Python — ข้อ 6: เมนูร้านกาแฟ

**Difficulty:** 🟡 Medium

---

## โจทย์

ร้านกาแฟอยากได้ป้ายเมนูที่ราคาเรียงตรงกันเป็นคอลัมน์เดียว อ่านง่าย

เขียนโปรแกรมแสดงเมนู โดยมีเส้นคั่นบน-ล่าง และชื่อเครื่องดื่มกับราคาต้องเรียงตรงกันทุกบรรทัด

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

เมนูในกรอบเส้นคั่น ชื่อเครื่องดื่มและราคาอยู่ตรงคอลัมน์เดียวกัน

---

## ตัวอย่าง

**Output:**

```text
========================
      COFFEE MENU
========================
Espresso        45
Latte           55
Cappuccino      55
Mocha           65
========================
```
