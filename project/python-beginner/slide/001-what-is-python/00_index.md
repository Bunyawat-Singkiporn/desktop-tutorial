## หมายเหตุสำหรับครู

- ข้อ 02 **ไม่ซ้ำ** ตัวอย่างในบทเรียน (บทเรียนใช้ `print("Hello, World!")` และคำทักทายภาษาไทย 3 บรรทัด)
- ทั้งบทใช้แค่ `print` กับข้อความ — ความยากไล่ระดับจาก **จำนวนบรรทัด → การจัดคอลัมน์ → การทำกรอบ → การจัดกึ่งกลาง**
- ข้อ 09 เป็นข้อแรกที่เจอ `print()` เปล่าเพื่อเว้นบรรทัด ใช้ต่อในข้อ 13 และ 16
- ข้อ Challenge ทั้ง 4 ข้อไม่ได้ใช้คำสั่งใหม่เลย ยากตรง **ความละเอียดในการนับช่องว่าง**
  ซึ่งเป็นทักษะที่จำเป็นมากตอนขึ้นบท f-string และการจัดรายงาน
- เด็กมักพลาดเรื่องลืมปิดเครื่องหมายคำพูด/วงเล็บ ให้ใช้โอกาสนี้ฝึกอ่าน SyntaxError ก่อนเข้าบท 002
