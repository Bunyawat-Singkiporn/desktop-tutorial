# 🏅 รู้จัก Python — ข้อ 14: เกียรติบัตร

**Difficulty:** 🔴 Challenge

---

## โจทย์

โรงเรียนอยากได้แบบร่างเกียรติบัตรแบบข้อความ ไว้พิมพ์แจกในค่ายคอมพิวเตอร์

เขียนโปรแกรมแสดงเกียรติบัตรตามตัวอย่าง มีกรอบล้อมรอบ และข้อความจัดกึ่งกลางหลายบรรทัด

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

เกียรติบัตรในกรอบ ความกว้างเท่ากันทุกบรรทัด

---

## ตัวอย่าง

**Output:**

```text
*========================================*
|                                        |
|            CERTIFICATE                 |
|          OF ACHIEVEMENT                |
|                                        |
|         This is given to               |
|                                        |
|            MINT SUKSAN                 |
|                                        |
|      Python Beginner Camp 2026         |
|                                        |
*========================================*
```

---

## 💡 Hint

บรรทัดว่างในกรอบไม่ใช่ `print()` เปล่า แต่เป็น `|` เว้นช่องว่างแล้วปิดด้วย `|`
ทำบรรทัดว่างในกรอบให้ถูกก่อน แล้วค่อยเติมข้อความลงไป
