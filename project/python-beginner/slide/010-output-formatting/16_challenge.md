# 🖨️ Output Formatting — ข้อ 16: สลิปชำระเงิน

**Difficulty:** 🔴 Challenge

---

## โจทย์

รับชื่อและยอด float แสดงสลิปตามตัวอย่าง

---

## Input

ดูตัวอย่าง

## Output

สลิป

---

## ตัวอย่าง

**Input:**

```text
Rin
120
```

**Output:**

```text
==== PAYMENT ====
Payer : Rin
Amount: 120.00
==================
```


---

## 💡 Hint

Amount ใช้ :.2f

---

name = input()
amount = float(input())
