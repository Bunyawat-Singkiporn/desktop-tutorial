# 🔄 Type Conversion — ข้อ 9: อายุและส่วนสูง

**Difficulty:** 🟡 Medium

---

## โจทย์

คลินิกสุขภาพบันทึกอายุและส่วนสูง
รับทั้งสองค่า แล้วแสดงเป็นสองบรรทัดข้อความ

---

## Input

2 บรรทัด — อายุ (จำนวนเต็ม) และส่วนสูงเมตร (ทศนิยม)

## Output

2 บรรทัด แสดงอายุและส่วนสูง

---

## ตัวอย่าง

**Input:**

```text
14
1.62
```

**Output:**

```text
Age: 14
Height: 1.62 m
```

---

## 💡 Hint

อายุใช้ `int(input())` ส่วนสูงใช้ `float(input())` แล้วพิมพ์ทีละบรรทัด

---

## Starter Code

```python
age = int(input())
height = float(input())

# เขียนโค้ดตรงนี้
```
