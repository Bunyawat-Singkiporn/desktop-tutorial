# 🔄 Type Conversion — ข้อ 5: คะแนนสอบ + โบนัส

**Difficulty:** 🟢 Easy

---

## โจทย์

ครูให้คะแนนสอบและคะแนนโบนัสแยกกัน
รับทั้งสองค่า แล้วแสดงคะแนนรวมด้วยการต่อข้อความ

---

## Input

2 บรรทัด — คะแนนสอบ และคะแนนโบนัส (จำนวนเต็ม)

## Output

ข้อความคะแนนรวม 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
72
8
```

**Output:**

```text
Total score: 80
```
