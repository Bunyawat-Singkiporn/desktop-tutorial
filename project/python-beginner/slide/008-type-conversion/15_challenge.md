# 🔄 Type Conversion — ข้อ 14: คะแนนสามวิชา

**Difficulty:** 🔴 Challenge

---

## โจทย์

นักเรียนสอบสามวิชา
รับคะแนนคณิต วิทย์ และอังกฤษ แล้วออกใบสรุปคะแนนรวมในกรอบ

---

## Input

3 บรรทัด — คะแนนคณิต วิทย์ อังกฤษ (จำนวนเต็ม)

## Output

ใบสรุปคะแนนในกรอบ

---

## ตัวอย่าง

**Input:**

```text
80
75
90
```

**Output:**

```text
========================
       SUBJECTS
========================
Math    : 80
Science : 75
English : 90
Total   : 245
========================
```

---

## 💡 Hint

รวมสามวิชาเก็บในตัวแปรก่อน แล้วพิมพ์กรอบให้ป้ายกำกับตรงกัน

---

## Starter Code

```python
math = int(input())
science = int(input())
english = int(input())

# เขียนโค้ดตรงนี้
```
