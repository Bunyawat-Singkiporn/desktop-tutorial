# 🔄 Type Conversion — ข้อ 7: ข้อความคะแนนจากตัวเลข

**Difficulty:** 🟡 Medium

---

## โจทย์

แอปแบบฝึกหัดต้องสร้างประโยคบอกคะแนน
รับคะแนนเป็นจำนวนเต็ม แล้วต่อเป็นข้อความเต็มประโยคด้วย `str()`

---

## Input

คะแนนเป็นจำนวนเต็ม 1 บรรทัด

## Output

ประโยคบอกคะแนน 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
88
```

**Output:**

```text
You scored 88 points.
```

---

## 💡 Hint

ต้องใช้ `str(score)` ก่อนเอามาต่อกับข้อความซ้ายและขวา

---

## Starter Code

```python
score = int(input())

# เขียนโค้ดตรงนี้
```
