# 🔄 Type Conversion — ข้อ 15: สลิปเติมเงิน

**Difficulty:** 🔴 Challenge

---

## โจทย์

ตู้เติมเงินมือถือพิมพ์สลิปหลังเติมสำเร็จ
รับเบอร์โทร (ข้อความ) จำนวนเงิน (จำนวนเต็ม) และค่าธรรมเนียม (ทศนิยม)
แสดงสลิปในกรอบ โดยยอดที่ตัดจริงคือเงินเติมบวกค่าธรรมเนียม

---

## Input

3 บรรทัด — เบอร์โทร จำนวนเงิน ค่าธรรมเนียม

## Output

สลิปในกรอบ

---

## ตัวอย่าง

**Input:**

```text
0812345678
100
5.0
```

**Output:**

```text
========================
        TOPUP
========================
Phone  : 0812345678
Amount : 100
Fee    : 5.0
Charged: 105.0
========================
```

---

## 💡 Hint

ยอดที่ตัดจริง = จำนวนเงิน + ค่าธรรมเนียม — แปลงชนิดให้ถูกก่อนบวก

---
