# 🔄 Type Conversion — ข้อ 11: คะแนนจากข้อความ

**Difficulty:** 🟡 Medium

---

## โจทย์

ระบบเก่าเก็บคะแนนเป็นข้อความ
รับคะแนนแบบข้อความ แปลงเป็นจำนวนเต็ม แล้วบวกโบนัส 5 คะแนน
แสดงทั้งคะแนนเดิมและคะแนนใหม่ในกล่อง

---

## Input

คะแนนเป็นข้อความตัวเลข 1 บรรทัด

## Output

ใบสรุปคะแนนในกรอบ

---

## ตัวอย่าง

**Input:**

```text
70
```

**Output:**

```text
========================
        SCORE
========================
Original : 70
Bonus    : 5
Final    : 75
========================
```

---

## 💡 Hint

ใช้ `int(...)` แปลงข้อความเป็นตัวเลขก่อนบวกโบนัส อย่าบวกตอนยังเป็น str

---

## Starter Code

```python
score_text = input()

# เขียนโค้ดตรงนี้
```
