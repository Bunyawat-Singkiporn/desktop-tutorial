# 🔄 Type Conversion — ข้อ 8: ใบเสร็จสองรายการ

**Difficulty:** 🟡 Medium

---

## โจทย์

ร้านเครื่องเขียนคิดเงินสองชิ้น
รับราคาทั้งสอง แล้วแสดงยอดรวมด้วยข้อความต่อกัน

---

## Input

2 บรรทัด — ราคาชิ้นที่ 1 และชิ้นที่ 2 (ทศนิยม)

## Output

ข้อความยอดรวม 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
45.5
30.0
```

**Output:**

```text
Bill total: 75.5
```

---

## 💡 Hint

บวกราคาก่อน แล้วค่อยใช้ `str()` ต่อเข้ากับข้อความหน้าป้าย

---

## Starter Code

```python
item1 = float(input())
item2 = float(input())

# เขียนโค้ดตรงนี้
```
