# 🔄 Type Conversion — ข้อ 2: ป้ายราคากาแฟ

**Difficulty:** 🟢 Easy

---

## โจทย์

บาริสต้าต้องติดป้ายราคาแก้วกาแฟ
รับราคาเป็นทศนิยม แล้วสร้างข้อความป้ายด้วยการต่อ string

---

## Input

ราคาเป็นทศนิยม 1 บรรทัด

## Output

ข้อความป้ายราคา 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
65.5
```

**Output:**

```text
Coffee price: 65.5
```

price = float(input())
