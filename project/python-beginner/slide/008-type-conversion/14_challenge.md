# 🔄 Type Conversion — ข้อ 13: บัตรเข้าชมพิพิธภัณฑ์

**Difficulty:** 🔴 Challenge

---

## โจทย์

พิพิธภัณฑ์พิมพ์บัตรเข้าชมจากชื่อและอายุ
รับชื่อ (ข้อความ) และอายุ (จำนวนเต็ม)
สร้างข้อความบัตรด้วยการต่อ string และแสดงชนิดของอายุหลังแปลงแล้ว

---

## Input

2 บรรทัด — ชื่อ และอายุ

## Output

ข้อความบัตร 2 บรรทัด และชนิดของอายุ 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
Mina
11
```

**Output:**

```text
Visitor: Mina
Age: 11
Age type: <class 'int'>
```

---

## 💡 Hint

อายุต้องผ่าน `int(input())` ก่อน — แล้วค่อยพิมพ์ค่าและ `type()` ของมัน

---

## Starter Code

```python
name = input()
age = int(input())

# เขียนโค้ดตรงนี้
```
