# 🔄 Type Conversion — ข้อ 3: น้ำหนักกระเป๋า

**Difficulty:** 🟢 Easy

---

## โจทย์

เคาน์เตอร์สนามบินชั่งน้ำหนักกระเป๋าเดินทาง
รับน้ำหนักเป็นทศนิยม แล้วแสดงผลพร้อมป้ายกำกับ

---

## Input

น้ำหนักเป็นทศนิยม 1 บรรทัด

## Output

ข้อความน้ำหนัก 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
12.8
```

**Output:**

```text
Bag weight: 12.8 kg
```

---

```python
weight = float(input())
```
