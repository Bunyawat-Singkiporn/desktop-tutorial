# 🔄 Practice: Type Conversion — Question 1: Number to Next Year

**Difficulty:** 🟢 Easy

---

## โจทย์

รับอายุจากผู้ใช้ แล้วแสดงอายุปีหน้า

**Input:**
```
15
```

**Output:**
```
Next year: 16
```

---

## 💡 Hint

- `input()` ให้ค่าเป็น string เสมอ
- ใช้ `int()` แปลงก่อนบวก 1

---

## Starter Code

```python
age = input()      # รับค่า — ยังเป็น string!

# แปลงเป็น int แล้วบวก 1
```
