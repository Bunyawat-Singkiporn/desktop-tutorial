# 🔄 Type Conversion — ข้อ 1: ชั้นจอดรถถัดไป

**Difficulty:** 🟢 Easy

---

## โจทย์

ตึกจอดรถมีลิฟต์บอกชั้นปัจจุบัน
ให้รับชั้นปัจจุบัน แล้วบอกชั้นถัดไปที่ลิฟต์จะไป

---

## Input

ชั้นปัจจุบันเป็นจำนวนเต็ม 1 บรรทัด

## Output

ข้อความบอกชั้นถัดไป 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
3
```

**Output:**

```text
Next floor: 4
```
