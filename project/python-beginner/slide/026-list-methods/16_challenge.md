# 🛠️ List Methods — ข้อ 16: กระดานคะแนนเกม

**Difficulty:** 🔴 Challenge

---

## โจทย์

เกมต้องการอัปเดตกระดานคะแนน

กำหนด `scores = [120, 80, 95]`

เพิ่ม `150` ลบ `80` แก้ตำแหน่ง 0 เป็น `130` แล้วเรียงมากไปน้อย
แสดง list และคะแนนสูงสุด (ค่าแรกหลังเรียง)

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
[150, 130, 95]
Top: 150
```
