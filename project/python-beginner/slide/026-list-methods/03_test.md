# 🛠️ List Methods — ข้อ 3: แก้ชื่อเมนูผิด

**Difficulty:** 🟢 Easy

---

## โจทย์

เมนูพิมพ์ผิดที่ตำแหน่งกลาง

กำหนด `menu = ["Soup", "Salad", "Cake"]`

แก้ค่าตำแหน่ง index 1 เป็น `Steak` แล้วแสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Soup', 'Steak', 'Cake']
```


---

## Starter Code

```python
menu = ["Soup", "Salad", "Cake"]

# เขียนโค้ดตรงนี้

print(menu)
```
