# ❌ Practice List Methods — Question 2: Remove Item

**Difficulty:** 🟢 Easy

---

## โจทย์

กำหนดรายการผลไม้ ลบ `"banana"` ออกแล้วแสดงผล

```python
fruits = ["apple", "banana", "mango", "orange"]
```

**Output:**
```
['apple', 'mango', 'orange']
```

---

## 💡 Hint

ใช้ `.remove("banana")`

---

## Starter Code

```python
fruits = ["apple", "banana", "mango", "orange"]

# ลบ banana ออก

print(fruits)
```
