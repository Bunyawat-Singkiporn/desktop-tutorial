# 🛠️ List Methods — ข้อ 8: เรียงราคาน้อยไปมาก

**Difficulty:** 🟢 Easy

---

## โจทย์

ร้านอยากเรียงราคาสินค้าจากน้อยไปมาก

กำหนด `prices = [45, 12, 80, 30]`

เรียงด้วย `.sort()` แล้วแสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
[12, 30, 45, 80]
```


---

## Starter Code

```python
prices = [45, 12, 80, 30]

# เขียนโค้ดตรงนี้

print(prices)
```
