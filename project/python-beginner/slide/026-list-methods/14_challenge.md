# 🛠️ List Methods — ข้อ 14: จัดชั้นวางสินค้า

**Difficulty:** 🔴 Challenge

---

## โจทย์

พนักงานจัดชั้นวางสินค้า

กำหนด `shelf = ["Soap", "Shampoo", "Cream"]`

แก้ตำแหน่ง 0 เป็น `Lotion` เพิ่ม `Toner` ลบ `Cream` แล้วเรียงชื่อ และแสดง list

---

## ตัวอย่าง

**Output:**

```text
['Lotion', 'Shampoo', 'Toner']
```


---

## 💡 Hint

ทำทีละขั้นตามลำดับที่โจทย์บอก

---

```python
shelf = ["Soap", "Shampoo", "Cream"]

# เขียนโค้ดตรงนี้
```
