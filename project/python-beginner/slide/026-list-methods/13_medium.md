# 🛠️ List Methods — ข้อ 13: ลบสองรายการแล้วเรียง

**Difficulty:** 🟡 Medium

---

## โจทย์

คลังลบสินค้าเสียสองชิ้นแล้วเรียงชื่อที่เหลือ

กำหนด `items = ["Apple", "Banana", "Mango", "Durian", "Grape"]`

ลบ `Banana` และ `Durian` แล้ว `.sort()` และแสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Apple', 'Grape', 'Mango']
```


---

## 💡 Hint

remove ได้ทีละค่า เรียกสองครั้ง

---

## Starter Code

```python
items = ["Apple", "Banana", "Mango", "Durian", "Grape"]

# เขียนโค้ดตรงนี้

print(items)
```
