# ➕ Practice List Methods — Question 1: Build a List

**Difficulty:** 🟢 Easy

---

## โจทย์

เริ่มด้วย list ว่าง แล้วเพิ่มชื่อ 3 คนด้วย `.append()` แสดงผล list สุดท้าย

**Output:**
```
['Alice', 'Bob', 'Charlie']
```

---

## 💡 Hint

เรียก `.append()` 3 ครั้ง แต่ละครั้งใส่ชื่อหนึ่งคน

---

## Starter Code

```python
names = []

# เพิ่มชื่อ 3 คน

print(names)
```
