# 🛠️ List Methods — ข้อ 15: คิวหน้าร้านกาแฟ

**Difficulty:** 🔴 Challenge

---

## โจทย์

คิวยากลบคนที่ยกเลิกและเพิ่มคนใหม่

กำหนด `queue = ["Ann", "Ben", "Cara"]`

ลบ `Ben` เพิ่ม `Dan` แล้วแสดง list และจำนวนคนตามตัวอย่าง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Ann', 'Cara', 'Dan']
Waiting: 3
```
