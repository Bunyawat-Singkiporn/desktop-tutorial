# 🛠️ List Methods — ข้อ 7: แก้แล้วเรียงเมนู

**Difficulty:** 🟡 Medium

---

## โจทย์

ร้านกาแฟแก้ชื่อเครื่องดื่มแล้วอยากเรียงชื่อ

กำหนด `drinks = ["Mocha", "Latte", "Tea"]`

แก้ค่าตำแหน่ง 2 เป็น `Americano` แล้ว `.sort()` และแสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Americano', 'Latte', 'Mocha']
```


---

## 💡 Hint

แก้ค่าก่อน แล้วค่อย sort

---

## Starter Code

```python
drinks = ["Mocha", "Latte", "Tea"]

# เขียนโค้ดตรงนี้

print(drinks)
```
