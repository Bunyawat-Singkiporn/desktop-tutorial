# 🛠️ List Methods — ข้อ 12: แก้ราคาแล้วเรียง

**Difficulty:** 🟡 Medium

---

## โจทย์

ป้ายราคาพิมพ์ผิดที่ชิ้นแรก

กำหนด `prices = [99, 45, 120, 30]`

แก้ราคาตำแหน่ง 0 เป็น `50` แล้วเรียงน้อยไปมาก และแสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
[30, 45, 50, 120]
```


---

index assign ก่อน sort
