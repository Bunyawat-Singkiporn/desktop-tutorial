# 🛠️ List Methods — ข้อ 5: จัดการคะแนนสอบ

**Difficulty:** 🔴 Challenge

---

## โจทย์

ครูจัดการคะแนนสอบชุดหนึ่ง

กำหนด `scores = [72, 55, 90]`

เพิ่ม `88` ด้วย append ลบ `55` ด้วย remove แล้วเรียงมากไปน้อย และแสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
[90, 88, 72]
```


---

## 💡 Hint

ลำดับ: append → remove → sort

---

## Starter Code

```python
scores = [72, 55, 90]

# เขียนโค้ดตรงนี้

print(scores)
```
