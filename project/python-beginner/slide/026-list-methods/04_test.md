# 🛠️ List Methods — ข้อ 4: เอาของหมดสต็อกออก

**Difficulty:** 🟢 Easy

---

## โจทย์

คลังต้องเอาสินค้าหมดสต็อกออกจากรายการ

กำหนด `stock = ["Rice", "Oil", "Soap", "Milk"]`

ลบ `Oil` ออกด้วย `.remove()` แล้วแสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Rice', 'Soap', 'Milk']
```


---

## Starter Code

```python
stock = ["Rice", "Oil", "Soap", "Milk"]

# เขียนโค้ดตรงนี้

print(stock)
```
