# 🥇 Practice List Methods — Question 3: Top Score

**Difficulty:** 🟡 Medium

---

## โจทย์

กำหนดคะแนน เรียงจากมากไปน้อย แล้วแสดงคะแนนสูงสุด

```python
scores = [72, 95, 60, 88, 45, 83]
```

**Output:**
```
Top score: 95
```

---

## 💡 Hint

- `.sort(reverse=True)` จะเรียงจากมากไปน้อย
- หลังเรียงแล้ว `scores[0]` คือค่ามากที่สุด
