# 🧩 Function Practice — ข้อ 24: เป้าหมายออมเงินรายสัปดาห์

**Difficulty:** 🔴 Challenge

---

## โจทย์

นักเรียนตั้งเป้าออมเงิน และจดยอดออมทุกสัปดาห์
อยากรู้ว่ายอดรวมเท่าไร ยังขาดอีกเท่าไร และถึงเป้าหรือยัง

รับเป้าหมาย แล้วรับยอดออม 3 สัปดาห์
สะสมด้วยฟังก์ชัน และสรุปผลด้วยฟังก์ชันอีกตัว

**เงื่อนไข:**

- `add_saving(saved, amount)` คืนยอดใหม่หลังบวก `amount`
- `report(saved, goal)` พิมพ์ 3 บรรทัด:
  - `Saved: <ยอดรวม>`
  - `Need: <ที่ยังขาด>` (ถ้าเกินเป้าแล้วให้เป็น 0)
  - `Done` ถ้ายอดถึงหรือเกินเป้า ไม่งั้น `Keep going`

---

## Input

4 บรรทัด — เป้าหมาย และยอดออมสัปดาห์ที่ 1–3

## Output

3 บรรทัด ตามรูปแบบในตัวอย่าง

---

## ตัวอย่าง

**Input:**

```text
1000
200
300
250
```

**Output:**

```text
Saved: 750
Need: 250
Keep going
```
