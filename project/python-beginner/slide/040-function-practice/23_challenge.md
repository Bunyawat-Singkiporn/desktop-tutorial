## โจทย์

ลูกค้าหยิบของใส่ตะกร้าแล้วอยากรู้ยอดหลังส่วนลด
ร้านลดทันที 50 บาทถ้ายอดรวมถึง 300 บาทขึ้นไป

รับจำนวนชิ้น แล้วรับราคาสินค้าทีละชิ้น เก็บเป็น list
ใช้ฟังก์ชันคิดยอดรวมและส่วนลด

**เงื่อนไข:**

- `calc_total(prices)` คืนผลรวมของ list ราคา
- `apply_discount(total)` คืน `total - 50` ถ้ายอด `>= 300` ไม่งั้นคืนยอดเดิม
- พิมพ์ยอดก่อนลด และยอดหลังลด

---

## Input

บรรทัดแรกเป็นจำนวนชิ้น `n`
ถัดไปอีก `n` บรรทัดเป็นราคาสินค้าแต่ละชิ้น

## Output

2 บรรทัด — ยอดก่อนลด และยอดหลังลด

---

## ตัวอย่าง

**Input:**

```text
3
100
120
150
```

**Output:**

```text
370
320
```
