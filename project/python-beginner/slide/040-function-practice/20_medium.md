# 🧩 Function Practice — ข้อ 20: ค่าไฟฟ้าบ้าน

**Difficulty:** 🟡 Medium

---

## โจทย์

บ้านหนึ่งอยากประมาณค่าไฟฟ้าจากหน่วยที่ใช้
อัตราคิดแบบแบ่งช่วงตามหน่วย

รับจำนวนหน่วย แล้วให้ฟังก์ชันคืนค่าไฟตามเกณฑ์

**เงื่อนไข:**

- `electric_bill(units)` คืนค่าไฟ
- หน่วย `<= 50` → หน่วยละ 3 บาท
- หน่วย `<= 150` → หน่วยละ 4 บาท
- มากกว่านั้น → หน่วยละ 5 บาท

> คิดทั้งบิลด้วยอัตราเดียวตามช่วงที่หน่วยตกอยู่ ไม่ต้องคิดแบบขั้นบันได

---

## Input

จำนวนหน่วยเป็นจำนวนเต็ม 1 บรรทัด

## Output

ค่าไฟ 1 บรรทัด

---
