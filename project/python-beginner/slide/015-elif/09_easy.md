# ⭐ elif — ข้อ 5: ระดับสมาชิกร้าน

**Difficulty:** 🟢 Easy

---

## โจทย์

ร้านกาแฟจัดระดับสมาชิกตามแต้มสะสม

เขียนโปรแกรมรับแต้มสะสม แล้วบอกระดับสมาชิก

**เงื่อนไข:**

- แต้ม `>= 1000` → `Gold`
- แต้ม `>= 500` → `Silver`
- แต้ม `>= 100` → `Bronze`
- น้อยกว่านั้น → `Member`

---

## Input

แต้มสะสมเป็นจำนวนเต็ม 1 บรรทัด

## Output

2 บรรทัด — แต้ม และระดับสมาชิก

---

## ตัวอย่าง

**Input:**

```text
720
```

**Output:**

```text
Points : 720
Level  : Silver
```

---

## 💡 Hint

เก็บชื่อระดับไว้ในตัวแปรก่อน แล้วค่อยพิมพ์สองบรรทัด
