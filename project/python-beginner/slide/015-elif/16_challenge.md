# 🏢 elif — ข้อ 15: สลิปเงินเดือนตามแผนก

**Difficulty:** 🔴 Challenge

---

## โจทย์

บริษัทจ่ายเงินเดือนพื้นฐานตามแผนก แล้วบวกโบนัสตามยอดขาย

**ขั้นที่ 1 — เงินเดือนตามแผนก**

| แผนก | เงินเดือน |
|------|-----------|
| `sales` | 18000 |
| `support` | 15000 |
| นอกนั้น | 12000 |

**ขั้นที่ 2 — โบนัสตามยอดขาย**

| ยอดขาย | โบนัส |
|--------|-------|
| `>= 100000` | 5000 |
| `>= 50000` | 2000 |
| น้อยกว่านั้น | 500 |

เขียนโปรแกรมรับแผนกและยอดขาย แล้วออกสลิปเงินเดือน

---

## Input

2 บรรทัด — ชื่อแผนก (`sales` / `support` / อื่นๆ) และยอดขาย (จำนวนเต็ม)

## Output

สลิปเงินเดือนในกรอบ แสดงเงินเดือน โบนัส และยอดรับสุทธิ

---

## ตัวอย่าง

**Input:**

```text
sales
62000
```

**Output:**

```text
============================
          PAYROLL
============================
Salary  : 18000
Bonus   : 2000
Net Pay : 20000
============================
```

---

## 💡 Hint

ยอดรับสุทธิ = เงินเดือน + โบนัส
คิดเงินเดือนจากแผนกให้จบก่อน แล้วค่อยคิดโบนัสจากยอดขายด้วย `elif` คนละชุด
