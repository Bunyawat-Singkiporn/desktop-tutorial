# 🎟️ elif — ข้อ 3: ชั้นตั๋วตามอายุ

**Difficulty:** 🟢 Easy

---

## โจทย์

สวนสนุกแบ่งประเภทตั๋วตามอายุผู้เข้าชม

เขียนโปรแกรมรับอายุ แล้วบอกประเภทตั๋ว

**เงื่อนไข:**

- อายุ `>= 60` → `Senior`
- อายุ `>= 18` → `Adult`
- อายุ `>= 13` → `Teen`
- น้อยกว่านั้น → `Child`

---

## Input

อายุเป็นจำนวนเต็ม 1 บรรทัด

## Output

ประเภทตั๋ว 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
15
```

**Output:**

```text
Teen
```
