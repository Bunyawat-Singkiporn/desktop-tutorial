# ⚖️ elif — ข้อ 4: แถบ BMI

**Difficulty:** 🟢 Easy

---

## โจทย์

แอปสุขภาพคำนวณ BMI จากน้ำหนักกับส่วนสูง แล้วจัดแถบสุขภาพ

สูตร: `BMI = น้ำหนัก / (ส่วนสูง ** 2)`
โดยน้ำหนักเป็นกิโลกรัม ส่วนสูงเป็นเมตร

เขียนโปรแกรมรับน้ำหนักกับส่วนสูง แล้วบอกแถบ BMI

**เงื่อนไข:**

- BMI `>= 30` → `Obese`
- BMI `>= 25` → `Overweight`
- BMI `>= 18.5` → `Normal`
- น้อยกว่านั้น → `Underweight`

> ข้อนี้ต่างจากข้อก่อนหน้า ตรงที่ต้อง **คำนวณก่อน** แล้วค่อยใช้ `elif`

---

## Input

2 บรรทัด — น้ำหนัก (ทศนิยม) และส่วนสูงเป็นเมตร (ทศนิยม)

## Output

2 บรรทัด — ค่า BMI (ทศนิยม 1 ตำแหน่ง) และแถบสุขภาพ

---

## ตัวอย่าง

**Input:**

```text
68
1.70
```

**Output:**

```text
BMI  : 23.5
Band : Normal
```
