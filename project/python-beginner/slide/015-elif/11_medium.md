# 🎢 elif — ข้อ 9: เครื่องเล่นตามส่วนสูง

**Difficulty:** 🟡 Medium

---

## โจทย์

สวนสนุกจัดโซนเครื่องเล่นตามส่วนสูงของเด็ก

| ส่วนสูง | โซน |
|---------|-----|
| `>= 150` ซม. | `Thrill Zone` |
| `>= 120` ซม. | `Adventure Zone` |
| `>= 90` ซม. | `Family Zone` |
| น้อยกว่านั้น | `Kids Zone` |

เขียนโปรแกรมรับส่วนสูง แล้วบอกโซนที่เล่นได้

---

## Input

ส่วนสูงเป็นเซนติเมตร (จำนวนเต็ม) 1 บรรทัด

## Output

2 บรรทัด — ส่วนสูง และโซน

---

## ตัวอย่าง

**Input:**

```text
135
```

**Output:**

```text
Height : 135
Zone   : Adventure Zone
```

---

## 💡 Hint

เก็บชื่อโซนในตัวแปรก่อน แล้วค่อยพิมพ์สองบรรทัด
