# 📱 elif — ข้อ 11: แพ็กเกจเน็ตมือถือ

**Difficulty:** 🟡 Medium

---

## โจทย์

ค่ายมือถือแนะนำแพ็กเกจตามปริมาณเน็ตที่ลูกค้าต้องการต่อเดือน

| เน็ตที่ต้องการ | แพ็กเกจ | ราคา |
|----------------|---------|------|
| `>= 100` GB | `Ultra` | 899 |
| `>= 50` GB | `Plus` | 599 |
| `>= 20` GB | `Basic` | 299 |
| น้อยกว่านั้น | `Lite` | 149 |

เขียนโปรแกรมรับปริมาณเน็ต แล้วออกใบแนะนำแพ็ก

---

## Input

ปริมาณเน็ตเป็น GB (จำนวนเต็ม) 1 บรรทัด

## Output

ใบแนะนำแพ็กในกรอบ แสดงปริมาณเน็ต ชื่อแพ็ก และราคา

---

## ตัวอย่าง

**Input:**

```text
55
```

**Output:**

```text
========================
      DATA PLAN
========================
Need  : 55
Plan  : Plus
Price : 599
========================
```
