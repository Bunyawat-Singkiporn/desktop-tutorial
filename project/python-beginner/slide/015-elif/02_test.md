# 🌡️ elif — ข้อ 1: ระดับอุณหภูมิห้อง

**Difficulty:** 🟢 Easy

---

## โจทย์

แอปบ้านอัจฉริยะจัดระดับอุณหภูมิห้องแล้วแนะนำข้อความสั้นๆ

เขียนโปรแกรมรับอุณหภูมิ แล้วบอกระดับอากาศ

**เงื่อนไข:**

- อุณหภูมิ `>= 35` → `Hot`
- อุณหภูมิ `>= 25` → `Warm`
- อุณหภูมิ `>= 15` → `Cool`
- น้อยกว่านั้น → `Cold`

---

## Input

อุณหภูมิเป็นจำนวนเต็ม 1 บรรทัด

## Output

ระดับอากาศ 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
28
```

**Output:**

```text
Warm
```
