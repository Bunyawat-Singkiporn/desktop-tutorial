# Practice: Review — Medium A: แคชเชียร์มินิ (ยังไม่ใช้ if)

**Difficulty:** 🟡 Medium

---

## โจทย์

รับชื่อสินค้า (str) ราคา (int) จำนวน (int) แสดง:

```
<item> x<qty>
Total: <price*qty>
```


---

## ตัวอย่าง Input / Output

**Input:**
```
Eraser
10
3
```

**Output:**
```
Eraser x3
Total: 30
```

---

## 💡 Hint

ใช้ input + f-string ได้

---

## Starter Code

```python
item = input()
price = int(input())
qty = int(input())

```
