# 🏅 Variables — ข้อ 15: โปรไฟล์นักกีฬา

**Difficulty:** 🔴 Challenge

---

## โจทย์

แอปกีฬาสร้างโปรไฟล์นักวิ่ง: ชื่อ Nova อายุ 15 ระยะทางสะสมเริ่ม 0
หลังวิ่งเสร็จ อัปเดตระยะทางเป็น 8 แล้วพิมพ์การ์ดโปรไฟล์ตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
========================
    ATHLETE CARD
========================
Name : Nova
Age  : 15
Km   : 8
========================
```

---

## 💡 Hint

เปลี่ยนเฉพาะตัวแปรระยะทางก่อนพิมพ์การ์ด — ชื่อกับอายุยังใช้ค่าเดิม

---

## Starter Code

```python
athlete_name = "Nova"

km = 0

# เขียนโค้ดตรงนี้
```
