# 📦 Variables — ข้อ 8: ค่าส่งพัสดุ

**Difficulty:** 🟡 Medium

---

## โจทย์

ร้านออนไลน์คิดราคาสินค้า 180 บาท และค่าส่ง 40 บาท

เก็บทั้งสองค่า บวกเป็นยอดชำระ แล้วแสดงทั้งสามบรรทัดตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
Item: 180
Shipping: 40
Pay: 220
```

---

## 💡 Hint

สร้างตัวแปรใหม่เก็บผลบวก แล้วค่อยพิมพ์ทีละป้าย

---

## Starter Code

```python
item_price = 180
shipping = 40

# เขียนโค้ดตรงนี้
```
