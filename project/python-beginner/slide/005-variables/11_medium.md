# 🏃 Variables — ข้อ 9: สรุปรอบวิ่งสามวัน

**Difficulty:** 🟡 Medium

---

## โจทย์

แอปวิ่งเก็บระยะทางสามวัน: 3, 5 และ 4 กิโลเมตร

เก็บแต่ละวันในตัวแปร บวกรวม แล้วแสดงสรุปตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
Day1: 3
Day2: 5
Day3: 4
Total km: 12
```

---

## 💡 Hint

บวกทีละขั้นได้ เช่น บวกสองวันก่อน แล้วค่อยบวกวันที่สาม

---

## Starter Code

```python
day1 = 3
day2 = 5
day3 = 4

# เขียนโค้ดตรงนี้
```
