# 🎟️ Variables — ข้อ 11: ใบสรุปค่าเข้าชม

**Difficulty:** 🟡 Medium

---

## โจทย์

สวนสนุกคิดค่าบัตรเด็ก 120 และบัตรผู้ใหญ่ 200

เก็บราคาทั้งสอง บวกรวม แล้วพิมพ์ใบสรุปในกรอบตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
========================
      TICKET BILL
========================
Child  : 120
Adult  : 200
Total  : 320
========================
```

---

## 💡 Hint

คำนวณยอดรวมเก็บในตัวแปรก่อน แล้วค่อยพิมพ์กรอบทีเดียว

---

## Starter Code

```python
child_ticket = 120
adult_ticket = 200

# เขียนโค้ดตรงนี้
```
