# 🎁 Variables — ข้อ 13: ตะกร้าของฝาก

**Difficulty:** 🔴 Challenge

---

## โจทย์

ซื้อของฝากสามอย่าง: สบู่ 45, ผ้าเช็ดหน้า 30, ขนม 55 บาท

เก็บราคาแต่ละชิ้น หาผลรวม แล้วพิมพ์ใบเสร็จในกรอบตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
========================
     GIFT BASKET
========================
Soap     : 45
Towel    : 30
Snack    : 55
Total    : 130
========================
```

---

## 💡 Hint

บวกสามค่าเก็บในตัวแปรเดียวก่อน แล้วจัดพิมพ์กรอบให้คอลัมน์ตรง

---

## Starter Code

```python
soap = 45
towel = 30
snack = 55

# เขียนโค้ดตรงนี้
```
