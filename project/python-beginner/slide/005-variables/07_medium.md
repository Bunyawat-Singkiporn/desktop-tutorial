# 📝 Variables — ข้อ 7: คะแนนก่อน-หลังสอบซ่อม

**Difficulty:** 🟡 Medium

---

## โจทย์

นักเรียนได้คะแนนครั้งแรก 48 แล้วสอบซ่อมได้ 72

พิมพ์คะแนนเดิมก่อน เปลี่ยนค่าในตัวแปรเดิม แล้วพิมพ์คะแนนใหม่ ตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
Before: 48
After: 72
```

---

## 💡 Hint

พิมพ์ค่าเดิมก่อน แล้วค่อยใส่ของใหม่ลงกล่องเดิม แล้วพิมพ์อีกรอบ

---

## Starter Code

```python
score = 48

# เขียนโค้ดตรงนี้
```
