# 🏊 Variables — ข้อ 6: การ์ดสมาชิกสระว่ายน้ำ

**Difficulty:** 🟡 Medium

---

## โจทย์

สระว่ายน้ำโรงเรียนออกบัตรสมาชิกให้นักเรียน

เก็บชื่อ อายุ และค่าธรรมเนียมรายเดือนไว้ในตัวแปร แล้วพิมพ์บัตร 3 บรรทัดตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
Member: Kira
Age: 14
Fee: 350
```

---

## 💡 Hint

ใช้ `print("ป้าย:", ตัวแปร)` ทีละบรรทัด — แต่ละบรรทัดคนละตัวแปร

---

## Starter Code

```python
member_name = "Kira"
age = 14
fee = 350

# เขียนโค้ดตรงนี้
```
