# 🐾 Variables — ข้อ 1: การ์ดสัตว์เลี้ยง

**Difficulty:** 🟢 Easy

---

## โจทย์

คลินิกสัตว์เลี้ยงอยากพิมพ์การ์ดแนะนำสัตว์ตัวแรกของวัน

เก็บชื่อสัตว์ไว้ในตัวแปร แล้วแสดง 2 บรรทัดตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ข้อความ 2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Pet Name
Mochi
```

---

## Starter Code

```python
pet_name = "Mochi"

# เขียนโค้ดตรงนี้
```
