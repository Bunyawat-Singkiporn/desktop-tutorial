# 📋 Lists — ข้อ 7: ป้ายชั้นเรียนพร้อมเลขที่

**Difficulty:** 🟡 Medium

---

## โจทย์

ครูอยากพิมพ์รายชื่อพร้อมเลขที่เริ่มที่ 1

กำหนด `names = ["Kate", "Leo", "Maya"]`

แสดงแบบ `1. Kate` ทีละบรรทัด (เพิ่มตัวนับเองใน loop)

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
1. Kate
2. Leo
3. Maya
```


---

## 💡 Hint

สร้างตัวแปรนับก่อน loop แล้วเพิ่มทีละ 1

---

## Starter Code

```python
names = ["Kate", "Leo", "Maya"]

# เขียนโค้ดตรงนี้
```
