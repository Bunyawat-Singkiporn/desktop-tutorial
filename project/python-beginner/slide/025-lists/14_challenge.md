# 📋 Lists — ข้อ 14: รายงานคะแนนสอบ

**Difficulty:** 🔴 Challenge

---

## โจทย์

ครูต้องการรายงานผลสอบรายคน

กำหนด `names = ["Ann", "Ben", "Cara"]` และ `scores = [72, 48, 91]`

พิมพ์ `Name Score Status` โดย Status เป็น Pass ถ้าคะแนน >= 50 ไม่เช่นนั้น Fail
แล้วปิดท้ายด้วยจำนวนคนผ่าน

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

รายงานรายคน + สรุป

---

## ตัวอย่าง

**Output:**

```text
Ann 72 Pass
Ben 48 Fail
Cara 91 Pass
Passed: 2
```


---

## 💡 Hint

ใช้ตัวนับคู่กับ list คะแนน เพราะยังไม่มี range(len) ในบทนี้ก็ใช้ได้ด้วย index มือ

---

## Starter Code

```python
names = ["Ann", "Ben", "Cara"]
scores = [72, 48, 91]

# เขียนโค้ดตรงนี้
```
