# 📋 Lists — ข้อ 12: หัวท้ายของคิว

**Difficulty:** 🟡 Medium

---

## โจทย์

ระบบคิวยากโชว์คนหัวคิวและท้ายคิวพร้อมจำนวนคน

กำหนด `queue = ["A01", "A02", "A03", "A04"]`

แสดงตามตัวอย่าง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

กล่องสรุป 3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Front: A01
Back : A04
Count: 4
```


---

## 💡 Hint

ใช้ [0] และ [-1] คู่กับ len

---

## Starter Code

```python
queue = ["A01", "A02", "A03", "A04"]

# เขียนโค้ดตรงนี้
```
