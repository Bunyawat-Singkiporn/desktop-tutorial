# 📋 Lists — ข้อ 16: ป้ายชั้นเรียนแบบกล่อง

**Difficulty:** 🔴 Challenge

---

## โจทย์

โรงเรียนอยากได้ป้ายชั้นเรียนแบบมีกรอบ

กำหนด `students = ["Ann", "Ben", "Cara", "Dan"]`

แสดงตามตัวอย่าง (หัวท้ายกรอบ ความยาว 20 ตัวอักษร `=`)

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

กล่องสรุป

---

## ตัวอย่าง

**Output:**

```text
====================
First : Ann
Last  : Dan
Count : 4
====================
```


---

## 💡 Hint

จัดช่องว่างหลังป้ายกำกับให้ตรงคอลัมน์

---

## Starter Code

```python
students = ["Ann", "Ben", "Cara", "Dan"]

# เขียนโค้ดตรงนี้
```
