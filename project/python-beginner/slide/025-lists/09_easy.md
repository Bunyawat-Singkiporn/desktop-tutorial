# 📋 Lists — ข้อ 9: ของชิ้นรองสุดท้าย

**Difficulty:** 🟢 Easy

---

## โจทย์

คลังสินค้าอยากดูชื่อสินค้าชิ้นรองสุดท้ายในกล่อง

กำหนด `items = ["Pen", "Book", "Glue", "Tape", "Ruler"]`

แสดงชื่อชิ้นรองสุดท้ายด้วย negative index

---

## ตัวอย่าง

**Output:**

```text
Tape
```


---

## Starter Code

```python
items = ["Pen", "Book", "Glue", "Tape", "Ruler"]

# เขียนโค้ดตรงนี้
```
