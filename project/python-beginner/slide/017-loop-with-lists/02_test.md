# 🌸 Practice: Loop with Lists — Question 1: Print All Items

---

## โจทย์

วนซ้ำ list ด้านล่างแล้วพิมพ์แต่ละชื่อ

```python
animals = ["Cat", "Dog", "Fish", "Bird"]
```

**Output:**
```
Cat
Dog
Fish
Bird
```

## 💡 Hint
