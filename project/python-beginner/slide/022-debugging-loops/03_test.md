# 🐛 Practice: Debugging Loops — Question 2: Fix Infinite Loop

**Difficulty:** 🟡 Medium

---

## โจทย์

โค้ดด้านล่างวนไม่หยุด — แก้ให้นับ 1–5 แล้วหยุด

```python
count = 1
while count <= 5:
    print(count)
```

**Output ที่ต้องการ:**
```
1
2
3
4
5
```
