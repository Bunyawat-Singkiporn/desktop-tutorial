## 2) กติกาขอบเขต (สำคัญที่สุด)

> **ห้ามใช้สิ่งที่ยังไม่เคยสอน — เด็ดขาด** ดูได้จาก `_SCOPE.md`

- โจทย์บทที่ N ใช้ได้เฉพาะความรู้จากบทที่ 1 ถึง N เท่านั้น
- ใช้ความรู้บทก่อนหน้าได้เต็มที่ (และควรใช้ เพื่อให้เด็กได้ทบทวน)
- **ข้อ Challenge ก็ห้ามเกินขอบเขต** — Challenge ยากเพราะ *ผสมหลายเงื่อนไข / หลายขั้นตอน* ไม่ใช่เพราะใช้ของใหม่
- ถ้าอยากได้โจทย์ที่ต้องใช้ของใหม่ → เก็บไว้ทำในบทที่สอนสิ่งนั้น

**ตัวอย่างการทำให้ยากขึ้นโดยไม่เกินขอบเขต**

| ✅ ทำได้ | ❌ ห้าม |
|----------|---------|
| เพิ่มเงื่อนไขเป็น 2 ชุดเรียงกัน | ใช้ `elif` ก่อนบท 015 |
| ให้คำนวณก่อนแล้วค่อยเทียบ | ใช้ `and` / `or` ก่อนบท 016 |
| รับ input หลายค่า | ใช้ `for` ก่อนบท 017 |
| จัด output เป็นตาราง/กล่อง | ใช้ `list` ก่อนบท 018 |

## 3) โจทย์ข้อแรกต้อง **ไม่ใช่** ตัวอย่างในบทเรียน

ข้อ `02` ของทุกบทห้ามเป็นโจทย์เดียวกับตัวอย่างในไฟล์บทเรียน

- บทเรียนสอน "คะแนน >= 50 → Pass/Fail" → ข้อแรกต้องเปลี่ยนสถานการณ์ (เช่น อุณหภูมิ, แบตเตอรี่, ส่วนสูง)
- เปลี่ยนเฉพาะตัวเลขไม่นับว่าต่าง ต้องเปลี่ยน **สถานการณ์** ด้วย
- ดูช่อง `EXAMPLES:` ใน `_SCOPE.md` ว่าบทนั้นใช้ตัวอย่างอะไรไปแล้วบ้าง

## 4) โจทย์ต้องเป็นสถานการณ์จริง ไม่ใช่โจทย์ลอย

| ✅ ดี | ❌ ไม่ดี |
|-------|---------|
| "ร้านคิดค่าส่ง 40 บาท ถ้าซื้อครบ 300 ส่งฟรี" | "รับ n ถ้า n >= 300 แสดง 0 ไม่งั้น 40" |
| "แอปเตือนเมื่อแบตต่ำกว่า 20%" | "รับค่า x เทียบกับ 20" |
| "ตู้จอดรถคิดชั่วโมงแรกฟรี" | "รับ h คำนวณ (h-1)*20" |

**เช็กลิสต์ความเป็นธรรมชาติ**

- [ ] อ่านแล้วนึกออกว่าเจอในชีวิตจริงตรงไหน
- [ ] ชื่อตัวแปรใน Starter Code สื่อความหมาย (`price` ไม่ใช่ `x`)
- [ ] ตัวเลขสมเหตุสมผล (ราคา 499 ไม่ใช่ 7)
- [ ] ไม่มีศัพท์แปลกๆ / คำแปลผิด

## 5) โครงไฟล์โจทย์ (ใช้เหมือนกันทุกข้อ)

````markdown
# 🔋 if/else — ข้อ 3: เตือนแบตเตอรี่ต่ำ

**Difficulty:** 🟢 Easy

---

## โจทย์

<สถานการณ์ 1–3 บรรทัด>

**เงื่อนไข:**

- ถ้า ... → `Low Battery`
- ถ้าไม่ใช่ → `Battery OK`

---

## Input

<รับอะไร กี่บรรทัด>

## Output

<ต้องแสดงอะไร>

---

## ตัวอย่าง

**Input:**

```text
15
```

**Output:**

```text
Battery : 15%
Status  : Low Battery
```

---

## 💡 Hint

<แนวคิด ไม่ใช่โค้ดเฉลย>

---

## Starter Code

```python
battery = int(input())

# เขียนโค้ดตรงนี้
```
````

**กติกาของแต่ละส่วน**

| ส่วน | กติกา |
|------|-------|
| หัวข้อ | `# <emoji> <ชื่อบท> — ข้อ N: <ชื่อโจทย์ภาษาไทย>` |
| Difficulty | 🟢 Easy / 🟡 Medium / 🔴 Challenge เท่านั้น |
| โจทย์ | เล่าสถานการณ์ ไม่ใช่สั่งว่าให้เขียนโค้ดอะไร |
| Input / Output | บอกให้ชัดว่ารับกี่ค่า แสดงกี่บรรทัด |
| ตัวอย่าง | ต้องมี **อย่างน้อย 1 คู่** ใน ` ```text ` block เสมอ |
| Hint | Easy ใส่หรือไม่ใส่ก็ได้ / Medium-Challenge ใส่เสมอ |
| Starter Code | ให้บรรทัดรับ input + คอมเมนต์ ห้ามให้โครง if/else สำเร็จรูป |

> ❌ **ห้ามเขียนตัวอย่างแบบย่อ** เช่น `**Input:** 10 → Open`
> ✅ ต้องแยกเป็น block ตามแบบข้างบน (เครื่องตรวจอัตโนมัติอ่านจาก block นี้)

## 6) Hint ที่ดี

Hint คือ **แนวคิด** ไม่ใช่เฉลย

| ✅ Hint ที่ดี | ❌ Hint ที่ไม่ดี |
|--------------|-----------------|
| "คำนวณราคาสุทธิเก็บไว้ในตัวแปรก่อน แล้วค่อยแสดงผล" | `final = price - 20` |
| "เริ่มจากเทียบว่าเงินพอไหม แล้วค่อยหาเงินทอน" | `if money >= price:` |
| "ค่าจอดคิดจากชั่วโมงที่เกินมาจากชั่วโมงแรก" | `(hours - 1) * 20` |

> ถ้า Hint คัดลอกไปวางแล้วรันได้เลย แปลว่า Hint นั้นผิดกติกา

## 7) รูปแบบ Output

เลือกตามความเหมาะสมของโจทย์

**แบบที่ 1 — บรรทัดเดียว** (ข้อง่าย ผลลัพธ์เดียว)

```text
Even Number
```

**แบบที่ 2 — ป้ายกำกับ** (มี 2–3 ค่า)

```text
Total: 18
```

```text
Battery : 15%
Status  : Low Battery
```

**แบบที่ 3 — กล่องสรุป** (ข้อที่มีหลายค่า / Medium-Challenge)

```text
========================
      SHOPPING
========================
Price       : 499
Discount    : 10
Final Price : 489
========================
```

> ข้อความใน Output ใช้ภาษาอังกฤษ (พิมพ์ง่าย ไม่ต้องสลับภาษา)
> กล่องใช้ `=` ยาวเท่ากันทุกบรรทัด และจัดคอลัมน์ `:` ให้ตรงกัน

## 8) ห้ามซ้ำกันเอง

ภายในบทเดียวกัน โจทย์ 15 ข้อต้อง **ไม่ซ้ำแกนการคิด**

- ❌ ข้อ 2 "คะแนน >= 50 → Pass/Fail" + ข้อ 7 "คะแนน >= 60 → Pass/Fail" = ซ้ำ
- ✅ ข้อ 2 "เทียบค่ากับเกณฑ์คงที่" + ข้อ 7 "เทียบค่าสองค่าที่รับเข้ามา" = ต่าง

**วิธีทำให้ไม่ซ้ำ — เปลี่ยนแกนการคิด**

1. เทียบกับค่าคงที่
2. เทียบสองค่าที่รับเข้ามา
3. คำนวณก่อน แล้วค่อยเทียบ
4. เทียบแล้วคำนวณต่อ
5. เงื่อนไข 2 ชุดเรียงกัน
6. เงื่อนไขที่ผลลัพธ์เป็นตัวเลข ไม่ใช่ข้อความ

## 9) ไฟล์เฉลย

- ทุกข้อต้องมีเฉลยใน `answer/` ชื่อขึ้นต้นด้วยเลขเดียวกับโจทย์
- เฉลยต้อง **รันได้จริง** และเมื่อป้อน Input ตามตัวอย่าง ต้องได้ Output ตรงเป๊ะทุกตัวอักษร
- เฉลยใช้เฉพาะสิ่งที่อยู่ในขอบเขตเช่นกัน (ห้ามโชว์ทางลัดที่ยังไม่สอน)
