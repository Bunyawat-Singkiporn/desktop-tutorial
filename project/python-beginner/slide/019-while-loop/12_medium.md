# 🏧 while-loop — ข้อ 12: ใส่ PIN จนถูกต้อง

**Difficulty:** 🟡 Medium

---

## โจทย์

PIN ที่ถูกต้องคือ `"1234"`
รับ PIN ซ้ำจนถูก แล้วพิมพ์ `PIN OK`

---

## Input

PIN ทีละบรรทัด

## Output

PIN OK เมื่อถูกต้อง

---

## ตัวอย่าง

**Input:**

```text
0000
1111
1234
```

**Output:**

```text
PIN OK
```

---

## 💡 Hint

while pin != "1234" แล้วรับใหม่

---

## Starter Code

```python
pin = input()

# เขียนโค้ดตรงนี้
```
