# 📐 while-loop — ข้อ 14: ค่าเฉลี่ยจนกดศูนย์

**Difficulty:** 🔴 Challenge

---

## โจทย์

รับจำนวนเต็มซ้ำจนเจอ `0`
หาผลรวมและจำนวนค่า (ไม่นับ 0) แล้วแสดงค่าเฉลี่ยทศนิยม 1 ตำแหน่งในกรอบ

---

## Input

จำนวนทีละบรรทัด จบด้วย 0

## Output

ใบสรุปในกรอบ

---

## ตัวอย่าง

**Input:**

```text
10
20
30
0
```

**Output:**

```text
========================
      AVERAGE
========================
Count   : 3
Total   : 60
Average : 20.0
========================
```

---

## 💡 Hint

สะสม total กับ count ในลูป แล้วคำนวณ average หลังจบ

---

## Starter Code

```python
total = 0
count = 0
number = int(input())

# เขียนโค้ดตรงนี้
```
