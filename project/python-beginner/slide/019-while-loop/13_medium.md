# 🚶 while-loop — ข้อ 13: ก้าวเดินจนถึงเป้าหมาย

**Difficulty:** 🟡 Medium

---

## โจทย์

เป้าหมายอยู่ที่ `target` ก้าว เริ่มจาก `steps = 0`
แต่ละรอบรับจำนวนก้าวที่เดินเพิ่ม แล้วบวกเข้า `steps`
พิมพ์ยอดก้าวสะสมทุกครั้งหลังบวก จนกว่า `steps >= target`

---

## Input

บรรทัดแรกเป้าหมาย ตามด้วยก้าวที่เดินแต่ละรอบ

## Output

ยอดก้าวสะสมทีละบรรทัดจนถึงเป้า

---

## ตัวอย่าง

**Input:**

```text
20
5
8
7
```

**Output:**

```text
5
13
20
```

---

## 💡 Hint

ตราบใดที่ยังไม่ถึงเป้า ให้รับก้าว บวกสะสม แล้วพิมพ์ยอด

---

## Starter Code

```python
target = int(input())
steps = 0

# เขียนโค้ดตรงนี้
```
