# Practice: while Loop — Medium B: ทายเลขจนถูก

**Difficulty:** 🟡 Medium

---

## โจทย์

กำหนดรหัสลับ 7 — รับทายซ้ำด้วย while จนถูก แล้วแสดง `Correct!` (ระหว่างผิดแสดง `Wrong`)


---

## ตัวอย่าง Input / Output

**Input:**
```
1
7
```
**Output:**
```
Wrong
Correct!
```

---

## 💡 Hint

while guess != secret

---

## Starter Code

```python
secret = 7
guess = int(input())

```
