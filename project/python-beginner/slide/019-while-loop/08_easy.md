# ⏱️ while-loop — ข้อ 8: นับถอยหลังเริ่มงาน

**Difficulty:** 🟢 Easy

---

## โจทย์

รับจำนวนเต็ม `n` แล้วนับถอยหลังจาก n ถึง 1
เมื่อจบให้พิมพ์ `Start!`

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

นับถอยหลังแล้ว Start!

---

## ตัวอย่าง

**Input:**

```text
3
```

**Output:**

```text
3
2
1
Start!
```

---

## Starter Code

```python
n = int(input())

# เขียนโค้ดตรงนี้
```
