# 🔞 while-loop — ข้อ 9: ตรวจอายุจนครบ 18

**Difficulty:** 🟢 Easy

---

## โจทย์

รับอายุซ้ำจนกว่าจะได้ค่า `>= 18`
แล้วพิมพ์ `Adult`

---

## Input

อายุทีละบรรทัด จนครบเกณฑ์

## Output

Adult เมื่ออายุถึงเกณฑ์

---

## ตัวอย่าง

**Input:**

```text
15
16
18
```

**Output:**

```text
Adult
```
