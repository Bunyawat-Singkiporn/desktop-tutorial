# 📊 while-loop — ข้อ 11: นับคะแนนจนเจอศูนย์

**Difficulty:** 🟡 Medium

---

## โจทย์

รับคะแนนทีละตัว จนเจอ `0` (ไม่นับ 0)
นับว่ามีคะแนนกี่ตัว แล้วแสดงจำนวน

---

## Input

คะแนนทีละบรรทัด จบด้วย 0

## Output

Count: <จำนวน>

---

## ตัวอย่าง

**Input:**

```text
80
70
90
0
```

**Output:**

```text
Count: 3
```

---

## 💡 Hint

คล้ายข้อรวมเลข แต่สะสมตัวนับแทนผลรวม

---

## Starter Code

```python
count = 0
score = int(input())

# เขียนโค้ดตรงนี้
```
