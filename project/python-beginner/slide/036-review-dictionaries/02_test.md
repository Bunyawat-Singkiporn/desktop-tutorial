# 🔁 Review Dicts — ข้อ 2: อ่านค่าปลอดภัย

**Difficulty:** 🟢 Easy

---

## โจทย์

อ่านคะแนนแบบเช็คคีย์ก่อน

กำหนด `student = {"name": "Gina", "room": "M3"}`

ถ้ามี `score` แสดงค่า ไม่งั้นแสดง `No score yet`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
No score yet
```

```python
student = {"name": "Gina", "room": "M3"}

# เขียนโค้ดตรงนี้
```
