# 🔁 Review Lists — ข้อ 15: สรุปผลสอบทบทวน

**Difficulty:** 🔴 Challenge

---

## โจทย์

สรุปผลสอบรายคนจากสอง list

กำหนด `names = ["Ann", "Ben", "Cara"]` และ `scores = [45, 80, 70]`

ใช้ range(len) พิมพ์ Pass/Fail (>=50) แล้วแสดงจำนวนผ่านและค่าเฉลี่ยทุกคนทศนิยม 1 ตำแหน่ง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

รายงาน + สรุป

---

## ตัวอย่าง

**Output:**

```text
Ann Fail
Ben Pass
Cara Pass
Passed : 2
Average: 65.0
```


---

## 💡 Hint

วนด้วย index คู่สอง list

---

## Starter Code

```python
names = ["Ann", "Ben", "Cara"]
scores = [45, 80, 70]

# เขียนโค้ดตรงนี้
```
