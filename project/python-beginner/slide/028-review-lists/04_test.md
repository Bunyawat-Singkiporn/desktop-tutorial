# 🔁 Review Lists — ข้อ 4: ลบเมนูเลิกขาย

**Difficulty:** 🟢 Easy

---

## โจทย์

ร้านเลิกขายเมนูหนึ่งรายการ

กำหนด `menu = ["Pad Thai", "Soup", "Salad", "Curry"]`

ลบ `Soup` แล้วแสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Pad Thai', 'Salad', 'Curry']
```


---

## Starter Code

```python
menu = ["Pad Thai", "Soup", "Salad", "Curry"]

# เขียนโค้ดตรงนี้

print(menu)
```
