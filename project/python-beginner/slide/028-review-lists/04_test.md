# 🔀 Practice Review Lists — Question 3: Merge and Sort

**Difficulty:** 🟡 Medium

---

## โจทย์

รวม 2 list เข้าด้วยกัน แล้วเรียงจากน้อยไปมาก และแสดงผล

```python
group_a = [5, 2, 9, 1]
group_b = [8, 3, 7, 4]
```

**Output:**
```
[1, 2, 3, 4, 5, 7, 8, 9]
```

---

## 💡 Hint

ใช้ `+` เพื่อรวม list แล้วใช้ `.sort()`

---
