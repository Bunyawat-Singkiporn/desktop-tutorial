# 🔁 Review Lists — ข้อ 16: กล่องสรุปยอดขาย

**Difficulty:** 🔴 Challenge

---

## โจทย์

สรุปยอดขายรายวันแบบมีกรอบ

กำหนด `sales = [900, 1200, 750, 1100]`

ลบยอดผิดปกติ `750` เพิ่ม `1300` แล้วเรียงน้อยไปมาก
แสดง list ยอดรวม และยอดสูงสุด (ตัวท้ายหลังเรียง) ตามตัวอย่าง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

กล่องสรุป

---

## ตัวอย่าง

**Output:**

```text
====================
[900, 1100, 1200, 1300]
Total  : 4500
Highest: 1300
====================
```
