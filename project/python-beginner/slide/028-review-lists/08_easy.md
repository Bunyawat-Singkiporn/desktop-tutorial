# 🔁 Review Lists — ข้อ 8: เรียงคะแนนทบทวน

**Difficulty:** 🟢 Easy

---

## โจทย์

เรียงคะแนนจากมากไปน้อยเพื่อติดบอร์ด

กำหนด `scores = [65, 90, 72, 88]`

เรียง reverse แล้วแสดง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
[90, 88, 72, 65]
```


---

## Starter Code

```python
scores = [65, 90, 72, 88]

# เขียนโค้ดตรงนี้

print(scores)
```
