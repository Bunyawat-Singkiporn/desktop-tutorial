## โจทย์

กำหนดรายการคำ แสดงแต่ละคำพร้อมความยาว

```python
words = ["cat", "python", "hi", "elephant", "ok"]
```

**Output:**
```
cat: 3
python: 6
hi: 2
elephant: 8
ok: 2
```
