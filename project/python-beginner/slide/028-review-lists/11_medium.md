# 🔁 Review Lists — ข้อ 11: นับงานเสร็จ

**Difficulty:** 🟡 Medium

---

## โจทย์

นับงานที่ขึ้นต้นด้วยคำว่า Done ในข้อความสถานะ

กำหนด `status = ["Done", "Todo", "Done", "Todo", "Done"]`

แสดง `Done: N` โดยเทียบว่าค่าเท่ากับ `Done`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
Done: 3
```


---

## 💡 Hint

เทียบด้วย == ไม่ใช้ in

---

## Starter Code

```python
status = ["Done", "Todo", "Done", "Todo", "Done"]

# เขียนโค้ดตรงนี้
```
