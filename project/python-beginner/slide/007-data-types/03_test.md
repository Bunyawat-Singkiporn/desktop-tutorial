# 🧪 Practice: Data Types — Question 2: Type Prediction

**Difficulty:** 🟡 Medium

---

## โจทย์

เขียนโค้ดสร้าง variable ตามตาราง แล้วใช้ `print(type(...))` แสดงชนิด พร้อมตรวจสอบว่าตรงกับที่คาดไว้

| ค่า | คาดว่าเป็น type |
|-----|----------------|
| `42` | `int` |
| `"42"` | `str` |
| `42.0` | `float` |
| `True` | `bool` |

**Output:**
```
<class 'int'>
<class 'str'>
<class 'float'>
<class 'bool'>
```

---

## 💡 Hint

`42` และ `"42"` ดูเหมือนกัน แต่ type ต่างกัน! เครื่องหมาย `"..."` เปลี่ยน type เป็น str

---

## Starter Code

```python
a = 42
b = "42"
c = 42.0
d = True

# Print type of each
```
