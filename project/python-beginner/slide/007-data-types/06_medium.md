# Practice: Data Types — Medium A: ทาย type()

**Difficulty:** 🟡 Medium

---

## โจทย์

สร้างตัวแปรตามตาราง แล้วพิมพ์ชนิดทีละบรรทัดด้วย `type(...)` (แสดงผลตามที่ Python ให้):

| ตัวแปร | ค่า |
|--------|-----|
| a | 10 |
| b | 2.5 |
| c | "10" |
| d | False |


---

## 💡 Hint

ใช้ print(type(a)) ฯลฯ

---

## Starter Code

```python
a = 10
b = 2.5
c = "10"
d = False

```
