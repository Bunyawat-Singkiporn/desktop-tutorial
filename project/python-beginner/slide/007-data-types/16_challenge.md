# 🧬 Data Types — ข้อ 16: รายงานชนิดครบ

**Difficulty:** 🔴 Challenge

---

## โจทย์

สร้างตัวแปรครบ 4 ชนิด: `i = 1`, `f = 1.5`, `s = "hi"`, `b = True` แล้วพิมพ์ type ทั้งสี่

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

4 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```


---

## 💡 Hint

ลำดับ int float str bool

---

## Starter Code

```python
i = 1
f = 1.5
s = "hi"
b = True

# แสดง type ทั้งสี่
```
