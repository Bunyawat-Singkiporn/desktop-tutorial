# 🧬 Data Types — ข้อ 5: ใบเสร็จชนิดข้อมูล

**Difficulty:** 🔴 Challenge

---

## โจทย์

เก็บ `item = "Juice"`, `price = 25.5`, `qty = 2`, `paid = True` แล้วแสดงค่าและ type ของ price กับ qty

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

ใบเสร็จ

---

## ตัวอย่าง

**Output:**

```text
Item: Juice
Price: 25.5
Price Type: <class 'float'>
Qty: 2
Qty Type: <class 'int'>
Paid: True
```
