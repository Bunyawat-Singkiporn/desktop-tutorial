# 🏁 Final Review — ข้อ 13: while นับถอย

**Difficulty:** 🟡 Medium

---

## โจทย์

เริ่ม n = 3 ขณะ n > 0 พิมพ์ n แล้วลด 1 หลังจบพิมพ์ `Done`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

4 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
3
2
1
Done
```


---

## 💡 Hint

ลดค่าในลูป

---

## Starter Code

```python
n = 3
while n > 0:
    print(n)
    n -= 1
print("Done")
```
