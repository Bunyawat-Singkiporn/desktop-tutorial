# 🏁 Final Review — ข้อ 7: กรองคะแนน

**Difficulty:** 🟡 Medium

---

## โจทย์

จาก `[45, 60, 80, 50]` พิมพ์เฉพาะค่า > 50

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
60
80
```


---

## 💡 Hint

เงื่อนไขเข้มกว่าเท่ากับ

---

## Starter Code

```python
scores = [45, 60, 80, 50]
for s in scores:
    if s > 50:
        print(s)
```
