# 🏁 Final Review — ข้อ 3: เลขคู่หรือไม่

**Difficulty:** 🟢 Easy

---

## โจทย์

รับจำนวนเต็ม พิมพ์ `Even` หรือ `Odd`

---

## Input

ดูตัวอย่าง

## Output

1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
8
```

**Output:**

```text
Even
```


---

## Starter Code

```python
n = int(input())
if n % 2 == 0:
    print("Even")
else:
    print("Odd")
```
