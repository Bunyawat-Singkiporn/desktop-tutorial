# Practice: Operators — Medium A: ทอนเงิน

**Difficulty:** 🟡 Medium

---

## โจทย์

รับราคาและเงินที่จ่าย (int) แสดงเงินทอน:

```
Change: <paid-price>
```


---

## ตัวอย่าง Input / Output

**Input:**
```
40
100
```

**Output:**
```
Change: 60
```

---

## 💡 Hint

change = paid - price

---

## Starter Code

```python
price = int(input())
paid = int(input())

```
