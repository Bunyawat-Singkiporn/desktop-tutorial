# ➕ Operators — เครื่องหมายคำนวณ

---

## Arithmetic Operators (คำนวณตัวเลข)

| Operator | ความหมาย | ตัวอย่าง | ผลลัพธ์ |
|---------|---------|---------|--------|
| `+` | บวก | `10 + 3` | `13` |
| `-` | ลบ | `10 - 3` | `7` |
| `*` | คูณ | `10 * 3` | `30` |
| `/` | หาร (ได้ทศนิยม) | `10 / 3` | `3.333...` |
| `//` | หารเต็ม (ปัดทิ้ง) | `10 // 3` | `3` |
| `%` | เศษจากการหาร | `10 % 3` | `1` |
| `**` | ยกกำลัง | `2 ** 3` | `8` |

---

## `/` vs `//` ต่างกันอย่างไร?

```python
print(10 / 3)    # 3.3333333333333335  (ทศนิยม)
print(10 // 3)   # 3                   (ปัดทศนิยมทิ้ง)
```

> ใช้ `//` เมื่อต้องการผลเป็นจำนวนเต็มเท่านั้น

---

## % (Modulo) — เศษที่เหลือจากหาร

```python
print(10 % 3)    # 1   (10 หาร 3 เหลือเศษ 1)
print(15 % 4)    # 3   (15 หาร 4 เหลือเศษ 3)
print(8 % 2)     # 0   (8 หาร 2 เหลือเศษ 0)
```

> ใช้มากในการตรวจ เลขคู่/คี่ ในบทถัดไป!

---

## Comparison Operators (เปรียบเทียบ)

ผลลัพธ์เป็น `True` หรือ `False` เสมอ

| Operator | ความหมาย | ตัวอย่าง | ผลลัพธ์ |
|---------|---------|---------|--------|
| `==` | เท่ากับ | `5 == 5` | `True` |
| `!=` | ไม่เท่ากับ | `5 != 3` | `True` |
| `>` | มากกว่า | `5 > 3` | `True` |
| `<` | น้อยกว่า | `5 < 3` | `False` |
| `>=` | มากกว่าหรือเท่ากับ | `5 >= 5` | `True` |
| `<=` | น้อยกว่าหรือเท่ากับ | `3 <= 5` | `True` |

## ตัวอย่างโปรแกรม

```python
price = int(input())
paid = int(input())
change = paid - price

print(f"Price: {price}")
print(f"Paid:  {paid}")
print(f"Change: {change}")
```

Input:
```
45
100
```

Output:
```
Price: 45
Paid:  100
Change: 55
```

## ลำดับการคำนวณ

Python ทำตามลำดับ **เหมือนคณิตศาสตร์**:

| ลำดับ | Operator |
|------|---------|
| 1 (สูงสุด) | `**` |
| 2 | `*`, `/`, `//`, `%` |
| 3 (ต่ำสุด) | `+`, `-` |

```python
print(2 + 3 * 4)     # 14  (คูณก่อน)
print((2 + 3) * 4)   # 20  (วงเล็บก่อน)
```
