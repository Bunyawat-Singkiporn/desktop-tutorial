# 📋 สารบัญโจทย์ — บท 006 Naming Rules

**ขอบเขตของบทนี้:** กฎตั้งชื่อตัวแปร · **snake_case** · ชื่อสื่อความหมาย · `print` แสดงผล · ใช้ `=` และบวก/ลบตัวเลขอย่างระมัดระวัง

> ❌ ยังไม่มี `input()` / แปลงชนิด (บท 008) · ไม่มี f-string (บท 010) · ไม่มี `*` `/` (บท 011) · ไม่มี `if` (บท 013) · อย่าใช้ keyword เป็นชื่อตัวแปร

## หมายเหตุสำหรับครู

- ข้อ `02` **ไม่ซ้ำ** ตัวอย่างในบทเรียน (บทเรียนใช้ `price`/`discount` และโปรแกรมเสื้อ `T-Shirt`)
- แกนหลักของบทคือ **ตั้งชื่อให้ถูกและสื่อความหมาย** — ผลลัพธ์บนจอสำคัญ แต่ชื่อในโค้ดสำคัญกว่า
- ใช้ `-` ได้ตามที่บทเรียนใช้แล้ว แต่หลีกเลี่ยง `*` `/` (รอบท 011)
- อย่าให้โจทย์บังคับใช้ `False`/`True` เป็นค่าหลัก — boolean สอนจริงในบท 007
- เฉลยทุกข้ออยู่ใน `answer/` และผ่านการรันเทียบกับตัวอย่างในโจทย์แล้ว
