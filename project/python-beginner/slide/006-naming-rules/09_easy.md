# 📒 Naming Rules — ข้อ 5: ส่วนต่างราคาสมุด

**Difficulty:** 🟢 Easy

---

## โจทย์

สมุดราคาเต็ม 60 บาท ลดไปแล้ว 15 บาท

ตั้งชื่อตัวแปรให้สื่อความหมาย แล้วคำนวณราคาที่เหลือด้วย `-` จากนั้นพิมพ์ตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
Pay: 45
```
