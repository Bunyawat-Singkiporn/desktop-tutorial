## โจทย์

โค้ดด้านล่างทำงานได้ แต่ตั้งชื่อ variable แย่มาก — **เขียนใหม่ให้ชื่อถูกต้อง** โดย Output เหมือนเดิม

```python
a = "Laptop"
b = 25000
c = 3
d = b * c

print(a)
print(b)
print(c)
print(d)
```

**Output:**
```
Laptop
25000
3
75000
```
