## โจทย์

โปรแกรมสรุปค่าขนมใช้ชื่อแย่และผิดสไตล์

```python
X = 40
Y = 25
TP = X + Y
print("Snack A:", X)
print("Snack B:", Y)
print("Total:", TP)
```

เขียนใหม่ให้ชื่อถูกกฎ snake_case และสื่อความหมาย โดย Output ต้องเหมือนเดิม

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
Snack A: 40
Snack B: 25
Total: 65
```
