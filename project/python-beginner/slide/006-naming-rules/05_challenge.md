# 🔥 Practice: Naming Rules — Question 4: Student Report

**Difficulty:** 🔴 Hard

## โจทย์

เขียนโปรแกรมแสดงรายงานนักเรียนโดยใช้ **ชื่อ variable ที่ถูกต้องทั้งหมด** ตามกฎ snake_case

**ข้อมูลที่ต้องเก็บ:**
- ชื่อนักเรียน: `"Mia"`
- ชั้นเรียน: `6` (ป.6)
- คะแนนวิชาคณิตศาสตร์: `88`
- คะแนนวิชาภาษาอังกฤษ: `92`
- คะแนนเฉลี่ย: (คณิต + อังกฤษ) / 2

**Output:**
```
=== Student Report ===
Name  : Mia
Grade : 6
Math  : 88
Eng   : 92
Avg   : 90.0
```

> **กฎเพิ่มเติม:** ห้ามใช้ชื่อ variable ที่สั้นกว่า 3 ตัวอักษร (ยกเว้น `avg`)
