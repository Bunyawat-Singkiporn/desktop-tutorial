# 📖 Naming Rules — ข้อ 1: ชื่อหนังสือในชั้น

**Difficulty:** 🟢 Easy

---

## โจทย์

ชั้นหนังสือในห้องสมุดมีโค้ดที่ใช้ชื่อสั้นเกินไป

```python
n = "Robot Tales"
print("Book:", n)
```

เขียนใหม่โดยใช้ชื่อตัวแปรที่สื่อความหมาย แล้วให้ได้ Output ตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
Book: Robot Tales
```
