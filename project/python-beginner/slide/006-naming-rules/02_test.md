## โจทย์

โค้ดด้านล่างมีชื่อ variable ที่ผิดกฎ **3 ตัว** แก้ให้ถูกต้องโดยที่ Output เหมือนเดิม

```python
FirstName = "Emma"
1score = 95
my grade = "A"

print(FirstName)
print(1score)
print(my grade)
```

**Output ที่ต้องการ:**
```
Emma
95
A
```
