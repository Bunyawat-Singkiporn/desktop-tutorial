# 🧥 Naming Rules — ข้อ 15: การ์ดสินค้าเสื้อผ้า

**Difficulty:** 🔴 Challenge

---

## โจทย์

ร้านเสื้อมีฮู้ดราคาเต็ม 790 บาท ส่วนลด 90 บาท

ตั้งชื่อให้สื่อความหมาย (อย่าลอกโปรแกรมเสื้อยืดในบทเรียนทุกตัวอักษร) คำนวณราคาสุทธิด้วย `-` แล้วพิมพ์การ์ดตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
========================
      HOODIE CARD
========================
Item     : Hoodie
List     : 790
Discount : 90
Final    : 700
========================
```

---

## 💡 Hint

ราคาสุทธิคือราคาเต็มลบส่วนลด เก็บในตัวแปรเช่น `final_price` ก่อนพิมพ์

---

## Starter Code

```python
item_name = "Hoodie"
list_price = 790
discount_amount = 90

# เขียนโค้ดตรงนี้
```
