# 🚶 Naming Rules — ข้อ 10: ส่วนต่างระยะทางเดิน

**Difficulty:** 🟡 Medium

---

## โจทย์

แอปเดินวัดได้ 3200 ก้าวตอนเช้า และ 5100 ก้าวตอนเย็น

ตั้งชื่อสื่อความหมาย หาผลต่างด้วย `-` แล้วพิมพ์ตามตัวอย่าง

---

## Input

ไม่มี (โปรแกรมนี้ไม่รับค่าจากผู้ใช้)

## Output

ดูตัวอย่าง

---

## ตัวอย่าง

**Output:**

```text
Morning: 3200
Evening: 5100
Diff: 1900
```

---

## 💡 Hint

ผลต่างคือก้าวเย็นลบก้าวเช้า เก็บในตัวแปรที่ชื่อบอกว่าเป็นผลต่าง

---

## Starter Code

```python
morning_steps = 3200
evening_steps = 5100

# เขียนโค้ดตรงนี้
```
