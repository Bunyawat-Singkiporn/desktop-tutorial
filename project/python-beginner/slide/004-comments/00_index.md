## หมายเหตุสำหรับครู

- ข้อ `02` **ไม่ซ้ำ** ตัวอย่างในบทเรียน (บทเรียนใช้ป้ายร้าน `BEST SHOP EVER` และตัวอย่างวินาทีต่อวัน)
- ทั้งบทใช้แค่ `print` + `#` — ความยากมาจาก **การจัดโครง comment ให้โค้ดอ่านง่าย** ไม่ใช่คำสั่งใหม่
- ข้อ Challenge ทั้ง 4 ข้อยังไม่มีตัวแปร/`input`/`if` — ยากตรงต้องวาง comment เป็นระบบในโปรแกรมที่ยาวขึ้น
- เฉลยทุกข้ออยู่ใน `answer/` และผ่านการรันเทียบกับตัวอย่างในโจทย์แล้ว
