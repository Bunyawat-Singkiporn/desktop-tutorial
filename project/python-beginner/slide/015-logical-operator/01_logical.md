# 🔗 Logical Operators — การรวมเงื่อนไข

---

## ทำไมต้องมี?

บางครั้งเงื่อนไขเดียวไม่พอ เราต้องรวมหลายเงื่อนไขเข้าด้วยกัน

มี 3 ตัวหลัก:

| Operator | ความหมาย |
|----------|----------|
| `and` | ทุกเงื่อนไขต้องเป็นจริง |
| `or` | จริงแค่ตัวเดียวก็พอ |
| `not` | กลับค่า (จริง → เท็จ, เท็จ → จริง) |

---

## `and` — ต้องจริงทั้งหมด

```python
age = 15
score = 80

if age >= 12 and score >= 50:
    print("Pass")
```

| age | score | ผลลัพธ์ |
|-----|-------|---------|
| 15 | 80 | ✅ `Pass` |
| 10 | 80 | ❌ ไม่แสดง |
| 15 | 30 | ❌ ไม่แสดง |

---

## `or` — จริงแค่ตัวเดียวก็พอ

```python
if score > 90 or score < 20:
    print("Special")
```

| score | ผลลัพธ์ |
|-------|---------|
| 95 | ✅ `Special` |
| 10 | ✅ `Special` |
| 50 | ❌ ไม่แสดง |

---

## `not` — กลับค่า

```python
is_raining = False

if not is_raining:
    print("Go Outside")
```

| is_raining | not is_raining | ผลลัพธ์ |
|------------|----------------|---------|
| `False` | `True` | ✅ `Go Outside` |
| `True` | `False` | ❌ ไม่แสดง |
