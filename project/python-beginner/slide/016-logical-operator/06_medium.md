# 📘 Logical — ข้อ 6: ผ่านวิชาสองส่วน

**Difficulty:** 🟡 Medium

---

## โจทย์

วิชาโครงงานต้องผ่านทั้งคะแนนนำเสนอและคะแนนรายงาน
แต่ละส่วนต้องได้ไม่ต่ำกว่า 40

เขียนโปรแกรมรับคะแนนสองส่วน แล้วออกใบสรุปผล

**เงื่อนไข:**

- นำเสนอ `>= 40` **และ** รายงาน `>= 40` → `Pass`
- ถ้าไม่ใช่ → `Fail`

---

## Input

2 บรรทัด — คะแนนนำเสนอ และคะแนนรายงาน

## Output

ใบสรุปในกรอบ แสดงคะแนนทั้งสองส่วนและผล

---

## ตัวอย่าง

**Input:**

```text
55
38
```

**Output:**

```text
========================
       PROJECT
========================
Present : 55
Report  : 38
Result  : Fail
========================
```

---

## 💡 Hint

ตัดสินผล Pass/Fail เก็บในตัวแปรก่อน แล้วค่อยพิมพ์กรอบทีเดียว

---
