# 🏨 Logical — ข้อ 13: ค่าห้องโรงแรม

**Difficulty:** 🔴 Challenge

---

## โจทย์

โรงแรมคิดค่าห้องจากราคาพื้นฐานคืนกะ 1500 บาท แล้วปรับสองอย่าง

**ส่วนลดสมาชิกค้างคืนนาน**

| เงื่อนไข | ส่วนลด |
|----------|--------|
| ค้าง `>= 3` คืน **และ** เป็นสมาชิก (`1`) | 300 |
| นอกนั้น | 0 |

**ค่าเพิ่มวันพิเศษ**

| เงื่อนไข | ค่าเพิ่ม |
|----------|----------|
| วันเป็น `weekend` **หรือ** เป็นวันหยุด (`1`) | 400 |
| นอกนั้น | 0 |

ยอดรวม = (1500 × จำนวนคืน) − ส่วนลด + ค่าเพิ่ม

เขียนโปรแกรมรับจำนวนคืน สถานะสมาชิก ประเภทวัน และสถานะวันหยุด แล้วออกใบค่าห้อง

---

## Input

4 บรรทัด — จำนวนคืน, สมาชิก (`1`/`0`), ประเภทวัน (`weekday`/`weekend`), วันหยุด (`1`/`0`)

## Output

ใบค่าห้องในกรอบ แสดงราคาพัก ส่วนลด ค่าเพิ่ม และยอดรวม

---

## ตัวอย่าง

**Input:**

```text
4
1
weekday
0
```

**Output:**

```text
============================
         HOTEL
============================
Stay     : 6000
Discount : 300
Surcharge: 0
Total    : 5700
============================
```
