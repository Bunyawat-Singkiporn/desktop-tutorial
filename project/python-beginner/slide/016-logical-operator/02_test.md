# 🎢 Logical — ข้อ 1: ขึ้นเครื่องเล่นสวนสนุก

**Difficulty:** 🟢 Easy

---

## โจทย์

เครื่องเล่นโรลเลอร์โคสเตอร์กำหนดว่าผู้เล่นต้องสูงอย่างน้อย 120 ซม.
และอายุอย่างน้อย 10 ปี จึงจะขึ้นได้

เขียนโปรแกรมรับส่วนสูงกับอายุ แล้วบอกว่าขึ้นได้หรือไม่

**เงื่อนไข:**

- ส่วนสูง `>= 120` **และ** อายุ `>= 10` → `Allowed`
- ถ้าไม่ใช่ → `Not Allowed`

---

## Input

2 บรรทัด — ส่วนสูง (จำนวนเต็ม) และอายุ (จำนวนเต็ม)

## Output

ผลการอนุญาต 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
130
12
```

**Output:**

```text
Allowed
```
