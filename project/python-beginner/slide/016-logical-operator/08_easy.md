# 🌤️ Logical — ข้อ 4: ออกไปข้างนอกไหม

**Difficulty:** 🟢 Easy

---

## โจทย์

แอปพยากรณ์อากาศแนะนำว่าควรออกไปข้างนอกเมื่อ**ไม่**ฝนตก

เขียนโปรแกรมรับสถานะฝน แล้วสร้างตัวแปร bool ก่อนตัดสินใจ

**เงื่อนไข:**

- รับ `1` แปลว่าฝนตก, `0` แปลว่าไม่ตก
- ถ้า `not is_raining` → `Go Outside`
- ถ้าไม่ใช่ → `Stay Home`

---

## Input

สถานะฝนเป็นจำนวนเต็ม 1 บรรทัด (`1` หรือ `0`)

## Output

คำแนะนำ 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
0
```

**Output:**

```text
Go Outside
```

---

## 💡 Hint

สร้างตัวแปร `is_raining` เป็น bool จากค่าที่รับมาก่อน
แล้วค่อยใช้ `not is_raining` ตามแบบในบทเรียน
