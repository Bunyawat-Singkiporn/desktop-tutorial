# 💳 Logical — ข้อ 2: ส่วนลดสมาชิกวันธรรมดา

**Difficulty:** 🟢 Easy

---

## โจทย์

ร้านหนังสือลดราคาให้เฉพาะสมาชิกที่มาซื้อในวันธรรมดา

เขียนโปรแกรมรับสถานะสมาชิกกับประเภทวัน แล้วแสดงสถานะส่วนลด

**เงื่อนไข:**

- สมาชิกเป็น `1` **และ** วันเป็น `weekday` → `Discount`
- ถ้าไม่ใช่ → `No Discount`

---

## Input

2 บรรทัด — สถานะสมาชิก (`1` = สมาชิก, `0` = ไม่ใช่) และประเภทวัน (`weekday` หรือ `weekend`)

## Output

2 บรรทัด — สถานะสมาชิก และผลการลดราคา

---

## ตัวอย่าง

**Input:**

```text
1
weekday
```

**Output:**

```text
Member : 1
Offer  : Discount
```

---

## 💡 Hint

เก็บข้อความ Offer ไว้ในตัวแปรก่อน แล้วค่อยพิมพ์สองบรรทัดทีเดียว
