# 📚 Logical — ข้อ 5: เข้าห้องสมุด

**Difficulty:** 🟢 Easy

---

## โจทย์

ห้องสมุดอนุญาตให้เข้าได้ถ้ามีบัตรสมาชิก หรืออายุอย่างน้อย 15 ปี

เขียนโปรแกรมรับสถานะบัตรกับอายุ แล้วบอกว่าเข้าได้หรือไม่

**เงื่อนไข:**

- มีบัตรเป็น `1` **หรือ** อายุ `>= 15` → `Enter`
- ถ้าไม่ใช่ → `Denied`

---

## Input

2 บรรทัด — สถานะบัตร (`1` / `0`) และอายุ (จำนวนเต็ม)

## Output

ผลการเข้าห้องสมุด 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
0
16
```

**Output:**

```text
Enter
```
