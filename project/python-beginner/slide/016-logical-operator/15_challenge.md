# 🎓 Logical — ข้อ 14: รับเข้าชมรม

**Difficulty:** 🔴 Challenge

---

## โจทย์

ชมรมหุ่นยนต์รับสมาชิกตามคะแนนสอบและคะแนนพอร์ตโฟลิโอ

เขียนโปรแกรมรับคะแนนสองส่วน แล้วออกใบผลการรับสมัคร

**เงื่อนไข:**

- คะแนนสอบ `>= 70` **และ** พอร์ตโฟลิโอ `>= 50` → `Offer`
- คะแนนสอบ `>= 90` **หรือ** พอร์ตโฟลิโอ `>= 80` → `Waitlist`
- นอกนั้น → `Reject`

---

## Input

2 บรรทัด — คะแนนสอบ และคะแนนพอร์ตโฟลิโอ

## Output

ใบผลในกรอบ แสดงคะแนนทั้งสองส่วนและผลการรับสมัคร

---

## ตัวอย่าง

**Input:**

```text
92
40
```

**Output:**

```text
========================
        CLUB
========================
Exam      : 92
Portfolio : 40
Result    : Waitlist
========================
```

---

## 💡 Hint

เรียง `if` / `elif` / `else` จากเงื่อนไขที่ต้องการรับจริงก่อน
คนที่ได้ Offer จะไม่ตกไป Waitlist เพราะ Python หยุดที่กิ่งแรกที่เป็นจริง
