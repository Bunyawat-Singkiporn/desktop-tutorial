# 💼 Logical — ข้อ 15: สลิปโบนัสพนักงาน

**Difficulty:** 🔴 Challenge

---

## โจทย์

บริษัทจ่ายเงินเดือนพื้นฐาน 15000 บาท แล้วบวกโบนัสตามผลงาน
และอาจบวกค่าตรงเวลาถ้าไม่เคยสาย

**ขั้นที่ 1 — โบนัสผลงาน**

| เงื่อนไข | โบนัส |
|----------|-------|
| ยอดขาย `>= 50000` **และ** คะแนนรีวิว `>= 4` | 4000 |
| ยอดขาย `>= 30000` **หรือ** คะแนนรีวิว `>= 5` | 2000 |
| นอกนั้น | 500 |

**ขั้นที่ 2 — ค่าตรงเวลา**

| เงื่อนไข | ค่าเพิ่ม |
|----------|----------|
| `not is_late` (ไม่เคยสาย) | 300 |
| เคยสาย | 0 |

รับสถานะสายเป็น `1` = สาย, `0` = ไม่สาย แล้วสร้างตัวแปร bool ก่อนใช้ `not`

เขียนโปรแกรมรับยอดขาย คะแนนรีวิว และสถานะสาย แล้วออกสลิป

---

## Input

3 บรรทัด — ยอดขาย, คะแนนรีวิว (จำนวนเต็ม), สถานะสาย (`1`/`0`)

## Output

สลิปในกรอบ แสดงเงินเดือน โบนัส ค่าตรงเวลา และยอดรับสุทธิ

---

## ตัวอย่าง

**Input:**

```text
55000
4
0
```

**Output:**

```text
============================
          PAYROLL
============================
Salary    : 15000
Bonus     : 4000
On Time   : 300
Net Pay   : 19300
============================
```

---

## 💡 Hint

คิดโบนัสด้วย `if` / `elif` / `else` ให้จบก่อน
แล้วสร้าง `is_late` เป็น bool จากค่าที่รับมา ค่อยใช้ `not is_late` หาค่าตรงเวลา
