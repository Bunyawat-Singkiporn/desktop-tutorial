# 📥 Parameters — ข้อ 16: บิลส่วนลดเงื่อนไข

**Difficulty:** 🔴 Challenge

---

## โจทย์

ซื้อครบ 300 ลด 50 ไม่งั้นไม่ลด

**เงื่อนไข:**

- สร้าง `pay(price)` ถ้า price >= 300 พิมพ์ `Pay: <price-50>` ไม่งั้น `Pay: <price>`
- เรียกกับ `350` และ `200`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม / เรียกฟังก์ชันในโค้ด)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Pay: 300
Pay: 200
```
