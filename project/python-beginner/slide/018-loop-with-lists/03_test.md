# 🛒 Practice: Loop with Lists — Question 2: Price Total

**Difficulty:** 🟡 Medium

---

## โจทย์

รวมราคาสินค้าทุกชิ้นใน list แล้วแสดงยอดรวม

```python
prices = [120, 350, 75, 200, 45]
```

**Output:**
```
120
350
75
200
45
Total: 790
```

---

## 💡 Hint

- ใช้ตัวแปร `total = 0` เก็บผลรวม
- แต่ละรอบ `total = total + price`
- แสดง total หลังออกจาก loop

---

```python
prices = [120, 350, 75, 200, 45]
```
