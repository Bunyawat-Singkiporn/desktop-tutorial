# 💬 กฎการเขียน Python — ข้อ 7: เครื่องหมายคำพูดซ้อนกัน

**Difficulty:** 🟡 Medium

---

## โจทย์

อยากพิมพ์ข้อความที่ **มีเครื่องหมายคำพูดอยู่ข้างใน** เช่น

```text
The sign says "Do Not Enter"
```

ถ้าใช้ `"` ทั้งข้างนอกและข้างใน Python จะสับสนว่าข้อความจบตรงไหน
ทางแก้คือใช้ `'` ครอบข้างนอก แล้วใช้ `"` ข้างใน

เขียนโปรแกรมแสดงข้อความ 2 บรรทัดตามตัวอย่าง

---

## Input

ไม่มี

## Output

ข้อความ 2 บรรทัด ที่มีเครื่องหมายคำพูดอยู่ข้างใน

---

## ตัวอย่าง

**Output:**

```text
The sign says "Do Not Enter"
Teacher said "Good job"
```

---

## 💡 Hint

ข้างนอกใช้เครื่องหมายคำพูดเดี่ยว `'` ข้างในใช้เครื่องหมายคำพูดคู่ `"`
แบบนี้ Python จะรู้ว่าข้อความจบตรงไหน
