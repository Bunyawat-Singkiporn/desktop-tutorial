## โจทย์

ครูเขียนโค้ดไว้ 4 แบบ มีแบบเดียวที่ถูกกฎทั้งหมด

```python
# แบบ A
Print("Hello")

# แบบ B
print("Hello)

# แบบ C
print("Hello")

# แบบ D
  print("Hello")
```

เขียนโปรแกรมที่ **แสดงคำตอบ** ว่าแบบไหนถูก และอีก 3 แบบผิดกฎข้อไหน

---

## Input

ไม่มี

## Output

คำตอบ 5 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
ANSWER
A : wrong - uppercase P
B : wrong - missing quote
C : correct
D : wrong - leading space
```

## 💡 Hint

ไล่ดูทีละแบบว่าผิดกฎข้อไหนใน 3 ข้อ แล้ว `print` คำตอบออกมา
