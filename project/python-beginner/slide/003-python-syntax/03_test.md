# 📐 Practice: Syntax — Question 2: Fix the Indentation

**Difficulty:** 🟡 Medium

---

## โจทย์

โค้ดด้านล่างมี IndentationError แก้ให้แสดงผลถูกต้อง

```python
  print("First line")
print("Second line")
    print("Third line")
```

**Output ที่ต้องการ:**
```
First line
Second line
Third line
```

---

## 💡 Hint

โค้ดปกติ (ที่ไม่อยู่ใน if/for) **ต้องไม่มี space** นำหน้า
