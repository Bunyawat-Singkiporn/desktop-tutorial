## หมายเหตุสำหรับครู

- บทนี้ต่างจากบท 002 ตรงที่ 002 เน้น **อ่าน error แล้วแก้** ส่วนบทนี้เน้น **ตรวจโค้ดด้วยกฎก่อนรัน**

  สอนในข้อ 07 แล้วใช้ต่อในข้อ 12 และ 14 — เด็กจะเจอปัญหานี้แน่นอนตอนพิมพ์ข้อความที่มีคำพูด
