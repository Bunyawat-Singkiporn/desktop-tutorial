# 🔀 Practice: Syntax — Question 3: Mixed Errors

**Difficulty:** 🟡 Medium

---

## โจทย์

โค้ดด้านล่างมีข้อผิดพลาด **3 ประเภทที่ต่างกัน** หาและแก้ทุกจุด

```python
Print("==========")
print("MY PROFILE"
  print("==========")
print("Name: Jordan")
```

**Output ที่ต้องการ:**
```
==========
MY PROFILE
==========
Name: Jordan
```

---

## 💡 Hint

3 ประเภทของ Error:
- `NameError` — ตัวพิมพ์ผิด
- `SyntaxError` — เครื่องหมายไม่ครบ
- `IndentationError` — ย่อหน้าเกิน
