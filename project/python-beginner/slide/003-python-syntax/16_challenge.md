## โจทย์

ครูให้โค้ด 5 ชิ้น ให้ตอบว่าแต่ละชิ้น **รันผ่านหรือไม่ผ่าน**

```python
# 1
print("A")

# 2
print('B')

# 3
Print("C")

# 4
print("D')

# 5
print ("E")
```

เขียนโปรแกรมแสดงคำตอบตามตัวอย่าง

> ชิ้นที่ 5 มีช่องว่างระหว่าง `print` กับวงเล็บ ลองคิดดูว่าผิดกฎข้อไหนหรือเปล่า

---

## Input

ไม่มี

## Output

คำตอบ 6 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
SYNTAX QUIZ RESULT
1 : OK
2 : OK
3 : FAIL
4 : FAIL
5 : OK
```

## 💡 Hint

กฎ 3 ข้อพูดถึงช่องว่าง **หน้าบรรทัด** เท่านั้น ไม่ได้ห้ามช่องว่างตรงกลางบรรทัด
และอย่าลืมว่าคำพูดต้องเปิด-ปิดด้วยชนิดเดียวกัน
