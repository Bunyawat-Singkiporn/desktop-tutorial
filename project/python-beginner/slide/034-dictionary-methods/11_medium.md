# 🔧 Dict Methods — ข้อ 11: รายงานด้วย items

**Difficulty:** 🟡 Medium

---

## โจทย์

รายงานสภาพอากาศด้วย items

กำหนด `weather = {"city": "Hua Hin", "temp": 31, "rain": "No"}`

พิมพ์แบบ `city -> Hua Hin`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
city -> Hua Hin
temp -> 31
rain -> No
```


---

## 💡 Hint

items ให้ทั้งคีย์และค่า

---

## Starter Code

```python
weather = {"city": "Hua Hin", "temp": 31, "rain": "No"}

# เขียนโค้ดตรงนี้
```
