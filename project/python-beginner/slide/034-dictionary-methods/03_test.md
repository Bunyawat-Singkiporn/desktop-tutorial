# 🔧 Dict Methods — ข้อ 3: อัปเดตหลายฟิลด์

**Difficulty:** 🟢 Easy

---

## โจทย์

อัปเดตข้อมูลติดต่อหลายฟิลด์พร้อมกัน

กำหนด `user = {"name": "Ben", "city": "Bangkok", "score": 70}`

ใช้ `.update({"city": "Phuket", "score": 85})` แล้วแสดง city และ score

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

```text
Phuket
85
```
