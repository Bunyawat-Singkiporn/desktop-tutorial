# 🔧 Dict Methods — ข้อ 9: พิมพ์คู่ด้วย items

**Difficulty:** 🟢 Easy

---

## โจทย์

พิมพ์คู่คีย์-ค่าด้วย `.items()`

กำหนด `book = {"title": "Python", "pages": 120}`

แสดงแบบ `title: Python`

---

## ตัวอย่าง

**Output:**

```text
title: Python
pages: 120
```


---

## Starter Code

```python
book = {"title": "Python", "pages": 120}

# เขียนโค้ดตรงนี้
```
