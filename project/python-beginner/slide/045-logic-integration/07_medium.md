# 🧠 Logic Integration — ข้อ 7: ชื่อที่ขึ้นต้น A

**Difficulty:** 🟡 Medium

---

## โจทย์

พิมพ์ชื่อที่ตัวอักษรแรกเป็น A

**เงื่อนไข:**

- `names = ["Ann", "Bob", "Ada", "Ken"]`
- ใช้ `name[0] == "A"` (ห้าม startswith)

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Ann
Ada
```


---

## 💡 Hint

ใช้ index 0 ไม่ใช่ startswith

---

## Starter Code

```python
names = ["Ann", "Bob", "Ada", "Ken"]

# เทียบตัวอักษรแรก
```
