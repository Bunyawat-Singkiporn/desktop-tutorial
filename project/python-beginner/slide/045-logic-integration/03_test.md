# 🧠 Logic Integration — ข้อ 3: พิมพ์เฉพาะคะแนนผ่าน

**Difficulty:** 🟢 Easy

---

## โจทย์

มีคะแนนใน list พิมพ์เฉพาะที่ >= 50

**เงื่อนไข:**

- `scores = [40, 55, 70, 30]`
- พิมพ์ค่าที่ผ่านทีละบรรทัด

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
55
70
```

```python
scores = [40, 55, 70, 30]

# พิมพ์เฉพาะที่ผ่าน
```
