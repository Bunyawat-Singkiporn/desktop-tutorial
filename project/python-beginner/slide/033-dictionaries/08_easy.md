# 📖 Dictionaries — ข้อ 8: วนพิมพ์คีย์สินค้า

**Difficulty:** 🟢 Easy

---

## โจทย์

พิมพ์ชื่อคีย์ของสินค้าทีละบรรทัด

กำหนด `product = {"id": "P01", "name": "Soap", "price": 25}`

ใช้ `for key in product:` พิมพ์คีย์

---

## ตัวอย่าง

**Output:**

```text
id
name
price
```
