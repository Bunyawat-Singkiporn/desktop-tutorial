# 📖 Dictionaries — ข้อ 10: พิมพ์คู่คีย์-ค่า

**Difficulty:** 🟡 Medium

---

## โจทย์

พิมพ์ทุกคีย์พร้อมค่า

กำหนด `pet = {"name": "Milo", "type": "Cat", "age": 2}`

ใช้ for key แล้วพิมพ์แบบ `name: Milo`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
name: Milo
type: Cat
age: 2
```


---

## 💡 Hint

ห้ามใช้ .items() ในบทนี้ — ใช้ pet[key]

---

## Starter Code

```python
pet = {"name": "Milo", "type": "Cat", "age": 2}

# เขียนโค้ดตรงนี้
```
