# 📖 Dictionaries — ข้อ 11: เช็คแล้วแสดงคะแนน

**Difficulty:** 🟡 Medium

---

## โจทย์

เช็คว่ามีคะแนนแล้วค่อยแสดง

กำหนด `student = {"name": "Ann", "score": 92}`

ถ้ามีคีย์ `score` แสดงค่าคะแนน ไม่เช่นนั้นแสดง `No score`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
92
```


---

## 💡 Hint

เช็ค in ก่อนอ่านค่า

---

## Starter Code

```python
student = {"name": "Ann", "score": 92}

# เขียนโค้ดตรงนี้
```
