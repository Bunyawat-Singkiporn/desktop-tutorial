# 📖 Dictionaries — ข้อ 16: กล่องข้อมูลพนักงาน

**Difficulty:** 🔴 Challenge

---

## โจทย์

แสดงข้อมูลพนักงานแบบมีกรอบ

กำหนด `staff = {"name": "Ada", "role": "Cashier", "id": "S12"}`

เพิ่ม `shift` เป็น `Morning` แล้วแสดงตามตัวอย่าง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

กล่องสรุป

---

## ตัวอย่าง

**Output:**

```text
====================
name: Ada
role: Cashier
id: S12
shift: Morning
====================
```


---

## 💡 Hint

เพิ่มคีย์ แล้ววนพิมพ์ในกรอบ

---

## Starter Code

```python
staff = {"name": "Ada", "role": "Cashier", "id": "S12"}

# เขียนโค้ดตรงนี้
```
