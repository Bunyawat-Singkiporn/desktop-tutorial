# 📖 Dictionaries — ข้อ 13: โปรไฟล์สัตว์เลี้ยง

**Difficulty:** 🟡 Medium

---

## โจทย์

แสดงโปรไฟล์สัตว์เลี้ยงแบบมีป้ายกำกับ

กำหนด `pet = {"name": "Lucky", "type": "Dog", "age": 4}`

แสดงตามตัวอย่าง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Name : Lucky
Type : Dog
Age  : 4
```


---

## 💡 Hint

จัดช่องว่างให้ตรงคอลัมน์

---

## Starter Code

```python
pet = {"name": "Lucky", "type": "Dog", "age": 4}

# เขียนโค้ดตรงนี้
```
