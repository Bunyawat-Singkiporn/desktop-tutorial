# ➕ Practice Dictionaries — Question 2: Add Key

**Difficulty:** 🟢 Easy

---

## โจทย์

กำหนด dict ของสินค้า เพิ่ม key `"stock"` มีค่า `50` แล้วแสดงทุก key

```python
product = {"name": "Notebook", "price": 45}
```

**Output:**
```
name
price
stock
```

---

## 💡 Hint

- เพิ่ม key ใหม่: `product["stock"] = 50`
- แสดง key ทั้งหมด: `for key in product:`
