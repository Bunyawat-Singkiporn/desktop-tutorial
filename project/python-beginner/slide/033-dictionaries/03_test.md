# 📖 Dictionaries — ข้อ 3: เพิ่มคะแนนเข้าโปรไฟล์

**Difficulty:** 🟢 Easy

---

## โจทย์

โปรไฟล์นักเรียนยังไม่มีคะแนน

กำหนด `student = {"name": "Pim", "age": 14}`

เพิ่มคีย์ `score` ค่า `88` แล้วแสดงค่าคะแนน

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
Score: 88
```


---

## Starter Code

```python
student = {"name": "Pim", "age": 14}

# เขียนโค้ดตรงนี้
```
