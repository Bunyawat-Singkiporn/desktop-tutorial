# 📖 Dictionaries — ข้อ 2: อ่านชื่อจากสมุดโทรศัพท์

**Difficulty:** 🟢 Easy

---

## โจทย์

เปิดสมุดโทรศัพท์แล้วอ่านชื่อเจ้าของเบอร์

กำหนด `contact = {"name": "Mew", "phone": "081-111-2222"}`

แสดง `Name: Mew`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
Name: Mew
```


---

## Starter Code

```python
contact = {"name": "Mew", "phone": "081-111-2222"}

# เขียนโค้ดตรงนี้
```
