# 📞 Practice Dictionaries — Question 3: Contact Card

**Difficulty:** 🟡 Medium

---

## โจทย์

กำหนดข้อมูลติดต่อ แสดงทุก key-value แบบมีรูปแบบสวยงาม

```python
contact = {
    "name": "Bob Smith",
    "phone": "081-234-5678",
    "city": "Bangkok",
    "email": "bob@email.com"
}
```

**Output:**
```
=== Contact Info ===
name: Bob Smith
phone: 081-234-5678
city: Bangkok
email: bob@email.com
```

---

## 💡 Hint

ใช้ `for key in contact:` แล้ว print `key` และ `contact[key]`
