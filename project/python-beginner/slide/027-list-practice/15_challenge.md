# 🏋️ List Practice — ข้อ 15: ผลสอบแบบมีเลขที่

**Difficulty:** 🔴 Challenge

---

## โจทย์

รายงานผลสอบพร้อมเลขที่

กำหนด `scores = [72, 40, 88, 55]`

ใช้ range(len) แสดง `1) 72 Pass` หรือ Fail ถ้า < 50 แล้วปิดท้ายจำนวนผ่าน

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

รายงาน + สรุป

---

## ตัวอย่าง

**Output:**

```text
1) 72 Pass
2) 40 Fail
3) 88 Pass
4) 55 Pass
Passed: 3
```
