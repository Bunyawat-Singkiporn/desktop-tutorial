# 🏋️ List Practice — ข้อ 6: กรองชื่อสั้น

**Difficulty:** 🟡 Medium

---

## โจทย์

อยากได้เฉพาะชื่อที่ยาวไม่เกิน 3 ตัวอักษร

กำหนด `names = ["Ann", "Bobby", "Cy", "Diana", "Ed"]`

สร้าง `short` แล้วแสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Ann', 'Cy', 'Ed']
```


---

## 💡 Hint

ใช้ len(name) เป็นเงื่อนไข

---

## Starter Code

```python
names = ["Ann", "Bobby", "Cy", "Diana", "Ed"]

# เขียนโค้ดตรงนี้
```
