# 📋 Practice List — Question 3: Numbered To-Do List

**Difficulty:** 🟡 Medium

---

## โจทย์

กำหนดรายการ to-do แสดงพร้อมหมายเลขลำดับ

```python
todos = ["Buy groceries", "Do homework", "Clean room", "Call mom"]
```

**Output:**
```
=== To-Do List ===
1. Buy groceries
2. Do homework
3. Clean room
4. Call mom
```

---

## 💡 Hint

ใช้ `range(len(todos))` เพื่อได้ index แล้วบวก 1 สำหรับลำดับ
