# 🔁 loop-review — ข้อ 6: รวมยอดบิลจนจบ

**Difficulty:** 🟡 Medium

---

## โจทย์

แคชเชียร์รับยอดสินค้าทีละบรรทัด
เมื่อรับข้อความ `done` ให้หยุด แล้วพิมพ์ยอดรวมเป็นจำนวนเต็มของยอดที่รับมาก่อนหน้า
(ยอดแต่ละรายการเป็นจำนวนเต็ม)

---

## Input

ยอดเป็นตัวเลขทีละบรรทัด จบด้วยคำว่า done

## Output

บรรทัดเดียว Total: <ยอดรวม>

---

## ตัวอย่าง

**Input:**

```text
50
70
done
```

**Output:**

```text
Total: 120
```


---

## 💡 Hint

แปลงเป็น int หลังเช็คว่ายังไม่ใช่ done

---

## Starter Code

```python
total = 0

# while True รับยอดจน done
```
