# 🔁 loop-review — ข้อ 8: พิมพ์คู่ถึง n

**Difficulty:** 🟢 Easy

---

## โจทย์

รับ `n` แล้วพิมพ์เลขคู่ตั้งแต่ 2 ถึง `n` inclusive ด้วย `range` แบบมี step

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

เลขคู่ทีละบรรทัด

---

## ตัวอย่าง

**Input:**

```text
10
```

**Output:**

```text
2
4
6
8
10
```


---

## Starter Code

```python
n = int(input())

# พิมพ์เลขคู่
```
