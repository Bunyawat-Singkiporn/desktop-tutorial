# 🔁 loop-review — ข้อ 14: รับคะแนนจน -1

**Difficulty:** 🔴 Challenge

---

## โจทย์

รับคะแนนทีละบรรทัดจนเจอ `-1` แล้วหยุด
แสดงจำนวนครั้งที่รับ (ไม่นับ -1) และผลรวม

---

## Input

คะแนนทีละบรรทัด จบด้วย -1

## Output

สองบรรทัด Count และ Total

---

## ตัวอย่าง

**Input:**

```text
80
70
90
-1
```

**Output:**

```text
Count: 3
Total: 240
```


---

## 💡 Hint

เช็ค -1 ก่อนนับและก่อนบวก

---

## Starter Code

```python
count = 0
total = 0

# while True จน -1
```
