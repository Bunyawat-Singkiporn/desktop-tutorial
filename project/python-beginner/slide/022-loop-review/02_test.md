# 🔁 loop-review — ข้อ 2: รวมแต้มเกม

**Difficulty:** 🟢 Easy

---

## โจทย์

เกมให้แต้มรอบละเท่ากับหมายเลขรอบตั้งแต่ 1 ถึง `n`
รับ `n` แล้วรวมแต้มทั้งหมดด้วย `for` และ `+=`

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

บรรทัดเดียว Total Points: <ผลรวม>

---

## ตัวอย่าง

**Input:**

```text
5
```

**Output:**

```text
Total Points: 15
```
