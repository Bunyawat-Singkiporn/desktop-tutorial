# 🔁 loop-review — ข้อ 16: กรองออเดอร์บวก

**Difficulty:** 🔴 Challenge

---

## โจทย์

ยอดออเดอร์ `[50, -10, 30, 0, 20]`
- ข้ามค่าที่ `<= 0` ด้วย `continue`
- รวมเฉพาะยอดบวก และนับจำนวนออเดอร์ที่นับได้
แสดง Count และ Total

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

สองบรรทัด Count และ Total

---

## ตัวอย่าง

**Output:**

```text
Count: 3
Total: 100
```


---

## 💡 Hint

continue ก่อน แล้วค่อยนับและบวก

---

## Starter Code

```python
orders = [50, -10, 30, 0, 20]
count = 0
total = 0

# กรองแล้วสรุป
```
