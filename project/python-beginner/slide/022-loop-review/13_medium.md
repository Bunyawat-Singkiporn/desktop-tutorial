# 🔁 loop-review — ข้อ 13: รวมเฉพาะเลขคี่

**Difficulty:** 🟡 Medium

---

## โจทย์

รับ `n` แล้วรวมเฉพาะเลขคี่ตั้งแต่ 1 ถึง `n`
เลขคู่ให้ `continue` ข้าม

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

บรรทัดเดียว Odd Total: <ผลรวม>

---

## ตัวอย่าง

**Input:**

```text
5
```

**Output:**

```text
Odd Total: 9
```


---

## 💡 Hint

ข้ามคู่ด้วย continue แล้วค่อยบวกคี่

---

## Starter Code

```python
n = int(input())
total = 0

# รวมเลขคี่
```
