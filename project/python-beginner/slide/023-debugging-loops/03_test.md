# 🐛 debugging-loops — ข้อ 3: แก้ while นับลูกค้า

**Difficulty:** 🟢 Easy

---

## โจทย์

ต้องการนับลูกค้าจาก 1 ถึง 4 แต่ยังไม่อัปเดต `count` ในลูป
เติมบรรทัดอัปเดตให้ถูกต้อง

---

## Input

ไม่มี (แก้โค้ดที่ให้มา)

## Output

เลข 1 ถึง 4

---

## ตัวอย่าง

**Output:**

```text
1
2
3
4
```


---

## 💡 Hint

ต้องเปลี่ยนค่า count ในทุกๆ รอบ

---

## Starter Code

```python
count = 1
while count <= 4:
    print(count)
    # เติมบรรทัดอัปเดตตรงนี้
```
