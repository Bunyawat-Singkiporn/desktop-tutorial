# 🐛 debugging-loops — ข้อ 2: แก้ range นับคะแนน

**Difficulty:** 🟢 Easy

---

## โจทย์

โปรแกรมต้องการพิมพ์คะแนนโบนัส `1` ถึง `6` แต่ตอนนี้ได้แค่ถึง `5`
แก้ `range` ให้ถูกต้อง

---

## Input

ไม่มี (แก้โค้ดที่ให้มา)

## Output

เลข 1 ถึง 6 ทีละบรรทัด

---

## ตัวอย่าง

**Output:**

```text
1
2
3
4
5
6
```


---

## 💡 Hint

range หยุดก่อนค่าสุดท้าย

---

## Starter Code

```python
for i in range(1, 6):  # ← แก้บรรทัดนี้
    print(i)
```
