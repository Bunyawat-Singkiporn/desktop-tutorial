## Phase 1 Checklist

### 🔹 พื้นฐาน (Lessons 001–024)
- [ ] อธิบาย Python ได้ว่าคืออะไร
- [ ] สร้างและใช้งาน variables ได้
- [ ] รู้ชนิดข้อมูล: int, float, str, bool
- [ ] รับ input และแสดง output ได้
- [ ] ใช้ if/elif/else ได้
- [ ] ใช้ for loop และ while loop ได้
- [ ] เข้าใจ nested loops

### 🔹 Collections (Lessons 025–036)
- [ ] สร้างและใช้ List ได้
- [ ] ใช้ append, remove, sort ได้
- [ ] เข้าใจความต่าง List vs Tuple vs Set
- [ ] สร้างและใช้ Dictionary ได้
- [ ] loop ผ่าน dict ด้วย .items() ได้

### 🔹 Functions (Lessons 037–040)
- [ ] สร้าง function ด้วย def ได้
- [ ] ส่ง parameters เข้า function ได้
- [ ] ใช้ return และเก็บผลลัพธ์ได้
- [ ] รวม function กับ list/dict ได้

### 🔹 Advanced (Lessons 041–043)
- [ ] เข้าใจ local vs global scope
- [ ] บอกได้ว่า bug เป็นประเภทไหน
- [ ] เขียนโค้ดอ่านง่าย ตั้งชื่อดี
