# 🚀 Transition Prep — เตรียมพร้อมสู่ Phase 2

---

## Phase 1 → Phase 2

```
Phase 1: พื้นฐาน Python
    ↓
    Variables, Conditions, Loops
    Collections (List, Dict, ...)
    Functions
    ↓
Phase 2: Python ขั้นสูง
    ↓
    Object-Oriented Programming
    File I/O
    Modules & Libraries
    Error Handling
```

---

## Phase 1 เชื่อมกับ Phase 2 อย่างไร?

| Phase 1 | นำไปใช้ใน Phase 2 |
|---------|------------------|
| Functions | Methods ใน Class (OOP) |
| Dictionaries | JSON data, API responses |
| Lists | Reading lines from files |
| Loops | Processing large datasets |
| Debugging | Error Handling (try/except) |

---

## สิ่งที่จะได้เรียนใน Phase 2

### OOP (Object-Oriented Programming)
```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score
```

### File I/O
```python
with open("data.txt", "r") as f:
    content = f.read()
```

### Modules
```python
import math
import random
```

---

## พร้อมหรือยัง?

ตรวจสอบตัวเองก่อนเริ่ม Phase 2:
- เข้าใจ function และ return ได้
- ใช้ list และ dict ได้คล่อง
- แก้ bug เบื้องต้นได้
- อ่านโค้ดที่คนอื่นเขียนได้
