# 🚀 Transition Prep — ข้อ 12: ผสม list+if

**Difficulty:** 🟡 Medium

---

## โจทย์

จาก `[2, 5, 8, 1]` พิมพ์เฉพาะเลขคู่

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
2
8
```


---

## 💡 Hint

ใช้ %

---

## Starter Code

```python
nums = [2, 5, 8, 1]
for n in nums:
    if n % 2 == 0:
        print(n)
```
