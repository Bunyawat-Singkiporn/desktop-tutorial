# 🚀 Transition Prep — ข้อ 11: while นับ

**Difficulty:** 🟡 Medium

---

## โจทย์

เริ่ม c = 1 ขณะ c <= 3 พิมพ์ c แล้วเพิ่ม 1

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
1
2
3
```


---

## 💡 Hint

อย่าลืมเพิ่ม c

---

## Starter Code

```python
c = 1
while c <= 3:
    print(c)
    c += 1
```
