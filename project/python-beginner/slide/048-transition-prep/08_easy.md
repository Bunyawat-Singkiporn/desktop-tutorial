# 🚀 Transition Prep — ข้อ 8: if ผ่านเกณฑ์

**Difficulty:** 🟢 Easy

---

## โจทย์

รับคะแนนความพร้อม ถ้า >= 70 พิมพ์ `Ready` ไม่งั้น `Review`

---

## Input

ดูตัวอย่าง

## Output

1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
80
```

**Output:**

```text
Ready
```


---

## Starter Code

```python
score = int(input())
if score >= 70:
    print("Ready")
else:
    print("Review")
```
