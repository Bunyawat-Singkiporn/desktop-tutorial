## โจทย์

สร้าง `square(n)` คืน n*n แล้วพิมพ์ผลของ 6

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

1 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
36
```


---

## Starter Code

```python
def square(n):
    return n * n

print(square(6))
```
