# 🚀 Transition Prep — ข้อ 15: เช็กความพร้อมฟังก์ชัน

**Difficulty:** 🔴 Challenge

---

## โจทย์

`double(x)` คืน x*2 และ `add_five(x)` คืน x+5

**เงื่อนไข:**

- พิมพ์ `add_five(double(4))`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

1 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
13
```


---

## 💡 Hint

ประกอบฟังก์ชัน

---

## Starter Code

```python
def double(x):
    return x * 2

def add_five(x):
    return x + 5

print(add_five(double(4)))
```
