# Even / Odd

## เลขคู่และเลขคี่

เราสามารถตรวจสอบได้ด้วย %

เครื่องหมาย %

เรียกว่า Modulo

ใช้หา "เศษจากการหาร"

ตัวอย่าง

7 หาร 2

เหลือเศษ 1

ดังนั้น

7 % 2 = 1

ตัวอย่าง

10 หาร 2

เหลือเศษ 0

ดังนั้น

10 % 2 = 0

ถ้า

number % 2 == 0

แปลว่าเป็นเลขคู่

ถ้า

number % 2 != 0

แปลว่าเป็นเลขคี่

ตัวอย่างโปรแกรม

```python
number = int(input())

if number % 2 == 0:
    print("Even")
else:
    print("Odd")
```

ตัวอย่าง

Input

8

Output

Even

Input

7

Output

Odd
