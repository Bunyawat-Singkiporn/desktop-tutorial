# 🔧 Practice: Environment — Question 2: Fix Three Errors

**Difficulty:** 🟡 Medium

---

## โจทย์

โค้ดด้านล่างมีข้อผิดพลาด **3 จุด** แก้ให้รันได้และแสดงผลถูกต้อง

```python
Print("Line 1: Hello")
print("Line 2: World"
print(Line 3: Done")
```

**Output ที่ต้องการ:**
```
Line 1: Hello
Line 2: World
Line 3: Done
```

---

## 💡 Hint

มองหา:
1. ตัวพิมพ์ผิด (P ใหญ่)
2. วงเล็บไม่ปิด
3. เครื่องหมาย `"` ขาด
