# 🔀 รันโปรแกรมและอ่าน Error — ข้อ 10: รันผ่านแต่ลำดับผิด

**Difficulty:** 🟡 Medium

---

## โจทย์

โปรแกรมนี้ **รันผ่านไม่มี error เลย** แต่ผลลัพธ์ไม่ถูกต้อง เพราะลำดับบรรทัดสลับกัน

```python
print("3. Serve hot")
print("Instant Noodle")
print("1. Boil water")
print("2. Wait 3 minutes")
```

เขียนใหม่ให้ได้ผลลัพธ์ตามลำดับที่ถูกต้อง

---

## Input

ไม่มี

## Output

ขั้นตอน 4 บรรทัด เรียงลำดับถูกต้อง

---

## ตัวอย่าง

**Output:**

```text
Instant Noodle
1. Boil water
2. Wait 3 minutes
3. Serve hot
```

---

## 💡 Hint

Python ทำงาน **จากบนลงล่าง** ทีละบรรทัดเสมอ บรรทัดไหนอยู่ก่อนก็แสดงก่อน
บั๊กแบบนี้อันตรายกว่า error เพราะโปรแกรมไม่เตือนอะไรเลย
