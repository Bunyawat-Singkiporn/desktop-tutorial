# 🗂️ รันโปรแกรมและอ่าน Error — ข้อ 13: จับคู่ error กับสาเหตุ

**Difficulty:** 🔴 Challenge

---

## โจทย์

ครูให้โค้ด 3 ชิ้น แต่ละชิ้นพังคนละแบบ

```python
# ชิ้น A
print("Hello"

# ชิ้น B
Print("Hello")

# ชิ้น C
    print("Hello")
```

เขียนโปรแกรมที่ **แสดงคำตอบ** ว่าโค้ดแต่ละชิ้นจะขึ้น error ชนิดใด
โดยแสดงผลตามรูปแบบในตัวอย่าง

> ข้อนี้ไม่ได้ให้แก้โค้ด แต่ให้ **ตอบว่าแต่ละชิ้นพังเพราะอะไร** ด้วยการ `print` คำตอบออกมา

---

## Input

ไม่มี

## Output

คำตอบ 3 บรรทัด พร้อมหัวเรื่อง

---

## ตัวอย่าง

**Output:**

```text
ERROR TYPES
A : SyntaxError
B : NameError
C : IndentationError
```

---

## 💡 Hint

ทบทวนว่า error แต่ละชนิดเกิดจากอะไร
วงเล็บ/คำพูดไม่ครบคู่ · ชื่อที่ Python ไม่รู้จัก · ช่องว่างหน้าบรรทัดที่ไม่ควรมี
