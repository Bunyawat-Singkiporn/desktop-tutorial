# ✅ รันโปรแกรมและอ่าน Error — ข้อ 15: เช็กลิสต์ล่าบั๊กของตัวเอง

**Difficulty:** 🔴 Challenge

---

## โจทย์

หลังจากแก้บั๊กมาทั้งบท ถึงเวลาทำ **เช็กลิสต์ส่วนตัว** ไว้ใช้ตอนโปรแกรมพัง

เขียนโปรแกรมแสดงเช็กลิสต์ 5 ข้อในกรอบ ตามตัวอย่าง

> เนื้อหาในเช็กลิสต์เปลี่ยนเป็นภาษาของตัวเองได้ แต่ตอนส่งให้ทำตามตัวอย่างก่อน
> เพื่อให้ผลลัพธ์ตรงกับเฉลย

---

## Input

ไม่มี

## Output

เช็กลิสต์ในกรอบ 5 ข้อ

---

## ตัวอย่าง

**Output:**

```text
*****************************
*   DEBUG CHECKLIST         *
*****************************
* 1 Read the last line      *
* 2 Find the line number    *
* 3 Check quotes and ()     *
* 4 Check lowercase print   *
* 5 Check leading spaces    *
*****************************
```

---

## 💡 Hint

ข้อนี้ไม่มีบั๊กให้แก้ แต่ยากตรงการทำให้ `*` ด้านขวาตรงกันทุกบรรทัด
เริ่มจากบรรทัดกรอบบนสุด แล้วใช้เป็นไม้บรรทัด
