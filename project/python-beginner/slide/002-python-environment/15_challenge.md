## โจทย์

ป้ายเมนูร้านก๋วยเตี๋ยวนี้พังหนักมาก มีทั้งจุดที่รันไม่ได้ และบรรทัดที่สลับที่กัน

> โค้ดข้างล่างนี้ **รันไม่ได้** หาที่ผิดแล้วเขียนใหม่ให้ถูกต้อง เพื่อให้ได้ผลลัพธ์ตามตัวอย่าง (ดูลำดับในตัวอย่างให้ดี)

```python
print("Noodle Shop")
print("=====================")
  Print("Beef Noodle     55")
print("Pork Noodle     45")
print("=====================")
print("Open 09:00 - 20:00)
```

---

## Input

ไม่มี

## Output

ป้ายเมนู 6 บรรทัด เรียงลำดับถูกต้อง

---

## ตัวอย่าง

**Output:**

```text
=====================
Noodle Shop
=====================
Pork Noodle     45
Beef Noodle     55
Open 09:00 - 20:00
```
