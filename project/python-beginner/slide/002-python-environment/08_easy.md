---

## โจทย์

ป้ายห้องสมุดรันไม่ออก คราวนี้ไม่ใช่เครื่องหมายคำพูด

> โค้ดข้างล่างนี้ **รันไม่ได้** หาที่ผิดแล้วเขียนใหม่ให้ถูกต้อง เพื่อให้ได้ผลลัพธ์ตามตัวอย่าง

```python
print("Library Rules"
print("No food allowed")
print("Keep quiet")
```

---

## Input

ไม่มี

## Output

ข้อความ 3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Library Rules
No food allowed
Keep quiet
```

## 💡 Hint

เครื่องหมายคำพูดครบแล้ว ลองดูของอีกคู่หนึ่งที่ต้องมาเป็นคู่เหมือนกัน
