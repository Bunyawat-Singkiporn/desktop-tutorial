# 🔧 Practice: Environment — Question 3: Fix Four Errors

**Difficulty:** 🟡 Medium

---

## โจทย์

โค้ดด้านล่างมีข้อผิดพลาด **4 จุด** หาและแก้ทุกจุดให้รันได้

```python
PRINT("Welcome!")
print("Today is Monday"
print("Have a great day!)
  print("Goodbye!")
```

**Output ที่ต้องการ:**
```
Welcome!
Today is Monday
Have a great day!
Goodbye!
```

---

## 💡 Hint

มองหา:
1. ตัวพิมพ์ผิด
2. วงเล็บ `)` ที่หายไป
3. เครื่องหมาย `"` ที่หายไป
4. Indentation ที่ไม่ควรมี
