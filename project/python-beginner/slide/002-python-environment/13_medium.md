**Difficulty:** 🟡 Medium

---

## โจทย์

ใบรายงานผลการเรียนนี้มีจุดผิดกระจายอยู่หลายที่

> โค้ดข้างล่างนี้ **รันไม่ได้** หาที่ผิดแล้วเขียนใหม่ให้ถูกต้อง เพื่อให้ได้ผลลัพธ์ตามตัวอย่าง

```python
print("======================")
Print("    REPORT CARD")
print("======================")
   print("Name  : Beam")
print("Math  : 82")
print("English : 75)
print("======================")
```

---

## Input

ไม่มี

## Output

ใบรายงานผลในกรอบ 7 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
======================
    REPORT CARD
======================
Name  : Beam
Math  : 82
English : 75
======================
```

## 💡 Hint

ไล่ทีละบรรทัดจากบนลงล่าง อย่าข้าม มีทั้งเรื่องตัวพิมพ์ ช่องว่างหน้าบรรทัด และเครื่องหมายคำพูด
