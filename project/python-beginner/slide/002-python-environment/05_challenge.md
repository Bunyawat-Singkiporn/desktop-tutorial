## 💡 Hint

5 ประเภท Error ที่ต้องหา:
1. ชื่อฟังก์ชันสะกดผิด (ไม่ใช่แค่ตัวพิมพ์)
2. ตัวพิมพ์ผิด (ตัวใหญ่)
3. วงเล็บ `)` ขาด
4. เครื่องหมาย `"` ขาด
5. Indentation เกิน
