## โจทย์

โปรแกรมตารางแข่งกีฬานี้มีจุดผิด **4 จุด** และไม่ซ้ำชนิดกันเลย

> โค้ดข้างล่างนี้ **รันไม่ได้** หาที่ผิดแล้วเขียนใหม่ให้ถูกต้อง เพื่อให้ได้ผลลัพธ์ตามตัวอย่าง

```python
print("+--------------------+"
print("|   MATCH SCHEDULE   |")
PRINT("+--------------------+")
  print("| 09:00  A  vs  B    |")
print("| 10:30  C  vs  D    |)
print("+--------------------+")
```

---

## Input

ไม่มี

## Output

ตารางแข่งในกรอบ 6 บรรทัด
