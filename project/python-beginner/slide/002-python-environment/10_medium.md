# ❝ รันโปรแกรมและอ่าน Error — ข้อ 8: เครื่องหมายคำพูดผิดชนิด

**Difficulty:** 🟡 Medium

---

## โจทย์

เด็กคนหนึ่งพิมพ์โค้ดในโปรแกรม Word แล้วก๊อปมาวางใน VS Code ปรากฏว่ารันไม่ได้
ทั้งที่มองยังไงก็เหมือนถูกทุกอย่าง

> โค้ดข้างล่างนี้ **รันไม่ได้** หาที่ผิดแล้วเขียนใหม่ให้ถูกต้อง เพื่อให้ได้ผลลัพธ์ตามตัวอย่าง

```python
print(“Art Exhibition”)
print("Room 105")
```

> สังเกตเครื่องหมายคำพูดบรรทัดแรกให้ดีๆ มันไม่ใช่ตัวเดียวกับบรรทัดที่สอง

---

## Input

ไม่มี

## Output

ข้อความ 2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Art Exhibition
Room 105
```

---

## 💡 Hint

Python รู้จักแค่ `"` กับ `'` ตรงๆ เท่านั้น เครื่องหมายคำพูดโค้งสวยๆ จากโปรแกรมเอกสารใช้ไม่ได้
นี่คือเหตุผลที่ต้องพิมพ์โค้ดในโปรแกรมแก้โค้ดจริงๆ
