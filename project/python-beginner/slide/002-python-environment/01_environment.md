# 🖥️ Python Environment — เริ่มต้นเขียนโค้ด

---

## Editor คืออะไร?

**Editor** คือโปรแกรมสำหรับเขียนโค้ด

เหมือน **สมุดโน้ต** 📒 แต่สำหรับโปรแกรมเมอร์ มีระบบช่วยเขียนโค้ดให้ง่ายขึ้น

| Editor | ลักษณะ |
|--------|--------|
| **VS Code** | ใช้กับทุกภาษา ✅ (แนะนำ) |
| PyCharm | Python โดยเฉพาะ |
| IDLE | มาพร้อมกับ Python |

---

## วิธีรันโค้ด Python

### วิธีที่ 1: ปุ่ม ▶ ใน VS Code
1. เปิดไฟล์ `.py`
2. กดปุ่ม **▶ Run** มุมขวาบน
3. ดูผลลัพธ์ใน **Terminal** ด้านล่าง

### วิธีที่ 2: Terminal
```bash
python hello.py
```

## Error Message คืออะไร?

เมื่อโค้ดมีข้อผิดพลาด Python จะแจ้งเตือน — เรียกว่า **Error**

> อย่ากลัว Error! มันคือ **ข้อความช่วยเหลือ** ที่บอกว่าต้องแก้ตรงไหน 🆘

```
SyntaxError: '(' was never closed
  File "hello.py", line 1
    print("Hello"
         ^
```

| ส่วนของ Error | ความหมาย |
|-------------|---------|
| `SyntaxError` | ประเภทของข้อผิดพลาด |
| `'(' was never closed` | รายละเอียด: วงเล็บไม่ปิด |
| `line 1` | บรรทัดที่มีปัญหา |

---

## Error ที่พบบ่อย

| Error | สาเหตุ | วิธีแก้ |
|-------|--------|--------|
| `SyntaxError` | เขียน code ผิดรูปแบบ | ตรวจวงเล็บ / เครื่องหมาย |
| `NameError` | ใช้ชื่อที่ไม่มีอยู่ | ตรวจการสะกด (print ไม่ใช่ Print) |
| `IndentationError` | ย่อหน้าไม่ถูกต้อง | ลบ space ที่ขึ้นต้นบรรทัด |

## ตัวอย่าง: โค้ดที่พัง vs โค้ดที่ถูก

❌ **ผิด:**
```python
print("Hello"
```
```
SyntaxError: '(' was never closed
```

✅ **ถูก:**
```python
print("Hello")
```
```
Hello
```

---

## เคล็ดลับการแก้ Error

1. **อ่าน Error** อย่างละเอียด — มันบอกบรรทัดที่มีปัญหา
2. **ตรวจวงเล็บ** — ทุก `(` ต้องมี `)` ปิด
3. **ตรวจเครื่องหมายคำพูด** — ทุก `"` ต้องมี `"` ปิด
4. **ลอง Google** Error message — มีคนเจอปัญหาเดียวกันแน่นอน!
