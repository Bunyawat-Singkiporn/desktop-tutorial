## หมายเหตุสำหรับครู

- แก่นของบทนี้คือ **อ่าน error ให้เป็นแล้วแก้ได้** ไม่ใช่การเขียนโค้ดใหม่
- error 3 ชนิดที่ต้องแยกออก: `SyntaxError` (วงเล็บ/คำพูดไม่ครบคู่) ·
  `NameError` (ชื่อที่ Python ไม่รู้จัก เช่น `Print`) · `IndentationError` (ช่องว่างหน้าบรรทัด)
- ข้อ 12 สำคัญมาก: โปรแกรม**รันผ่านแต่ผลลัพธ์ผิด** — ให้เด็กเห็นว่า "ไม่ error" ไม่ได้แปลว่า "ถูก"
- ข้อ 10 เป็นกับดักที่เจอจริงบ่อยมาก (ก๊อปโค้ดจาก Word/เว็บแล้วได้เครื่องหมายคำพูดโค้ง)
- ข้อ 14 ไม่ต้องแก้โค้ด แต่ต้อง **ทำนาย** ชื่อ error ให้ถูก ใช้วัดความเข้าใจได้ดีกว่าการแก้โค้ด
- ย้ำวิธีทำงาน: แก้ทีละจุด แล้วรันใหม่ทุกครั้ง
