## โจทย์

โปรแกรมนี้แก้ที่เดียวยังไม่พอ รันแล้วเจอ error ซ้ำอีกรอบ

> โค้ดข้างล่างนี้ **รันไม่ได้** หาที่ผิดแล้วเขียนใหม่ให้ถูกต้อง เพื่อให้ได้ผลลัพธ์ตามตัวอย่าง

```python
print("Canteen Menu")
Print("Rice with chicken  40")
print("Noodle soup  35)
```

---

## Input

ไม่มี

## Output

เมนู 3 บรรทัด

```text

```
