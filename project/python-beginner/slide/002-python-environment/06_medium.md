# Practice: Environment — Medium A: จับคู่ Error

**Difficulty:** 🟡 Medium

---

## โจทย์

เขียนคำตอบเป็นข้อความ (print) ตามตาราง — แต่ละบรรทัดเป็นชนิด Error ที่ถูกต้อง

| สาเหตุ | Error |
|--------|-------|
| พิมพ์ `Print` ตัวใหญ่ | NameError |
| ลืมปิด `)` | SyntaxError |
| มี space นำหน้าโดยไม่จำเป็น | IndentationError |

**Output:**
```
NameError
SyntaxError
IndentationError
```
