# for Loop

Loop คือการทำงานซ้ำ

แทนที่จะเขียน

```python
print("Hello")
print("Hello")
print("Hello")
print("Hello")
print("Hello")
```

เราสามารถเขียน

```python
for i in range(5):
    print("Hello")
```

ได้

----------------

range(5)

จะสร้าง

0
1
2
3
4

รวมทั้งหมด 5 รอบ

ตัวอย่าง

```python
for i in range(5):
    print(i)
```

ผลลัพธ์

0
