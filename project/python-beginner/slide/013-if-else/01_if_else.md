# 🔀 if / else — เงื่อนไขสองทาง

---

## if คืออะไร?

`if` ใช้สำหรับ **ตรวจสอบเงื่อนไข**

> ถ้าเงื่อนไขเป็น **จริง (True)** → ทำคำสั่ง
> ถ้าเงื่อนไขเป็น **เท็จ (False)** → ข้ามไป

---

## รูปแบบ if

```python
if เงื่อนไข:
    # คำสั่งที่ทำเมื่อเงื่อนไขเป็นจริง
```

---

## รูปแบบ if / else

```python
if เงื่อนไข:
    # ทำเมื่อเงื่อนไขเป็นจริง
else:
    # ทำเมื่อเงื่อนไขเป็นเท็จ
```

> `else` คือ "ถ้าไม่ใช่กรณีข้างบน"

---

## ตัวอย่างโปรแกรม

```python
score = int(input())

if score >= 50:
    print("Pass")
else:
    print("Fail")
```

---

## ตัวอย่าง Input / Output

| Input | Output |
|-------|--------|
| `80` | `Pass` |
| `45` | `Fail` |
| `50` | `Pass` |

---

## ข้อควรระวัง

- ต้องมี `:` ต่อท้าย `if` และ `else`
- คำสั่งภายใน **ต้อง indent** (เว้น 4 ช่องว่าง)
- `else` ไม่มีเงื่อนไข — รับทุกกรณีที่เหลือ
