# 🔋 if/else — ข้อ 2: เตือนแบตเตอรี่ต่ำ

**Difficulty:** 🟢 Easy

---

## โจทย์

โทรศัพท์จะขึ้นเตือนเมื่อแบตเตอรี่เหลือน้อยกว่า 20%

เขียนโปรแกรมรับเปอร์เซ็นต์แบตเตอรี่ แล้วแสดงสถานะออกมา

**เงื่อนไข:**

- แบตเตอรี่ `< 20` → `Low Battery`
- ตั้งแต่ 20 ขึ้นไป → `Battery OK`

---

## Input

เปอร์เซ็นต์แบตเตอรี่เป็นจำนวนเต็ม 1 บรรทัด

## Output

2 บรรทัด — เปอร์เซ็นต์ และสถานะ

---

## ตัวอย่าง

**Input:**

```text
15
```

**Output:**

```text
Battery : 15%
Status  : Low Battery
```

---

## 💡 Hint

เก็บข้อความสถานะไว้ในตัวแปรก่อน แล้วค่อยแสดงผลทั้งสองบรรทัดทีเดียว
จะได้ไม่ต้องเขียน `print` ซ้ำในทั้งสองทาง
