# ☕ if/else — ข้อ 14: สั่งกาแฟ

**Difficulty:** 🔴 Challenge

---

## โจทย์

ร้านกาแฟคิดราคาแก้วละ 45 บาท แล้วมีตัวเลือกเพิ่ม

| ตัวเลือก | เงื่อนไข | ค่าเพิ่ม |
|----------|----------|----------|
| ขนาดแก้ว | `L` | +15 บาท |
| ขนาดแก้ว | `M` | ไม่เพิ่ม |
| วิปครีม | `yes` | +10 บาท |
| วิปครีม | `no` | ไม่เพิ่ม |

เขียนโปรแกรมรับตัวเลือกของลูกค้า แล้วออกใบเสร็จ

---

## Input

2 บรรทัด — ขนาดแก้ว (`M` หรือ `L`) และวิปครีม (`yes` หรือ `no`)

## Output

ใบเสร็จในกรอบ แสดงราคาฐาน ค่าขนาด ค่าวิปครีม และยอดรวม

---

## ตัวอย่าง

**Input:**

```text
L
no
```

**Output:**

```text
========================
        COFFEE
========================
Base   : 45
Size   : 15
Whip   : 0
Total  : 60
========================
```

---

## 💡 Hint

ข้อนี้รับข้อมูลเป็น **ข้อความ** ไม่ใช่ตัวเลข จึงไม่ต้องแปลงด้วย `int()`
เทียบข้อความด้วย `==` ได้เลย และระวังตัวพิมพ์ใหญ่-เล็กให้ตรงกับที่โจทย์กำหนด
