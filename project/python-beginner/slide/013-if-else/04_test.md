# 🏷️ Practice if/else — Question 3: Discount

**Difficulty:** 🟡 Medium

---

## โจทย์

รับราคาสินค้า ถ้าราคา >= 100 บาท จะได้ส่วนลด 10 บาท แล้วแสดงราคาสุดท้าย

| เงื่อนไข | Output |
|----------|--------|
| ราคา >= 100 | แสดงราคาหลังหัก 10 บาท |
| ราคา < 100 | แสดงราคาเดิม |

---

## ตัวอย่าง

**Input:**
```
120
```

**Output:**
```
110
```

**Input:**
```
80
```

**Output:**
```
80
```
