# 🎢 if/else — ข้อ 3: ส่วนสูงขั้นต่ำของเครื่องเล่น

**Difficulty:** 🟢 Easy

---

## โจทย์

สวนสนุกกำหนดว่าเครื่องเล่นรถไฟเหาะต้องสูงอย่างน้อย 120 เซนติเมตรถึงจะขึ้นได้

เขียนโปรแกรมรับส่วนสูงของผู้เล่น แล้วบอกว่าขึ้นได้หรือไม่

**เงื่อนไข:**

- ส่วนสูง `>= 120` → `Allowed`
- ต่ำกว่านั้น → `Not Allowed`

---

## Input

ส่วนสูงเป็นเซนติเมตร (จำนวนเต็ม) 1 บรรทัด

## Output

ผลการตรวจ 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
118
```

**Output:**

```text
Not Allowed
```
