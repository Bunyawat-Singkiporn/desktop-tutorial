# 🌡️ if/else — ข้อ 1: เปิดแอร์หรือยัง

**Difficulty:** 🟢 Easy

---

## โจทย์

ห้องเรียนติดเซนเซอร์วัดอุณหภูมิไว้ ครูตั้งกติกาว่า
ถ้าอุณหภูมิถึง 30 องศาเมื่อไหร่ ให้เปิดแอร์

เขียนโปรแกรมอ่านค่าจากเซนเซอร์แล้วบอกว่าต้องทำอะไร

**เงื่อนไข:**

- อุณหภูมิ `>= 30` → `Turn On AC`
- น้อยกว่านั้น → `No AC`

---

## Input

อุณหภูมิเป็นจำนวนเต็ม 1 บรรทัด

## Output

ข้อความบอกการทำงาน 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
33
```

**Output:**

```text
Turn On AC
```
