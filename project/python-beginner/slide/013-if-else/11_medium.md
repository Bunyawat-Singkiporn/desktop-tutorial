# 🅿️ if/else — ข้อ 9: ค่าจอดรถชั่วโมงแรกฟรี

**Difficulty:** 🟡 Medium

---

## โจทย์

ลานจอดรถห้างให้จอดฟรีชั่วโมงแรก
ชั่วโมงที่เกินมาคิดชั่วโมงละ 20 บาท

เขียนโปรแกรมรับจำนวนชั่วโมงที่จอด แล้วคิดค่าจอด

**เงื่อนไข:**

- จอด `<= 1` ชั่วโมง → ค่าจอด `0` บาท
- จอดเกิน 1 ชั่วโมง → คิดเฉพาะชั่วโมงที่เกินมา ชั่วโมงละ 20 บาท

---

## Input

จำนวนชั่วโมงเป็นจำนวนเต็ม 1 บรรทัด

## Output

ใบคิดค่าจอดในกรอบ แสดงชั่วโมงที่จอด ชั่วโมงที่คิดเงิน และค่าจอด

---

## ตัวอย่าง

**Input:**

```text
4
```

**Output:**

```text
========================
       PARKING
========================
Hours Parked : 4
Hours Charged: 3
Fee          : 60
========================
```

---

## 💡 Hint

ชั่วโมงที่ต้องจ่ายเงินไม่เท่ากับชั่วโมงที่จอด — ลองคิดว่าต้องหักออกกี่ชั่วโมง
และอย่าลืมว่าถ้าจอดไม่เกินชั่วโมงแรก ชั่วโมงที่คิดเงินต้องเป็น 0

---

```python
hours = int(input())

# เขียนโค้ดตรงนี้
```
