# 🚚 if/else — ข้อ 7: ค่าส่งฟรีเมื่อซื้อครบ

**Difficulty:** 🟡 Medium

---

## โจทย์

ร้านออนไลน์คิดค่าส่ง 40 บาท แต่ถ้าสั่งของครบ 300 บาทขึ้นไป **ส่งฟรี**

เขียนโปรแกรมรับยอดสินค้า แล้วสรุปยอดที่ต้องจ่ายจริง

**เงื่อนไข:**

- ยอดสินค้า `>= 300` → ค่าส่ง `0`
- ยอดสินค้า `< 300` → ค่าส่ง `40`

---

## Input

ยอดสินค้าเป็นจำนวนเต็ม 1 บรรทัด

## Output

ใบสรุปคำสั่งซื้อในกรอบ แสดงค่าสินค้า ค่าส่ง และยอดรวม

---

## ตัวอย่าง

**Input:**

```text
280
```

**Output:**

```text
========================
        ORDER
========================
Items    : 280
Shipping : 40
Payable  : 320
========================
```

---

## 💡 Hint

ค่าส่งมีแค่สองความเป็นไปได้ ตัดสินใจก่อนแล้วค่อยบวกเข้ากับค่าสินค้า
