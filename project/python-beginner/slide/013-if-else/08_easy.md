# 🏪 if/else — ข้อ 4: ร้านไหนถูกกว่า

**Difficulty:** 🟢 Easy

---

## โจทย์

น้ำหาของชิ้นเดียวกันจาก 2 ร้าน แล้วจดราคาไว้

เขียนโปรแกรมเปรียบเทียบราคา แล้วบอกว่าควรซื้อร้านไหน

**เงื่อนไข:**

- ถ้าราคาร้าน A น้อยกว่าหรือเท่ากับร้าน B → `Shop A`
- ถ้าไม่ใช่ → `Shop B`

> ข้อนี้ต่างจากข้อก่อนหน้า ตรงที่เราเทียบ **ค่าสองค่าที่รับเข้ามา** ไม่ใช่เทียบกับตัวเลขคงที่

---

## Input

2 บรรทัด — ราคาร้าน A และราคาร้าน B

## Output

ชื่อร้านที่ควรซื้อ 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
250
230
```

**Output:**

```text
Shop B
```
