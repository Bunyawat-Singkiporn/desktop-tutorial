# 🔥 Practice if/else — Question 4: Ticket Price

**Difficulty:** 🔴 Hard

---

## โจทย์

รับอายุและวัน (weekday หรือ weekend) แล้วคำนวณราคาตั๋ว

**เงื่อนไขที่ 1 — ตรวจอายุ:**

| เงื่อนไข | ราคาพื้นฐาน |
|----------|-------------|
| อายุ >= 60 | 50 บาท (ผู้สูงอายุ) |
| อายุ < 60 | 100 บาท (ปกติ) |

**เงื่อนไขที่ 2 — ตรวจวัน:**

| เงื่อนไข | เพิ่มราคา |
|----------|-----------|
| `weekend` | +20 บาท |
| `weekday` | ไม่เพิ่ม |

> รับอายุบรรทัดแรก รับวัน (`weekday` หรือ `weekend`) บรรทัดที่สอง

---

## ตัวอย่าง

**Input:**
```
65
weekend
```

**Output:**
```
70
```

> ผู้สูงอายุ 50 + weekend 20 = 70
