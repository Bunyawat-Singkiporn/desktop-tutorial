## โจทย์

โค้ดด้านล่างรันได้ แต่ชื่อตัวแปรไม่สื่อความหมาย — เขียนใหม่ด้วยชื่อที่ดีกว่า

```python
# โค้ดเดิม
a = int(input())
b = int(input())
c = a + b
d = c / 2
if d >= 50:
    print("ok")
else:
    print("not ok")
```

**ชื่อที่ดีกว่า:** `score1`, `score2`, `total`, `average`, `"Pass"`, `"Fail"`

**Output** (เหมือนเดิม สำหรับ input 80 60):
```
Pass
```
