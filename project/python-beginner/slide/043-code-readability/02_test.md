# ✨ Code Readability — ข้อ 2: ตั้งชื่อคะแนนให้ชัด

**Difficulty:** 🟢 Easy

---

## โจทย์

มีคะแนน 75 ตรวจผ่านเกณฑ์ 50

**เงื่อนไข:**

- ใช้ชื่อ `score` และ `is_passed`
- พิมพ์ `Passed` หรือ `Not passed`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

1 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Passed
```


---

## Starter Code

```python
score = 75
is_passed = score >= 50

# พิมพ์ตาม is_passed
```
