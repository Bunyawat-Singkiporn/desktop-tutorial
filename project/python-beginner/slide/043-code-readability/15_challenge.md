# ✨ Code Readability — ข้อ 15: โปรไฟล์สั้นชัด

**Difficulty:** 🔴 Challenge

---

## โจทย์

แสดงโปรไฟล์สั้นๆ

**เงื่อนไข:**

- รับชื่อและเมือง
- พิมพ์ `Profile: <name> / <city>` ด้วย f-string

---

## Input

ดูตัวอย่าง

## Output

1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
Mina
Chiang Mai
```

**Output:**

```text
Profile: Mina / Chiang Mai
```


---

## 💡 Hint

ใช้ f-string คู่เดียว

---

## Starter Code

```python
name = input()
city = input()

# f-string
```
