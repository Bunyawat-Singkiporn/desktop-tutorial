# ✨ Code Readability — ข้อ 6: ใบเสร็จชื่อดี

**Difficulty:** 🟡 Medium

---

## โจทย์

ใบเสร็จใช้ชื่อตัวแปรสื่อความ

**เงื่อนไข:**

- `item_name = "Notebook"` `unit_price = 45` `quantity = 2`
- พิมพ์ `Notebook x2 = 90`

---

## ตัวอย่าง

**Output:**

```text
Notebook x2 = 90
```


---

## 💡 Hint

คูณราคาต่อชิ้นกับจำนวน

---

## Starter Code

```python
item_name = "Notebook"
unit_price = 45
quantity = 2

# พิมพ์ใบเสร็จสั้น
```
