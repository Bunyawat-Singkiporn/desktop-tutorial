# ✨ Code Readability — ข้อ 7: เกณฑ์ผ่านชัดเจน

**Difficulty:** 🟡 Medium

---

## โจทย์

รับคะแนนแล้วใช้ตัวแปร boolean

**เงื่อนไข:**

- `is_passed = score >= 60`
- พิมพ์ `True` หรือ `False` ของ is_passed

---

## Input

ดูตัวอย่าง

## Output

1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
72
```

**Output:**

```text
True
```


---

## 💡 Hint

พิมพ์ค่า boolean โดยตรงได้

---

## Starter Code

```python
score = int(input())
is_passed = score >= 60
print(is_passed)
```
