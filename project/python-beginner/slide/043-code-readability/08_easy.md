# ✨ Code Readability — ข้อ 8: เปลี่ยนเป็น f-string

**Difficulty:** 🟢 Easy

---

## โจทย์

มี name และ age ให้พิมพ์ด้วย f-string

**เงื่อนไข:**

- `name = "Rin"` `age = 14`
- พิมพ์ `Name: Rin, Age: 14` ด้วย f-string

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

1 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Name: Rin, Age: 14
```


---

## Starter Code

```python
name = "Rin"
age = 14

# ใช้ f-string
```
