# ✨ Code Readability — ข้อ 4: เก็บผลเปรียบเทียบ

**Difficulty:** 🟢 Easy

---

## โจทย์

ตรวจอายุผู้ใหญ่

**เงื่อนไข:**

- รับอายุ
- เก็บ `is_adult = age >= 18`
- ถ้า True พิมพ์ `Adult` ไม่งั้น `Minor`

---

## Input

ดูตัวอย่าง

## Output

1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
20
```

**Output:**

```text
Adult
```


---

## Starter Code

```python
age = int(input())
is_adult = age >= 18

# ใช้ is_adult
```
