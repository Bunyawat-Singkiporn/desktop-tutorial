## โจทย์

โค้ดด้านล่างมี indentation ผิด และไม่มี comment — แก้และเพิ่ม comment ที่เหมาะสม

```python
fruits=["apple","banana","mango"]
total=0
for f in fruits:
total+=len(f)
avg=total/len(fruits)
print(avg)
```

**Output:**
```
5.333333333333333
```

---

## 💡 Hint

- เว้นช่องว่างรอบ `=` และ `,`
- indent บรรทัดใน `for` 4 ช่อง
- เพิ่ม comment อธิบายว่าโค้ดทำอะไร
