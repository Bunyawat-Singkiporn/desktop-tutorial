## โจทย์

**เงื่อนไข:**

- ตั้ง `DISCOUNT_RATE = 0.1`
- `price = 200`
- พิมพ์ `Final: <price * (1 - DISCOUNT_RATE)>` ทศนิยม 1 ตำแหน่ง

---

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

1 บรรทัด
