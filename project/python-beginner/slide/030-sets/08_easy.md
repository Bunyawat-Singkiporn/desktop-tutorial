# 🔤 Sets — ข้อ 8: ตัดชื่อซ้ำจากรายชื่อ

**Difficulty:** 🟢 Easy

---

## โจทย์

รายชื่อมีชื่อซ้ำ อยากได้ชุดไม่ซ้ำ

กำหนด `names = ["Ann", "Ben", "Ann", "Cara", "Ben"]`

แปลงเป็น set แล้วกลับเป็น list เรียงชื่อ และแสดง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Ann', 'Ben', 'Cara']
```


---

## Starter Code

```python
names = ["Ann", "Ben", "Ann", "Cara", "Ben"]

# เขียนโค้ดตรงนี้
```
