# 🔤 Sets — ข้อ 11: ลบแล้วหาส่วนร่วม

**Difficulty:** 🟡 Medium

---

## โจทย์

ลบสมาชิกแล้วหาส่วนร่วมกับอีกกลุ่ม

กำหนด `a = {"A", "B", "C", "D"}` และ `b = {"B", "C", "E"}`

ลบ `D` จาก a แล้วแสดง `a & b` แบบ list เรียง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['B', 'C']
```


---

## 💡 Hint

remove ก่อนคำนวณส่วนร่วม

---

## Starter Code

```python
a = {"A", "B", "C", "D"}
b = {"B", "C", "E"}

# เขียนโค้ดตรงนี้
```
