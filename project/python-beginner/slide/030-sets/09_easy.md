# 🔤 Sets — ข้อ 9: เช็คว่ามีรหัสหรือยัง

**Difficulty:** 🟢 Easy

---

## โจทย์

ระบบเช็ครหัสคูปอง

กำหนด `codes = {"A1", "B2", "C3"}`

เช็ค `"B2"` ถ้ามีแสดง `Valid` ไม่มีแสดง `Invalid`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
Valid
```

codes = {"A1", "B2", "C3"}

# เขียนโค้ดตรงนี้
