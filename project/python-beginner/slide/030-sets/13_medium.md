# 🔤 Sets — ข้อ 13: วิชาที่เรียนร่วมกัน

**Difficulty:** 🟡 Medium

---

## โจทย์

หาวิชาที่ทั้งสองคนเรียนร่วมกัน

กำหนด `ann = {"Math", "Thai", "PE"}` และ `ben = {"Thai", "Art", "PE"}`

แสดงส่วนร่วมแบบ list เรียง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['PE', 'Thai']
```


---

## 💡 Hint

& ให้เฉพาะตัวที่มีทั้งสองฝั่ง

---

## Starter Code

```python
ann = {"Math", "Thai", "PE"}
ben = {"Thai", "Art", "PE"}

# เขียนโค้ดตรงนี้
```
