# 🔤 Sets — ข้อ 15: เพื่อนเก่าเพื่อนใหม่

**Difficulty:** 🔴 Challenge

---

## โจทย์

เปรียบเทียบเพื่อนปีที่แล้วกับปีนี้

กำหนด `old = {"Ann", "Ben", "Cara"}` และ `new = {"Ben", "Cara", "Dan", "Ed"}`

แสดงจำนวนเพื่อนทั้งหมด (union) และจำนวนเพื่อนร่วม (intersection)

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
All  : 5
Both : 2
```


---

## 💡 Hint

ใช้ len กับผลของ | และ &

---

## Starter Code

```python
old = {"Ann", "Ben", "Cara"}
new = {"Ben", "Cara", "Dan", "Ed"}

# เขียนโค้ดตรงนี้
```
