# 🔤 Sets — ข้อ 10: เพิ่มแล้วเช็คของในคลัง

**Difficulty:** 🟡 Medium

---

## โจทย์

คลังเพิ่มสินค้าแล้วเช็คว่ามีหรือยัง

กำหนด `stock = {"Rice", "Oil"}` แล้ว add `Salt`

ถ้ามี `Salt` แสดง `In stock` ไม่เช่นนั้น `Out`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
In stock
```


---

## 💡 Hint

add ก่อน แล้วค่อย in

---

## Starter Code

```python
stock = {"Rice", "Oil"}

# เขียนโค้ดตรงนี้
```
