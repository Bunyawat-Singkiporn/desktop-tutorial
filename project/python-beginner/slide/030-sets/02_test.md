# 🔁 Practice Sets — Question 1: Remove Duplicates

**Difficulty:** 🟢 Easy

---

## โจทย์

กำหนด list ที่มีค่าซ้ำ แปลงเป็น set เพื่อลบซ้ำแล้วแสดงผล

```python
numbers = [1, 2, 2, 3, 4, 4, 4, 5]
```

**Output** (ลำดับอาจต่างกัน):
```
{1, 2, 3, 4, 5}
```

---

## 💡 Hint

ใช้ `set(numbers)` เพื่อแปลง list เป็น set

---

## Starter Code

```python
numbers = [1, 2, 2, 3, 4, 4, 4, 5]

# แปลงเป็น set
```
