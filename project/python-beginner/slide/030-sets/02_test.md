# 🔤 Sets — ข้อ 2: เช็คชื่อในกลุ่มเพื่อน

**Difficulty:** 🟢 Easy

---

## โจทย์

แอปเช็คว่ามีเพื่อนชื่อนี้ในกลุ่มหรือไม่

กำหนด `friends = {"Mew", "Pim", "Ohm"}`

ถ้า `"Pim"` อยู่ในกลุ่ม แสดง `Found` ไม่เช่นนั้นแสดง `Missing`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
Found
```


---

## Starter Code

```python
friends = {"Mew", "Pim", "Ohm"}

# เขียนโค้ดตรงนี้
```
