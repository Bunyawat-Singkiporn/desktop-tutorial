# 🔤 Sets — ข้อ 6: เพื่อนร่วมและสหภาพ

**Difficulty:** 🟡 Medium

---

## โจทย์

หาเพื่อนที่อยู่ทั้งสองกลุ่ม และเพื่อนทั้งหมด

กำหนด `a = {"Ann", "Ben", "Cara"}` และ `b = {"Ben", "Dan", "Cara"}`

แสดงส่วนร่วมและสหภาพ (เรียงชื่อ) คนละบรรทัด

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Ben', 'Cara']
['Ann', 'Ben', 'Cara', 'Dan']
```


---

## 💡 Hint

& คือส่วนร่วม | คือรวมทั้งหมด

---

## Starter Code

```python
a = {"Ann", "Ben", "Cara"}
b = {"Ben", "Dan", "Cara"}

# เขียนโค้ดตรงนี้
```
