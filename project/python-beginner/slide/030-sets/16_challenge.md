# 🔤 Sets — ข้อ 16: คลังรหัสสินค้า

**Difficulty:** 🔴 Challenge

---

## โจทย์

คลังจัดการรหัสสินค้า

กำหนด `warehouse = {"S01", "S02", "S03"}` และ `incoming = {"S03", "S04"}`

เพิ่ม `S05` เข้า warehouse ลบ `S01` แล้วแสดง
รหัสทั้งหมดหลังรวมกับ incoming (เรียง) ส่วนร่วมกับ incoming (เรียง) และจำนวนทั้งหมด

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
['S02', 'S03', 'S04', 'S05']
['S03']
Total: 4
```


---

## 💡 Hint

อัปเดต warehouse ก่อนค่อย | และ &

---

## Starter Code

```python
warehouse = {"S01", "S02", "S03"}
incoming = {"S03", "S04"}

# เขียนโค้ดตรงนี้
```
