# 🔤 Sets — ข้อ 12: รวมสองรายการไม่ซ้ำ

**Difficulty:** 🟡 Medium

---

## โจทย์

รวมรายชื่อสองห้องให้ไม่ซ้ำ

กำหนด `room1 = {"Ann", "Ben"}` และ `room2 = {"Ben", "Cara", "Dan"}`

ใช้ `|` แล้วแสดง list เรียง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Ann', 'Ben', 'Cara', 'Dan']
```


---

## 💡 Hint

| รวมแล้วตัดซ้ำอัตโนมัติ

---

## Starter Code

```python
room1 = {"Ann", "Ben"}
room2 = {"Ben", "Cara", "Dan"}

# เขียนโค้ดตรงนี้
```
