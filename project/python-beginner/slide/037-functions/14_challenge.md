# ⚙️ Functions — ข้อ 14: ใบเสร็จหลายรายการ

**Difficulty:** 🔴 Challenge

---

## โจทย์

พิมพ์รายการราคาจาก list แล้วสรุปยอด

**เงื่อนไข:**

- ใน `bill()` มี `prices = [45, 60, 30]`
- พิมพ์แต่ละราคาในรูป `Item: <ราคา>`
- สุดท้ายพิมพ์ `Total: <ผลรวม>`
- เรียก 1 ครั้ง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม / เรียกฟังก์ชันในโค้ด)

## Output

4 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Item: 45
Item: 60
Item: 30
Total: 135
```
