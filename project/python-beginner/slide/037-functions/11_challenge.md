## โจทย์

ทำโปรแกรมประกาศวันหนึ่งที่โรงเรียน โดยแยกเป็น **3 functions**:

| Function | แสดงอะไร |
|----------|----------|
| `morning()` | ทักทายเช้า |
| `lunch()` | บอกเวลากินข้าว |
| `goodbye()` | บอกลาตอนเย็น |

เรียกทั้ง 3 ตามลำดับในโปรแกรมหลัก

---

```
Good morning, students!
Time for lunch!
Goodbye! See you tomorrow.
```
