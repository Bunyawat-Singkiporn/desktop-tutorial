# ⌨️ Input — ข้อ 15: ใบเสร็จร้านกาแฟ

**Difficulty:** 🔴 Challenge

---

## โจทย์

ร้านกาแฟพิมพ์ใบเสร็จหลังรับออเดอร์
รับชื่อลูกค้า ราคาเครื่องดื่ม ราคาขนม และทิป
แสดงใบเสร็จในกรอบ โดยยอดรวมคือเครื่องดื่ม + ขนม + ทิป

---

## Input

4 บรรทัด — ชื่อลูกค้า ราคาเครื่องดื่ม ราคาขนม ทิป (จำนวนเต็มทั้งราคาและทิป)

## Output

ใบเสร็จในกรอบ

---

## ตัวอย่าง

**Input:**

```text
Bow
55
40
10
```

**Output:**

```text
========================
        CAFE
========================
Customer : Bow
Drink    : 55
Snack    : 40
Tip      : 10
Total    : 105
========================
```

---

## 💡 Hint

รับชื่อด้วย `input()` ที่เหลือเป็น `int(input())` แล้วบวกสามจำนวนก่อนพิมพ์กรอบ

---

## Starter Code

```python
customer = input()
drink = int(input())
snack = int(input())
tip = int(input())

# เขียนโค้ดตรงนี้
```
