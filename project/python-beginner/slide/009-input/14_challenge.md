# ⌨️ Input — ข้อ 13: ตะกร้าสามชิ้น

**Difficulty:** 🔴 Challenge

---

## โจทย์

แอปสั่งของออนไลน์รับจำนวนสินค้าสามชิ้น
รับจำนวนแต่ละชิ้น แล้วแสดงจำนวนรวมในกรอบ

---

## Input

3 บรรทัด — จำนวนชิ้น A B และ C (จำนวนเต็ม)

## Output

ใบสรุปตะกร้าในกรอบ

---

## ตัวอย่าง

**Input:**

```text
2
1
4
```

**Output:**

```text
========================
         CART
========================
Item A : 2
Item B : 1
Item C : 4
Total  : 7
========================
```

---

## 💡 Hint

บวกสามค่าเก็บในตัวแปรก่อน แล้วพิมพ์กรอบให้ครบ
