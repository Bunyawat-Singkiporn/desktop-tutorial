# ⌨️ Input — ข้อ 9: ชื่อจริงกับชื่อเล่น

**Difficulty:** 🟡 Medium

---

## โจทย์

ระบบลงทะเบียนห้องสมุดเก็บชื่อจริงและชื่อเล่น
รับทั้งสองค่า แล้วแสดงบรรทัดรวมและบรรทัดแยก

---

## Input

2 บรรทัด — ชื่อจริง และชื่อเล่น

## Output

2 บรรทัด แสดงชื่อเต็มแบบสั้นและชื่อเล่น

---

## ตัวอย่าง

**Input:**

```text
Kanokwan
Kan
```

**Output:**

```text
Full: Kanokwan Kan
Nick: Kan
```

---

## 💡 Hint

`print("Full:", real, nick)` จะเว้นวรรคให้อัตโนมัติระหว่างค่า
