# ⌨️ Input — ข้อ 11: คะแนนสามครั้ง

**Difficulty:** 🟡 Medium

---

## โจทย์

ครูเก็บคะแนนควิซสามครั้ง
รับคะแนนทั้งสาม แล้วแสดงยอดรวม

---

## Input

3 บรรทัด — คะแนนครั้งที่ 1 2 และ 3 (จำนวนเต็ม)

## Output

คะแนนรวม 1 บรรทัด

---
