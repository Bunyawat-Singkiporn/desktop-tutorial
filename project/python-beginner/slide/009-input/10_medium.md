# ⌨️ Input — ข้อ 8: บัตรชื่ออายุเมือง

**Difficulty:** 🟡 Medium

---

## โจทย์

งานสมัครค่ายถามชื่อ อายุ และเมืองที่อยู่
รับครบสามค่า แล้วแสดงเป็นบัตรสามบรรทัด

---

## Input

3 บรรทัด — ชื่อ อายุ (จำนวนเต็ม) เมือง

## Output

3 บรรทัด แสดงข้อมูลบัตร

---

## ตัวอย่าง

**Input:**

```text
Fah
13
Phuket
```

**Output:**

```text
Name: Fah
Age: 13
City: Phuket
```

---

## 💡 Hint

อายุต้องใช้ `int(input())` ส่วนชื่อกับเมืองใช้ `input()` ธรรมดา

---

## Starter Code

```python
name = input()
age = int(input())
city = input()

# เขียนโค้ดตรงนี้
```
