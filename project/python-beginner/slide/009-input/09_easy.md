# ⌨️ Input — ข้อ 5: ชื่อสินค้ากับราคา

**Difficulty:** 🟢 Easy

---

## โจทย์

พนักงานร้านสะดวกซื้อบันทึกชื่อสินค้าและราคา
รับทั้งสองค่า แล้วแสดงเป็นสองบรรทัด

---

## Input

2 บรรทัด — ชื่อสินค้า และราคา (จำนวนเต็ม)

## Output

2 บรรทัด แสดงชื่อและราคา

---

## ตัวอย่าง

**Input:**

```text
Milk
29
```

**Output:**

```text
Product: Milk
Price: 29
```
