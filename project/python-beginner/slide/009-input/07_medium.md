# Practice: Input — Medium B: ราคารวม

**Difficulty:** 🟡 Medium

---

## โจทย์

รับราคาสินค้าต่อชิ้น (int) และจำนวน (int) แสดงผลคูณ:

```
Total: <price*qty>
```


---

## ตัวอย่าง Input / Output

**Input:**
```
25
4
```

**Output:**
```
Total: 100
```

---

## 💡 Hint

สอง int(input())

---

## Starter Code

```python
price = int(input())
qty = int(input())

```
