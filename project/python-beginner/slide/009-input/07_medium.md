# ⌨️ Input — ข้อ 7: บิลสองรายการ

**Difficulty:** 🟡 Medium

---

## โจทย์

ร้านมินิมาร์ทคิดเงินสองรายการ
รับราคาสองชิ้น แล้วแสดงยอดรวม

---

## Input

2 บรรทัด — ราคาชิ้นที่ 1 และชิ้นที่ 2 (จำนวนเต็ม)

## Output

ยอดรวม 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
45
30
```

**Output:**

```text
Total: 75
```

---

## 💡 Hint

ใช้ `int(input())` สองครั้ง แล้วบวกก่อนพิมพ์

---

## Starter Code

```python
item1 = int(input())
item2 = int(input())

# เขียนโค้ดตรงนี้
```
