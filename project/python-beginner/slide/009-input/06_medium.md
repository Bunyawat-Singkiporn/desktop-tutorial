# Practice: Input — Medium A: การ์ดชื่อ+อายุ

**Difficulty:** 🟡 Medium

---

## โจทย์

รับชื่อ (string) และอายุ (int) แล้วแสดง:

```
Name: <name>
Age: <age>
```


---

## ตัวอย่าง Input / Output

**Input:**
```
Mina
11
```

**Output:**
```
Name: Mina
Age: 11
```

---

## 💡 Hint

input แล้ว int(input())

---

## Starter Code

```python
name = input()
age = int(input())

```
