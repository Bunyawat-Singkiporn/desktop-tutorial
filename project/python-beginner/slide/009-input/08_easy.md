# ⌨️ Input — ข้อ 4: จำนวนเพื่อนในกลุ่ม

**Difficulty:** 🟢 Easy

---

## โจทย์

ครูให้นับจำนวนเพื่อนในกลุ่ม แล้วบวกครูเข้าไปเป็นสมาชิกอีกคน
รับจำนวนเพื่อน แล้วแสดงจำนวนคนทั้งหมดในกลุ่ม

---

## Input

จำนวนเพื่อนเป็นจำนวนเต็ม 1 บรรทัด

## Output

จำนวนคนทั้งหมด 1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
5
```

**Output:**

```text
Group size: 6
```
