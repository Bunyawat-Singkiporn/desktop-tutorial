## โจทย์

สร้างโค้ดสำหรับ 3 สถานการณ์ต่อไปนี้โดยใช้ชนิดข้อมูลที่เหมาะสม:

| สถานการณ์ | ชนิดที่เหมาะ |
|----------|------------|
| ชื่อวันในสัปดาห์ (ไม่เปลี่ยน) | Tuple |
| รายชื่อสมาชิก (เพิ่มลบได้) | List |
| รหัสนักเรียน (ไม่ซ้ำ) | Set |

แสดงจำนวนสมาชิกของแต่ละชนิด

**Output:**
```
Days: 7
Members: 4
IDs: 5
```
