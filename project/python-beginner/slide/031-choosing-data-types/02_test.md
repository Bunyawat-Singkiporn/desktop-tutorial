# 🧭 Choosing Types — ข้อ 2: รายการซื้อที่แก้ได้

**Difficulty:** 🟢 Easy

---

## โจทย์

รายการซื้อต้องเพิ่มของได้ทีหลัง เลยใช้ list

เริ่ม `cart = ["Milk", "Bread"]` แล้ว append `Eggs`

แสดง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Milk', 'Bread', 'Eggs']
```


---

## Starter Code

```python
cart = ["Milk", "Bread"]

# เขียนโค้ดตรงนี้

print(cart)
```
