# 🧭 Choosing Types — ข้อ 15: แขกงานกับรายชื่อซ้ำ

**Difficulty:** 🔴 Challenge

---

## โจทย์

รายชื่อแขกเป็น list มีซ้ำ อยากสรุปด้วย set

กำหนด `guests = ["Ann", "Ben", "Ann", "Cara", "Ben", "Dan"]`

แสดงจำนวนชื่อใน list และจำนวนไม่ซ้ำ

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Listed : 6
Unique : 4
```


---

## 💡 Hint

list นับทั้งหมด set นับไม่ซ้ำ

---

guests = ["Ann", "Ben", "Ann", "Cara", "Ben", "Dan"]
