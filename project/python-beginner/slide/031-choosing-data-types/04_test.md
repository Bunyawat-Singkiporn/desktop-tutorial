## โจทย์

โค้ดด้านล่างใช้ list เก็บพิกัด (x, y, z) ซึ่งไม่ควรเปลี่ยน
เขียนใหม่โดยใช้ **tuple** แทนและเพิ่ม comment อธิบายว่าทำไมถึงเลือก tuple

```python
# โค้ดเดิม (ใช้ list)
point = [10, 20, 30]
print(f"x={point[0]}, y={point[1]}, z={point[2]}")
```

**Output** (เหมือนเดิม):
```
x=10, y=20, z=30
```
