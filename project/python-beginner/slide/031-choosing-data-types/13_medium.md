# 🧭 Choosing Types — ข้อ 13: เช็คสมาชิกชมรม

**Difficulty:** 🟡 Medium

---

## โจทย์

เช็คสมาชิกด้วย set เพราะต้องการ in ที่เร็วและไม่ซ้ำ

กำหนด `club = {"Ann", "Ben", "Cara"}`

เช็ค `"Dan"` แสดง `Member` หรือ `Guest`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
Guest
```


---

## 💡 Hint

set + in เหมาะกับเช็คสมาชิก

---

club = {"Ann", "Ben", "Cara"}

# เขียนโค้ดตรงนี้
