# 🧭 Choosing Types — ข้อ 11: ตะกร้าแล้วตัดซ้ำ

**Difficulty:** 🟡 Medium

---

## โจทย์

ตะกร้าเป็น list มีของซ้ำ อยากได้ชุดไม่ซ้ำ

กำหนด `cart = ["Pen", "Book", "Pen", "Glue"]`

แสดงของไม่ซ้ำแบบเรียง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Book', 'Glue', 'Pen']
```


---

## 💡 Hint

list เก็บลำดับซื้อ set ตัดซ้ำ

---

## Starter Code

```python
cart = ["Pen", "Book", "Pen", "Glue"]

# เขียนโค้ดตรงนี้
```
