# 🧭 Choosing Types — ข้อ 10: โปรไฟล์คงที่

**Difficulty:** 🟡 Medium

---

## โจทย์

ข้อมูลโปรไฟล์สั้นๆ ไม่ควรแก้ ใช้ tuple

กำหนด `profile = ("Ohm", 14, "Bangkok")`

แสดงตามตัวอย่าง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Name: Ohm
Age : 14
City: Bangkok
```


---

## 💡 Hint

tuple อ่านด้วย index

---

## Starter Code

```python
profile = ("Ohm", 14, "Bangkok")

# เขียนโค้ดตรงนี้
```
