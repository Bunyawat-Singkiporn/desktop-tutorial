# 🧭 Choosing Types — ข้อ 12: เมนูคงที่กับของเพิ่ม

**Difficulty:** 🟡 Medium

---

## โจทย์

เมนูหลักเป็น tuple ส่วนของเพิ่มเป็น list

กำหนด `menu = ("Rice", "Soup")` และ `extra = ["Egg"]` แล้ว append `Pork`

แสดงเมนูหลักทีละบรรทัด และของเพิ่มทั้ง list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Rice
Soup
['Egg', 'Pork']
```


---

## 💡 Hint

tuple อ่านอย่างเดียว list แก้ได้

---

## Starter Code

```python
menu = ("Rice", "Soup")
extra = ["Egg"]

# เขียนโค้ดตรงนี้
```
