# 🧭 Choosing Types — ข้อ 7: เพื่อนร่วมสองกลุ่ม

**Difficulty:** 🟡 Medium

---

## โจทย์

หาเพื่อนร่วมด้วย set

กำหนด `g1 = {"Ann", "Ben"}` และ `g2 = {"Ben", "Cara"}`

แสดงส่วนร่วมแบบ list เรียง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
['Ben']
```


---

## 💡 Hint

set เหมาะกับส่วนร่วม

---

## Starter Code

```python
g1 = {"Ann", "Ben"}
g2 = {"Ben", "Cara"}

# เขียนโค้ดตรงนี้
```
