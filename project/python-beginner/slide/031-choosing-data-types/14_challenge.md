# 🧭 Choosing Types — ข้อ 14: งานบ้านกับวันคงที่

**Difficulty:** 🔴 Challenge

---

## โจทย์

งานบ้านเป็น list วันเป็น tuple

กำหนด `chores = ["Sweep", "Mop"]` append `Dust`
และ `days = ("Sat", "Sun")`

แสดงงานพร้อมเลขที่ด้วย range(len) และแสดงทุกวันจาก tuple

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

รายการผสม

---

## ตัวอย่าง

**Output:**

```text
1) Sweep
2) Mop
3) Dust
Sat
Sun
```


---

## 💡 Hint

list แก้ได้ tuple วนอย่างเดียว

---

```python
chores = ["Sweep", "Mop"]
days = ("Sat", "Sun")

# เขียนโค้ดตรงนี้
```
