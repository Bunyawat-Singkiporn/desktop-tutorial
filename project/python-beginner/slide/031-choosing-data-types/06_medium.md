# 🧭 Choosing Types — ข้อ 6: คิวงานที่เรียงได้

**Difficulty:** 🟡 Medium

---

## โจทย์

คิวงานต้องเรียงชื่อได้ ใช้ list

กำหนด `jobs = ["Clean", "Cook", "Buy"]` แล้ว sort และแสดง

---

## ตัวอย่าง

**Output:**

```text
['Buy', 'Clean', 'Cook']
```


---

## 💡 Hint

list เรียงได้ด้วย .sort()

---

## Starter Code

```python
jobs = ["Clean", "Cook", "Buy"]

# เขียนโค้ดตรงนี้

print(jobs)
```
