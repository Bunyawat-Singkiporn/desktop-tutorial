# ⏬ Practice: while Loop — Question 1: Count Up

**Difficulty:** 🟢 Easy

---

## โจทย์

ใช้ `while` loop นับจาก 1 ถึง 5

**Output:**
```
1
2
3
4
5
Done!
```

---

## 💡 Hint

- ตั้ง `count = 1`
- เงื่อนไข: `count <= 5`
- อย่าลืม `count = count + 1` ในทุกรอบ

---

## Starter Code

```python
count = 1

while count <= 5:
    # Print count
    # Increase count

print("Done!")
```
