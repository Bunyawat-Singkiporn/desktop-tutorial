# 📦 Tuples — ข้อ 9: รหัสห้องเรียน

**Difficulty:** 🟢 Easy

---

## โจทย์

รหัสห้องเก็บเป็น tuple สามส่วน อยากได้ส่วนกลาง

กำหนด `room = ("B", "204", "Lab")`

แสดงส่วนกลาง `204`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
204
```
