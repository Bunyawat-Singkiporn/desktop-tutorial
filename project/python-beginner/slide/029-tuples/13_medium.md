# 📦 Tuples — ข้อ 13: ป้ายเที่ยวบิน

**Difficulty:** 🟡 Medium

---

## โจทย์

กำหนด `flight = ("TG", 305, "BKK")`

แสดงตามตัวอย่าง

---

## Input

## Output

3 บรรทัด

## ตัวอย่าง

```text

Number : 305
City   : BKK
```
