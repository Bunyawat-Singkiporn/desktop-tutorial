# 📦 Tuples — ข้อ 10: เมนูคงที่พร้อมเลข

**Difficulty:** 🟡 Medium

---

## โจทย์

เมนูอาหารชุดพิเศษเปลี่ยนไม่ได้ อยากพิมพ์พร้อมเลขที่

กำหนด `menu = ("Rice", "Soup", "Fruit")`

แสดง `1. Rice` โดยเพิ่มตัวนับเอง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
1. Rice
2. Soup
3. Fruit
```


---

## 💡 Hint

tuple วนได้เหมือน list

---

## Starter Code

```python
menu = ("Rice", "Soup", "Fruit")

# เขียนโค้ดตรงนี้
```
