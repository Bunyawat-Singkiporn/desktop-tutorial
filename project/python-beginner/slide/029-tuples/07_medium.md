# 📦 Tuples — ข้อ 7: สรุปพิกัดพร้อมจำนวน

**Difficulty:** 🟡 Medium

---

## โจทย์

สรุปพิกัดและจำนวนค่าใน tuple

กำหนด `point = (8, 15, 3)`

แสดงค่าแรก ค่าสุดท้าย และจำนวนสมาชิก

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Start: 8
End  : 3
Size : 3
```


---

## 💡 Hint

ใช้ [0] [-1] และ len

---

## Starter Code

```python
point = (8, 15, 3)

# เขียนโค้ดตรงนี้
```
