# 📦 Tuples — ข้อ 11: เปรียบเทียบสองพิกัด

**Difficulty:** 🟡 Medium

---

## โจทย์

เปรียบเทียบพิกัด X ของจุดสองจุด

กำหนด `a = (10, 20)` และ `b = (7, 25)`

ถ้า X ของ a มากกว่าหรือเท่ากับ b แสดง `A` ไม่เช่นนั้นแสดง `B`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
A
```


---

## 💡 Hint

เทียบเฉพาะค่า index 0

---

## Starter Code

```python
a = (10, 20)
b = (7, 25)

# เขียนโค้ดตรงนี้
```
