# 📦 Tuples — ข้อ 2: ป้ายวันทำการหัวท้าย

**Difficulty:** 🟢 Easy

---

## โจทย์

ออฟฟิศอยากโชว์วันทำการวันแรกและวันสุดท้าย

กำหนด `workdays = ("Mon", "Tue", "Wed", "Thu", "Fri")`

แสดงวันแรกและวันสุดท้ายคนละบรรทัด

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Mon
Fri
```


---

## Starter Code

```python
workdays = ("Mon", "Tue", "Wed", "Thu", "Fri")

# เขียนโค้ดตรงนี้
```
