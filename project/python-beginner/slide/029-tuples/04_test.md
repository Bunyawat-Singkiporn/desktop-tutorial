# 📦 Tuples — ข้อ 4: นับจำนวนวันในสัปดาห์เรียน

**Difficulty:** 🟢 Easy

---

## โจทย์

นับจำนวนวันเรียนในสัปดาห์

กำหนด `days = ("Mon", "Tue", "Wed", "Thu", "Fri")`

แสดง `Days: 5`

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
Days: 5
```

```python
days = ("Mon", "Tue", "Wed", "Thu", "Fri")

# เขียนโค้ดตรงนี้
```
