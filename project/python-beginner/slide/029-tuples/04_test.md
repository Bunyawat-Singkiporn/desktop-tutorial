## โจทย์

กำหนดข้อมูลนักเรียน 3 คน แต่ละคนเก็บเป็น tuple `(ชื่อ, คะแนน)` แสดงข้อมูลทุกคนพร้อมบอกว่า Pass หรือ Fail (>= 50)

```python
students = [("Alice", 85), ("Bob", 42), ("Charlie", 73)]
```

**Output:**
```
Alice: 85 → Pass
Bob: 42 → Fail
Charlie: 73 → Pass
```

---

## 💡 Hint

- Loop ผ่าน `students`
- แต่ละรายการคือ tuple: `student[0]` = ชื่อ, `student[1]` = คะแนน
