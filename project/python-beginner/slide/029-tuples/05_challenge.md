# 📦 Tuples — ข้อ 5: โปรไฟล์นักกีฬา

**Difficulty:** 🔴 Challenge

---

## โจทย์

พิมพ์โปรไฟล์นักกีฬาจาก tuple

กำหนด `athlete = ("Beam", 16, "Swim", 3)`

แสดงชื่อ อายุ กีฬา และจำนวนเหรียญ ตามตัวอย่าง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

4 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Name  : Beam
Age   : 16
Sport : Swim
Medals: 3
```
