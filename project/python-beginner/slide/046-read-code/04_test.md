# 👀 Read Code — ข้อ 4: ทำนาย if

**Difficulty:** 🟢 Easy

---

## โจทย์

ถ้า score = 55 และเกณฑ์ 50 ผลคือ Pass — จงเขียนให้ได้ผลนั้น

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

1 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Pass
```


---

## Starter Code

```python
score = 55
if score >= 50:
    print("Pass")
else:
    print("Fail")
```
