## โจทย์

อ่านโค้ดด้านล่าง **โดยไม่รัน** แล้วเขียนว่า output คืออะไร
จากนั้นรันเพื่อตรวจสอบ

```python
numbers = [2, 5, 3, 8, 1]
result = 0

for n in numbers:
    if n % 2 == 0:
        result += n

print(result)
```
