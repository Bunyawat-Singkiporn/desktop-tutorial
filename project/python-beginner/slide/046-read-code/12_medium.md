# 👀 Read Code — ข้อ 12: ผลลัพธ์ dict อัปเดต

**Difficulty:** 🟡 Medium

---

## โจทย์

เริ่ม `d = {"a": 1}` แล้วตั้ง `d["a"] = 5` และเพิ่ม `d["b"] = 2` แล้วพิมพ์ d

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

1 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
{'a': 5, 'b': 2}
```


---

## Starter Code

```python
d = {"a": 1}
d["a"] = 5
d["b"] = 2
print(d)
```
