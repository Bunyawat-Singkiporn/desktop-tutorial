# 👀 Read Code — ข้อ 9: ทำนาย list สะสม

**Difficulty:** 🟢 Easy

---

## โจทย์

เริ่ม list ว่าง เพิ่ม 1 แล้ว 2 แล้วพิมพ์ list

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

1 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
[1, 2]
```


---

