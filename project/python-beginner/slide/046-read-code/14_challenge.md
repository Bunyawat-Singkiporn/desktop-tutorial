# 👀 Read Code — ข้อ 14: ทำนาย while สั้น

**Difficulty:** 🔴 Challenge

---

## โจทย์

เริ่ม x = 0 ขณะ x < 3 พิมพ์ x แล้ว x += 1

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
0
1
2
```


---

## 💡 Hint

ระวังเงื่อนไขหยุด

---

## Starter Code

```python
x = 0
while x < 3:
    print(x)
    x += 1
```
