# 🏋️ Dict Practice — ข้อ 7: แปลสีสั้นๆ

**Difficulty:** 🟡 Medium

---

## โจทย์

พจนานุกรมแปลสี

กำหนด `colors = {"red": "แดง", "blue": "น้ำเงิน", "green": "เขียว"}`

รับคำภาษาอังกฤษจากผู้ใช้ด้วย `input("color: ")` แล้วแสดงคำแปล
(ตัวอย่างใส่ `blue`)

> หมายเหตุ: prompt ของ input จะโผล่ใน Output ด้วย

---

## Input

1 บรรทัด — ชื่อสีภาษาอังกฤษ

## Output

บรรทัดเดียว (รวม prompt)

---

## ตัวอย่าง

**Input:**

```text
blue
```

**Output:**

```text
color: น้ำเงิน
```


---

## Starter Code

```python
colors = {"red": "แดง", "blue": "น้ำเงิน", "green": "เขียว"}

# เขียนโค้ดตรงนี้
```
