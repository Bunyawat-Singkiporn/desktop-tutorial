# 🏋️ Dict Practice — ข้อ 14: นับสินค้าแล้วเรียงคีย์

**Difficulty:** 🔴 Challenge

---

## โจทย์

นับสินค้าจากรายการสั่งซื้อ

กำหนด `items = ["pen", "book", "pen", "glue", "book", "pen"]`

นับความถี่ แล้วพิมพ์คีย์เรียงตามตัวอักษรพร้อมจำนวน
(สร้าง list จากคีย์ แล้ว sort ก่อนพิมพ์)

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
book: 2
glue: 1
pen: 3
```
