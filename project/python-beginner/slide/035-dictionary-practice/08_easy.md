# Practice Dictionary — Question 7: อัปเดตคะแนนเกม

**Difficulty:** 🟢 Easy

---

## โจทย์

คะแนนเกมเริ่มที่ 10 — ผู้เล่นได้คะแนนเพิ่ม ให้เปลี่ยนเป็น 25 แล้วแสดงผล

```python
player = {"name": "Hero", "score": 10}
```

**Output:**
```
Before: 10
After: 25
```

---

## 💡 Hint

`player["score"] = 25`

---

## Starter Code

```python
player = {"name": "Hero", "score": 10}

print(f"Before: {player['score']}")
# อัปเดตคะแนนที่นี่
print(f"After: {player['score']}")
```
