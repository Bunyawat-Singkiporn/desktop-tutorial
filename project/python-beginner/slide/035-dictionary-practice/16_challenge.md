# 🏋️ Dict Practice — ข้อ 16: สรุปออเดอร์สองชิ้น

**Difficulty:** 🔴 Challenge

---

## โจทย์

รับชื่อสินค้าสองชิ้นแล้วรวมราคา

กำหนด `prices = {"pen": 10, "book": 45, "glue": 20}`

ใช้ `input("item1: ")` และ `input("item2: ")` แล้วแสดงราคารวม
ตัวอย่าง: book / glue

> หมายเหตุ: prompt จะโผล่ใน Output — เพื่อให้อ่านง่ายให้พิมพ์ผลลัพธ์คนละบรรทัดหลังรับครบ

---

## Input

2 บรรทัด — ชื่อสินค้า

## Output

รวม prompt + ยอด

---

## ตัวอย่าง

**Input:**

```text
book
glue
```

**Output:**

```text
item1: item2: Total: 65
```
