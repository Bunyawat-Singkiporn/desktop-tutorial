# Practice Dictionary — Question 8: เพิ่มเบอร์โทร

**Difficulty:** 🟢 Easy

---

## โจทย์

สมุดติดต่อยังไม่มีเบอร์ — เพิ่ม key `"phone"` เป็น `"0812345678"` แล้วแสดงทั้ง dict

```python
contact = {"name": "Bob", "city": "Bangkok"}
```

**Output:**
```
{'name': 'Bob', 'city': 'Bangkok', 'phone': '0812345678'}
```

---

## Starter Code

```python
contact = {"name": "Bob", "city": "Bangkok"}

# เพิ่ม phone ที่นี่
print(contact)
```
