# Practice Dictionary — Question 5: บัตรนักเรียน

**Difficulty:** 🟢 Easy

---

## โจทย์

สร้าง dictionary ของนักเรียนคนหนึ่ง แล้วแสดงข้อมูล

```python
student = {"name": "Alice", "age": 12, "grade": "M1"}
```

**Output:**
```
Name: Alice
Age: 12
Grade: M1
```

---

## Starter Code

```python
student = {"name": "Alice", "age": 12, "grade": "M1"}

print(f"Name: {student['name']}")
# เขียน Age และ Grade ต่อ
```
