# 🏋️ Dict Practice — ข้อ 3: เพิ่มเบอร์โทร

---

## โจทย์

โปรไฟล์ยังไม่มีเบอร์

เพิ่ม `phone` เป็น `081-222-3333` แล้วแสดงเบอร์

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

บรรทัดเดียว

---

## ตัวอย่าง

**Output:**

```text
Phone: 081-222-3333
```
