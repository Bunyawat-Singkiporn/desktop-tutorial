# 🔲 nested-loops — ข้อ 14: ผังที่นั่งห้องเรียน

**Difficulty:** 🔴 Challenge

---

## โจทย์

ห้องมี 3 แถว ละ 4 ที่
พิมพ์ผังแบบนี้: ขึ้นต้นแต่ละแถวด้วย `Row{n}:` แล้วตามด้วยรหัสที่นั่ง `A` `B` `C` `D` คั่นช่องว่าง
หมายเลขแถวเริ่มที่ 1

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

3 บรรทัดผังที่นั่ง

---

## ตัวอย่าง

**Output:**

```text
Row1: A B C D 
Row2: A B C D 
Row3: A B C D 
```
