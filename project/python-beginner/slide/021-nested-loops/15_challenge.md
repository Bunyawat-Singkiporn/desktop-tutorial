# 🔲 nested-loops — ข้อ 15: ตารางคูณตาม n

**Difficulty:** 🔴 Challenge

---

## โจทย์

รับจำนวนเต็ม `n` แล้วพิมพ์ตารางคูณขนาด n×n (แถวและคอลัมน์เริ่มที่ 1)
แต่ละช่องคั่นด้วยแท็บ

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

ตารางคูณ n×n

---

## ตัวอย่าง

**Input:**

```text
3
```

**Output:**

```text
1	2	3	
2	4	6	
3	6	9	
```


---

## 💡 Hint

ทั้งสองลูปใช้ range(1, n + 1)

---

## Starter Code

```python
n = int(input())

# เขียนลูปซ้อน
```
