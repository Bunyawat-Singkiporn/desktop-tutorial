# 🔲 nested-loops — ข้อ 10: สติกเกอร์ติดแผ่น

**Difficulty:** 🟡 Medium

---

## โจทย์

แผ่นสติกเกอร์มี `rows` แถว และ `cols` คอลัมน์
รับสองค่าแล้วพิมพ์ `#` เต็มแผ่น

---

## Input

จำนวนแถว 1 บรรทัด แล้วจำนวนคอลัมน์ 1 บรรทัด

## Output

ตาราง # ตามขนาดที่รับ

---

## ตัวอย่าง

**Input:**

```text
2
3
```

**Output:**

```text
###
###
```


---

## 💡 Hint

แถวและคอลัมน์มาจาก input ทั้งคู่

---

## Starter Code

```python
rows = int(input())
cols = int(input())

# เขียนลูปซ้อน
```
