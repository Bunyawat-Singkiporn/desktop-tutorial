# 📚 Collection Review — ข้อ 11: กรองคะแนนแล้วตัดซ้ำ

**Difficulty:** 🟡 Medium

---

## โจทย์

กรองคะแนน >= 50 แล้วตัดค่าซ้ำ

กำหนด `scores = [40, 70, 70, 90, 40, 55]`

แสดงค่าที่ผ่านแบบไม่ซ้ำเรียง

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

list หนึ่งบรรทัด

---

## ตัวอย่าง

**Output:**

```text
[55, 70, 90]
```


---

## 💡 Hint

กรองด้วย list ก่อน แล้วค่อย set

---
