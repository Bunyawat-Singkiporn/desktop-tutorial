## โจทย์

```python
rgb = (255, 128, 0)
```

**ต้องทำ:**
1. แสดงค่า r, g, b แยกกัน
2. วน loop แสดงทุกค่า
3. print ว่า `"RGB values are fixed"` เพื่อสื่อ immutability

**Output:**
```
R: 255
G: 128
B: 0
All values: 255 128 0
RGB values are fixed
```
