# 📚 Collection Review — ข้อ 12: คิว list กับวัน tuple

**Difficulty:** 🟡 Medium

---

## โจทย์

คิวเป็น list วันเปิดเป็น tuple

กำหนด `queue = ["A1", "A2"]` append `A3`
และ `open_days = ("Mon", "Wed", "Fri")`

แสดงคิวและวันเปิดวันแรก

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

2 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
['A1', 'A2', 'A3']
Mon
```


---

## 💡 Hint

list แก้ได้ tuple คงที่

---

## Starter Code

```python
queue = ["A1", "A2"]
open_days = ("Mon", "Wed", "Fri")

# เขียนโค้ดตรงนี้
```
