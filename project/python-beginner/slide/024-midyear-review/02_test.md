# 🏆 Practice: Mid-Year Review — Question 1: Name & Grade

**Difficulty:** 🟢 Easy

---

## โจทย์

รับชื่อและคะแนน แล้วแสดงเกรด

**Input:**
```
Alice
85
```

**Output:**
```
Name: Alice
Score: 85
Grade: A
```

> เกรด: A = 80+, B = 60–79, C = ต่ำกว่า 60

---

## 💡 Hint

ใช้ `if / elif / else` ตรวจเกรด

---

```python
name = input()
score = int(input())
```
