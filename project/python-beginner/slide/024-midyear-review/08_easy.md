# 🏆 midyear-review — ข้อ 8: พิมพ์เลข 1 ถึง n

**Difficulty:** 🟢 Easy

---

## โจทย์

รับ `n` แล้วพิมพ์เลขจาก 1 ถึง n ทีละบรรทัด

---

## Input

จำนวนเต็ม n 1 บรรทัด

## Output

เลข 1 ถึง n

---

## ตัวอย่าง

**Input:**

```text
4
```

**Output:**

```text
1
2
3
4
```


---

## Starter Code

```python
n = int(input())

# วนพิมพ์
```
