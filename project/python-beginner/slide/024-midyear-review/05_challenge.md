# 🏆 midyear-review — ข้อ 5: ใบเสร็จร้านกาแฟ

**Difficulty:** 🔴 Challenge

---

## โจทย์

รับชื่อเมนู ราคากาแฟ และราคขนม (จำนวนเต็ม)
คำนวณยอดรวม แล้วพิมพ์ใบเสร็จในกรอบดังตัวอย่าง

---

## Input

ชื่อเมนู 1 บรรทัด แล้วราคากาแฟ 1 บรรทัด แล้วราคขนม 1 บรรทัด

## Output

ใบเสร็จในกรอบ

---

## ตัวอย่าง

**Input:**

```text
Latte
55
20
```

**Output:**

```text
====================
      COFFEE
====================
Menu  : Latte
Coffee: 55
Snack : 20
Total : 75
====================
```


---

## 💡 Hint

จัดคอลัมน์เครื่องหมาย : ให้ตรงกัน

---

## Starter Code

```python
menu = input()
coffee = int(input())
snack = int(input())

# พิมพ์ใบเสร็จ
```
