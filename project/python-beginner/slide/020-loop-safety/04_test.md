# 💬 loop-safety — ข้อ 4: พิมพ์ข้อความจนเจอ stop

**Difficulty:** 🟢 Easy

---

## โจทย์

ใช้ `while True` รับข้อความ
ถ้าได้ `"stop"` ให้ `break`
ข้อความอื่นให้พิมพ์กลับในรูปแบบ `Echo: <ข้อความ>`

---

## Input

ข้อความทีละบรรทัด จบด้วย stop

## Output

Echo ของข้อความก่อน stop

---

## ตัวอย่าง

**Input:**

```text
hi
python
stop
```

**Output:**

```text
Echo: hi
Echo: python
```
