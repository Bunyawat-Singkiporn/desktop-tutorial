# 🏫 loop-safety — ข้อ 15: นับคนเข้าเรียนข้าม Absent

---

## โจทย์

มีลิสต์สถานะนักเรียน
- ค่า `"END"` → break (ไม่นับ)
- ค่า `"Absent"` → continue
- อื่นๆ → นับเป็นคนมาเรียน
แสดงจำนวนคนมาเรียน

ไม่มี

## Output
