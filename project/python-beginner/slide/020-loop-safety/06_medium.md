# Practice: Loop Safety — Medium A: หยุดเมื่อเจอคำ quit

**Difficulty:** 🟡 Medium

---

## โจทย์

รับข้อความซ้ำด้วย while True — ถ้าได้ `quit` ให้ break ไม่ต้องพิมพ์ quit; คำอื่นพิมพ์ `Echo: ...`


---

## ตัวอย่าง Input / Output

**Input:**
```
hi
quit
```
**Output:**
```
Echo: hi
```

---

## 💡 Hint

break

---

## Starter Code

```python
while True:
    word = input()

```
