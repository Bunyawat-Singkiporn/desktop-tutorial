# 🐛 Debugging — ข้อ 3: กันหารศูนย์

**Difficulty:** 🟢 Easy

---

## โจทย์

หารตัวเลขสองค่า แต่ห้ามให้โปรแกรมพังเมื่อตัวหารเป็น 0

**เงื่อนไข:**

- รับ a และ b
- ถ้า b == 0 พิมพ์ `Cannot divide`
- ไม่งั้นพิมพ์ผล `a / b` ทศนิยม 1 ตำแหน่ง

---

## Input

ดูตัวอย่าง

## Output

1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
10
0
```

**Output:**

```text
Cannot divide
```


---

## 💡 Hint

เช็ก b ก่อนหาร

---

## Starter Code

```python
a = int(input())
b = int(input())

# กันหารศูนย์
```
