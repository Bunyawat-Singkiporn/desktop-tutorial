# 🐛 Debugging — ข้อ 10: ตรวจตัวหารก่อน

**Difficulty:** 🟡 Medium

---

## โจทย์

หาค่าเฉลี่ยจากจำนวนชิ้น

**เงื่อนไข:**

- รับ total และ count
- ถ้า count == 0 พิมพ์ `No data`
- ไม่งั้นพิมพ์ average ทศนิยม 1 ตำแหน่ง

---

## Input

ดูตัวอย่าง

## Output

1 บรรทัด

---

## ตัวอย่าง

**Input:**

```text
100
0
```

**Output:**

```text
No data
```


---

## 💡 Hint

เช็ก count ก่อน

---

## Starter Code

```python
total = int(input())
count = int(input())

# กันหารศูนย์
```
