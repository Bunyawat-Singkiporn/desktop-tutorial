# 🐛 Debugging — ข้อ 8: แปลงก่อนบวก

**Difficulty:** 🟢 Easy

---

## โจทย์

ผู้ใช้พิมพ์ตัวเลขเป็นข้อความ ต้องแปลงก่อนบวก

**เงื่อนไข:**

- รับสองบรรทัดเป็นข้อความตัวเลข
- แปลงเป็น int แล้วพิมพ์ผลบวก

---

## Input

ดูตัวอย่าง

## Output

1 บรรทัด

---

## ตัวอย่าง

```text

5
```

```text
8
```
