# 🐛 Debugging — ข้อ 12: แก้ชื่อตัวแปรผิด

**Difficulty:** 🟡 Medium

---

## โจทย์

พิมพ์ราคาสุทธิจากตัวแปรที่ตั้งชื่อไว้

**เงื่อนไข:**

- มี `price = 120` และ `discount = 20`
- คำนวณ `final_price` แล้วพิมพ์ `Pay: <final_price>`
- อย่าพิมพ์ชื่อตัวแปรผิด

---

## Input

ไม่มี (กำหนดค่าในโปรแกรม)

## Output

1 บรรทัด

---

## ตัวอย่าง

**Output:**

```text
Pay: 100
```


---

## 💡 Hint

ใช้ชื่อให้ตรงกับที่ประกาศ

---

## Starter Code

```python
price = 120
discount = 20

# คำนวณแล้วพิมพ์
```
