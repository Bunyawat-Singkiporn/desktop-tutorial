# 🐛 Debugging — Question 1: Fix Syntax Error

**Difficulty:** 🟢 Easy

---

## โจทย์

โค้ดด้านล่างมี **Syntax Error** — หาและแก้ให้รันได้

```python
score = 75

if score >= 50
    print("Pass")
else
    print("Fail")
```

**Output ที่ถูกต้อง:**
```
Pass
```

---

## 💡 Hint

Python ต้องการ `:` หลัง `if` และ `else` ทุกครั้ง

---

## Starter Code

```python
score = 75

# แก้ syntax error ด้านล่าง
if score >= 50
    print("Pass")
else
    print("Fail")
```
