# 🧮 Practice: Review — Question 2: Simple Calculator

**Difficulty:** 🟡 Medium

---

## Problem

Get 2 numbers, then display +, -, *, / results.

**Input:**
```
10
3
```

**Output:**
```
10 + 3 = 13
10 - 3 = 7
10 * 3 = 30
10 / 3 = 3.33
```

---

## 💡 Hint

- Use an f-string: `f"{a} + {b} = {a + b}"`
- For division use `{a / b:.2f}` to show only 2 places
