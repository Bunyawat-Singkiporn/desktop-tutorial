# ❌ Practice List Methods — Question 2: Remove Item

**Difficulty:** 🟢 Easy

---

## Problem

Set the fruit list, delete `"banana"` and display it.

```python
fruits = ["apple", "banana", "mango", "orange"]
```

**Output:**
```
['apple', 'mango', 'orange']
```

---

## 💡 Hint

Use `.remove("banana")`

---

## Starter Code

```python
fruits = ["apple", "banana", "mango", "orange"]

# remove banana

print(fruits)
```
