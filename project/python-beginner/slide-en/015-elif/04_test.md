## Task
สวนสนุกแบ่งประเภทตั๋วตามอายุผู้เข้าชม
เขียนโปรแกรมรับอายุ แล้วบอกประเภทตั๋ว
**Rules:**
- อายุ `>= 60` → `Senior`
- อายุ `>= 18` → `Adult`
- อายุ `>= 13` → `Teen`
- น้อยกว่านั้น → `Child`
---
## Input
อายุเป็นจำนวนเต็ม 1 บรรทัด
## Output
ประเภทตั๋ว 1 บรรทัด
---
## Example
**Input:**
```text
15
```

**Output:**

```text
Teen
```
