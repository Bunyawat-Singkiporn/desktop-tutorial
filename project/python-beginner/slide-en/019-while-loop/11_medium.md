# 📊 while-loop — Q11: นับคะแนนจนเจอศูนย์

**Difficulty:** 🟡 Medium

---

## Task

รับคะแนนทีละตัว จนเจอ `0` (ไม่นับ 0)
นับว่ามีคะแนนกี่ตัว แล้วแสดงจำนวน

---

## Input

คะแนนทีละบรรทัด จบด้วย 0

## Output

Count: <จำนวน>

---

## Example

**Input:**

```text
80
70
90
0
```

**Output:**

```text
Count: 3
```
