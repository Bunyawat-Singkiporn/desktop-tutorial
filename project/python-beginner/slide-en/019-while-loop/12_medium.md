# 🏧 while-loop — Q12: ใส่ PIN จนถูกต้อง

**Difficulty:** 🟡 Medium

---

## Task

PIN ที่ถูกต้องคือ `"1234"`
รับ PIN ซ้ำจนถูก แล้วพิมพ์ `PIN OK`

---

## Input

PIN ทีละบรรทัด

## Output

PIN OK เมื่อถูกต้อง

---

## Example

**Input:**

```text
0000
1111
1234
```

**Output:**

```text
PIN OK
```

---

## Hint

while pin != "1234" แล้วรับใหม่
