# 🔀 Practice: Syntax — Question 3: Mixed Errors

**Difficulty:** 🟡 Medium

---

## Problem

The code below has **3 different types of errors**. Find and fix them all.

```python
Print("==========")
print("MY PROFILE"
  print("==========")
print("Name: Jordan")
```

**Required Output:**
```
==========
MY PROFILE
==========
Name: Jordan
```

---

## 💡 Hint

3 types of errors:
- `NameError` — typo
- `SyntaxError` — missing symbols
- `IndentationError` — paragraph exceeded
