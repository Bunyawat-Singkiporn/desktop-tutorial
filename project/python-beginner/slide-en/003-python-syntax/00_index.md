## Notes for teachers

- Unlike Lesson 002 (read errors and fix), this lesson focuses on **checking code against rules before running**.
- New but essential topic not spelled out in the slide: **two quote types** (`"` and `'`), taught in Q7 and reused in Q12 and Q14 — students will need this for quoted text inside strings.
- Q11 clears a common mistake: “no leading spaces” means at the **start of a code line**, not spaces inside quoted text.
- Q15 piece 5 (`print ("E")`) runs fine — use it to see if students understand rules vs memorization.
