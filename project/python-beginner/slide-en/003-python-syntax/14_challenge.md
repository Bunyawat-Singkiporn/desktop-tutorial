# 🧠 Python syntax rules — Q13: Quote puzzle

**Difficulty:** 🔴 Challenge

---

## Task

Write a program that prints these three lines, each with quotes inside the text:

```text
He said "hello" to me
It's a sunny day
She wrote 'python' on the board
```

> Line 1 has `"` · line 2 has `'` · line 3 has `'`
> Pick outer quotes that fit each line.

---

## Example

**Output:**

```text
He said "hello" to me
It's a sunny day
She wrote 'python' on the board
```

---

## Hint

Simple rule — if `"` is inside, wrap with `'`. If `'` is inside, wrap with `"`.
Never use the same quote type outside and inside.
