# 💬 Python syntax rules — Q7: Nested quotes

**Difficulty:** 🟡 Medium

---

## Task

You want to print text that **contains quote marks inside**, for example:

```text
The sign says "Do Not Enter"
```

If you use `"` both outside and inside, Python cannot tell where the string ends.
Use `'` on the outside and `"` inside.

Write a program that shows 2 lines as in the example.

---

## Input

None

## Output

Two lines that contain quote marks inside the text

---

## Example

**Output:**

```text
The sign says "Do Not Enter"
Teacher said "Good job"
```

---

## Hint

Outside: single quotes `'`. Inside: double quotes `"`.
Then Python knows where the string ends.
