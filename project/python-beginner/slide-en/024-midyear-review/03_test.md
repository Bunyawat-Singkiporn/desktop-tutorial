# 🏆 midyear-review — Q3: คิดเงินทอน

**Difficulty:** 🟢 Easy

---

## Task

รับราคาสินค้าและเงินที่จ่าย (จำนวนเต็ม) แล้วพิมพ์เงินทอน

---

## Input

ราคา 1 line แล้วเงินที่จ่าย 1 line

## Output

บรรทัดเดียว Change: <เงินทอน>

---

## Example

**Input:**

```text
70
100
```

**Output:**

```text
Change: 30
```


---

```python
price = int(input())
paid = int(input())

# คำนวณแล้วพิมพ์
```
