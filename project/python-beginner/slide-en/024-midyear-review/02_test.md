# 🏆 Practice: Mid-Year Review — Question 1: Name & Grade

**Difficulty:** 🟢 Easy

---

## Problem

Get name and score, then show grade.

**Input:**
```
Alice
85
```

**Output:**
```
Name: Alice
Score: 85
Grade: A
```

> Grade: A = 80+, B = 60–79, C = below 60

---

## 💡 Hint

Use `if / elif / else` to check grades.

---

## Starter Code

```python
name = input()
score = int(input())

print(f"Name: {name}")
print(f"Score: {score}")

# Determine and print grade
```
