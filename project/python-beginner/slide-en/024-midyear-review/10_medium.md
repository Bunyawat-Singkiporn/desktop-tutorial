# 🏆 midyear-review — Q10: รวมยอดจนเจอ 0

**Difficulty:** 🟡 Medium

---

## Task

รับจำนวนเต็มทีละบรรทัดจนเจอ `0` แล้วพิมพ์ผลรวมของค่าก่อนหน้า

---

## Input

จำนวนเต็มทีละบรรทัด จบด้วย 0

## Output

บรรทัดเดียว Total

---

## Example

**Input:**

```text
5
7
6
0
```

**Output:**

```text
Total: 18
```


---

## 💡 Hint

เจอ 0 ให้หยุดโดยไม่บวก

---

## Starter Code

```python
total = 0

# while True จน 0
```
