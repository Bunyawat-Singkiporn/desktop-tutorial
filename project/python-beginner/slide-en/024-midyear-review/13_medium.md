# 🏆 midyear-review — Q13: เกรดจากคะแนน

**Difficulty:** 🟡 Medium

---

## Task

รับคะแนนแล้วพิมพ์เกรด
- `>= 80` → `A`
- `>= 60` → `B`
- น้อยกว่านั้น → `C`

---

## Input

คะแนนจำนวนเต็ม 1 line

## Output

บรรทัดเดียว Grade: <ตัวอักษร>

---

## Example

**Input:**

```text
65
```

**Output:**

```text
Grade: B
```


---

```python
score = int(input())

# หาเกรด
```
