# 🏆 midyear-review — Q5: receiptร้านกาแฟ

**Difficulty:** 🔴 Challenge

---

## Task

รับชื่อเมนู ราคากาแฟ และราคขนม (จำนวนเต็ม)
คำนวณยอดรวม แล้วพิมพ์receiptในกรอบดังตัวอย่าง

---

## Input

ชื่อเมนู 1 line แล้วราคากาแฟ 1 line แล้วราคขนม 1 line

## Output

receiptในกรอบ

---

## Example

**Input:**

```text
Latte
55
20
```

**Output:**

```text
====================
      COFFEE
====================
Menu  : Latte
Coffee: 55
Snack : 20
Total : 75
====================
```


---

## 💡 Hint

จัดคอลัมน์เครื่องหมาย : ให้ตรงกัน

---

## Starter Code

```python
menu = input()
coffee = int(input())
snack = int(input())

# พิมพ์receipt
```
