# 💻 What is Programming?

---

## Imagine this...

Suppose you have a **robot** friend 🤖

The robot will do everything you tell it — but it does not understand Thai!

> You must speak to it in a **special language** it understands.
> That special language is... a **programming language** 🎯

---

## What is Programming?

**Programming** means writing instructions for a computer to follow.

It is like writing a **recipe** 🍳 for someone to cook:

| Recipe (real life) | Program (computer) |
|--------------------|--------------------|
| "Turn on the stove" | Start the program |
| "Put the egg in the pan" | Get input |
| "Wait 3 minutes" | Process data |
| "Serve on a plate" | Show output |

---

## What is Python?

**Python** is one programming language.

There are many programming languages, just like human languages:

| Human language | Programming language |
|----------------|----------------------|
| Thai | Python |
| English | JavaScript |
| Japanese | Java |

> Python is **easy to read and easy to learn** — great for beginners!

## Your first command — `print()`

`print()` tells the computer to **show text on the screen**.

```python
print("Hello, World!")
```

Output:
```
Hello, World!
```

> Text must always be inside `"..."` quotes

---

## Example: `print()` several times

```python
print("Hello!")
print("My name is Python")
print("Nice to meet you")
```

Output:
```
Hello!
My name is Python
Nice to meet you
```

> Each `print()` starts a new line automatically
