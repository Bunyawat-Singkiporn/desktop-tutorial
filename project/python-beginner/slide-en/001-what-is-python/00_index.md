## Notes for teachers

- Exercise 02 is **not** the same as the lesson demo (the lesson uses `print("Hello, World!")` and a three-line Thai greeting).
- The whole lesson uses only `print` and strings — difficulty scales from **number of lines → column alignment → borders → centering**.
- Exercise 09 is the first time students see empty `print()` for spacing; reuse that in 13 and 16.
- All four Challenge items use **no new commands** — the hard part is **counting spaces carefully**, which matters later for f-strings and reports.
- Students often forget closing quotes/parentheses — use this lesson to practice reading SyntaxError before Lesson 002.
