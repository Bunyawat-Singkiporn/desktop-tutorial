# ✅ Readiness Self-Assessment — Check Your Readiness

## Instructions

Mark the skills you feel confident about with ✅.
If you are still unsure about a skill, review that lesson.

---

## Phase 1 Checklist

### 🔹 Fundamentals (Lessons 001–024)
- [ ] I can explain what Python is.
- [ ] I can create and use variables.
- [ ] I know the `int`, `float`, `str`, and `bool` data types.
- [ ] I can receive input and display output.
- [ ] I can use `if`/`elif`/`else`.
- [ ] I can use `for` and `while` loops.
- [ ] I understand nested loops.

### 🔹 Collections (Lessons 025–036)
- [ ] I can create and use a list.
- [ ] I can use `append`, `remove`, and `sort`.
- [ ] I understand the differences among lists, tuples, and sets.
- [ ] I can create and use a dictionary.
- [ ] I can loop through a dictionary with `.items()`.

### 🔹 Functions (Lessons 037–040)
- [ ] I can create a function with `def`.
- [ ] I can pass parameters to a function.
- [ ] I can use `return` and store the result.
- [ ] I can use functions with lists and dictionaries.

### 🔹 Advanced (Lessons 041–043)
- [ ] I understand local and global scope.
- [ ] I can identify the type of a bug.
- [ ] I can write readable code with clear names.
