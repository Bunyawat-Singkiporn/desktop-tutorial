# 💰 Practice: Operators — Question 2: Change Calculator

**Difficulty:** 🟡 Medium

---

## Problem

Get the product price and amount paid, then calculate the change.

**Input:**
```
45
100
```

**Output:**
```
Price: 45
Paid: 100
Change: 55
```

---

## 💡 Hint

- Change = paid - price
- Use `-` to subtract

---
