# 🔁 Practice: Loop Review — Question 1: Sum with for

**Difficulty:** 🟢 Easy

---

## Problem

Get n and add the numbers from 1 to n.

**Input:**
```
5
```

**Output:**
```
Sum from 1 to 5 = 15
```

---

## 💡 Hint

- Use `for i in range(1, n+1):`
- Accumulated in `total`

---

## Starter Code

```python
n = int(input())
total = 0

for i in range(1, n + 1):
    # Add i to total
```
