# 🔥 Practice for Loop — Question 4: Multiplication Table

**Difficulty:** 🔴 Hard

---

## Problem

Read a number N, then display the **multiplication table** for N from 1 to 10.

> Mix skills: for loop + range + input + string formatting

---

## Example

**Input:**
```
3
```

**Output:**
```
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30
```

---

## 💡 Hint

- Use `range(1, 11)` to loop from 1 to 10
- Calculate `n * i` each round
- Use `print(f"...")` or `print(n, "x", i, "=", n * i)`
