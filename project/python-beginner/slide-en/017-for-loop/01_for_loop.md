♪ What's Loop?

Loop is to get computers to run over without repeating their code.

Instead of writing like this...```python
print("Hello")
print("Hello")
print("Hello")
print("Hello")
print("Hello")
```We can write this! **```python
for i in range(5):
    print("Hello")
```---

What?

5 times

& Always stop before a given number```python
for i in range(5):
    print(i)
```The result:```

4
