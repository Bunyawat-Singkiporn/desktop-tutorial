# 🔢 Practice for Loop — Question 3: Count to N

**Difficulty:** 🟡 Medium

---

## Problem

Read a number N, then display numbers 1 to N, one per line.

---

## Example

**Input:**
```
5
```

**Output:**
```
1
2
3
4
5
```

---

## 💡 Hint

Use `range(1, n + 1)` so N is included
