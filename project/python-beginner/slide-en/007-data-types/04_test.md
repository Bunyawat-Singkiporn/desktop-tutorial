# 👤 Practice: Data Types — Question 3: Character Profile

**Difficulty:** 🟡 Medium

---

## Problem

Create a game character profile using all 4 data types, then display it.

| Variable | Value | Type |
|----------|-------|------|
| `hero_name` | `"Shadow"` | str |
| `hero_level` | `10` | int |
| `hero_hp` | `99.5` | float |
| `is_alive` | `True` | bool |

**Output:**
```
=== Character Profile ===
Name: Shadow
Level: 10
HP: 99.5
Alive: True
```

---

## 💡 Hint

Use `print("Label:", variable)` for each line

---

## Starter Code

```python
hero_name = "Shadow"
hero_level = 10
hero_hp = 99.5
is_alive = True

# Print profile
```
