# 🐛 Debugging — Q3: กันหารศูนย์

**Difficulty:** 🟢 Easy

---

## Task

หารตัวเลขสองค่า แต่ห้ามให้โปรแกรมพังเมื่อตัวหารเป็น 0

**Requirements:**

- รับ a และ b
- ถ้า b == 0 พิมพ์ `Cannot divide`
- ไม่งั้นพิมพ์ผล `a / b` ทศนิยม 1 ตำแหน่ง

---

## Input

See example

## Output

1 line(s)

---

## Example

**Input:**

```text
10
0
```

**Output:**

```text
Cannot divide
```


---

## Hint

เช็ก b ก่อนหาร

---

## Starter Code

```python
a = int(input())
b = int(input())

# กันหารศูนย์
```
