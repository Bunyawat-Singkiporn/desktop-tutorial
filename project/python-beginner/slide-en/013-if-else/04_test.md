# 🏷️ Practice if/else — Question 3: Discount

**Difficulty:** 🟡 Medium

---

## Problem

Get product price. If price >= 100 baht, get 10 baht discount and show the final price.

|condition| Output |
|----------|--------|
|Price >= 100|Show price after deducting 10 baht|
|Price < 100|Show original price|

---

## example

**Input:**
```
120
```

**Output:**
```
110
```

**Input:**
```
80
```

**Output:**
```
80
```
