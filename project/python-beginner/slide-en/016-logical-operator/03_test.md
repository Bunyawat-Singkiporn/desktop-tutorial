## Problem

Read an amount of money and member status, then check whether a discount is given.

**Conditions:** both must pass
- money >= 100
- is a member (`True`)

| Result | Output |
|--------|--------|
| Both pass | `Discount` |
| Fail | show nothing |

---

## Example

**Input:**
```
150
True
```

**Output:**
```
Discount
```
