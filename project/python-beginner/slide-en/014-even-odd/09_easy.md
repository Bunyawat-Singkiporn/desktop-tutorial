# 📝 Even/Odd — Q5: คะแนนรวมคู่หรือคี่
**Difficulty:** 🟢 Easy
---
## Task
ครูเก็บคะแนนกลางภาคกับปลายภาค แล้วดูว่าคะแนนรวมเป็นเลขคู่หรือเลขคี่
เพื่อจัดกลุ่มตรวจข้อสอบ
เขียนโปรแกรมรับคะแนนสองวิชา บวกรวม แล้วบอกว่าผลรวมเป็นคู่หรือคี่
**Rules:**
- คะแนนรวม `% 2 == 0` → `Even Total`
- ถ้าไม่ใช่ → `Odd Total`
> ข้อนี้ต่างจากข้อก่อนหน้า ตรงที่ต้อง **คำนวณก่อน** แล้วค่อยเช็คคู่/คี่
---
## Input
2 บรรทัด — คะแนนกลางภาค และคะแนนปลายภาค
## Output
2 บรรทัด — คะแนนรวม และสถานะคู่/คี่
---
## Example
**Input:**
```text
45
37
```

**Output:**

```text
Total  : 82
Status : Even Total
```

บวกคะแนนสองตัวเก็บไว้ในตัวแปรก่อน แล้วค่อยเอาผลรวมไป `% 2`
