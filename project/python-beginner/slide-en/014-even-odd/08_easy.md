# 🛗 Even/Odd — Q4: ลิฟต์ซ้าย-ขวา
**Difficulty:** 🟢 Easy
---
## Task
อาคารสำนักงานมีลิฟต์สองตัว
ชั้นเลขคู่ให้ขึ้นลิฟต์ซ้าย ชั้นเลขคี่ขึ้นลิฟต์ขวา
เขียนโปรแกรมรับหมายเลขชั้น แล้วบอกว่าควรขึ้นลิฟต์ฝั่งไหน
**Rules:**
- ชั้น `% 2 == 0` → `Go Left`
- ถ้าไม่ใช่ → `Go Right`
---
## Input
หมายเลขชั้นเป็นจำนวนเต็ม 1 บรรทัด
## Output
ทิศทางลิฟต์ 1 บรรทัด
---
## Example
**Input:**
```text
9
```

**Output:**

```text
Go Right
```
