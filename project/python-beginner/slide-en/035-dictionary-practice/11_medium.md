# 🏋️ Dict Practice — Q11: สั่งเครื่องดื่ม

**Difficulty:** 🟡 Medium

---

## Task

รับชื่อเครื่องดื่มแล้วบอกราคา

กำหนด `menu = {"latte": 55, "mocha": 60, "tea": 40}`

ใช้ `input("drink: ")` แล้วแสดงราคาในรูปแบบ `Price: ...`
(ตัวอย่างใส่ `mocha`)

> หมายเหตุ: prompt ของ input จะโผล่ใน Output ด้วย

---

## Input

1 lines — ชื่อเครื่องดื่ม

## Output

รวม prompt + ราคา

---

## Example

**Input:**

```text
mocha
```

**Output:**

```text
drink: Price: 60
```


---

## Hint

อ่านคีย์จาก input แล้วไปดูราคา

---

## Starter Code

```python
menu = {"latte": 55, "mocha": 60, "tea": 40}

# Write your code here
```
