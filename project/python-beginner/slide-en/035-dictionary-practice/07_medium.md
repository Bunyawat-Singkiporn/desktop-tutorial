# 🏋️ Dict Practice — Q7: แปลสีสั้นๆ

**Difficulty:** 🟡 Medium

---

## Task

พจนานุกรมแปลสี

กำหนด `colors = {"red": "แดง", "blue": "น้ำเงิน", "green": "เขียว"}`

รับคำภาษาอังกฤษจากผู้ใช้ด้วย `input("color: ")` แล้วแสดงคำแปล
(ตัวอย่างใส่ `blue`)

> หมายเหตุ: prompt ของ input จะโผล่ใน Output ด้วย

---

## Input

1 lines — ชื่อสีภาษาอังกฤษ

## Output

One line (รวม prompt)

---

## Example

**Input:**

```text
blue
```

**Output:**

```text
color: น้ำเงิน
```
