# 📞 Practice Dictionaries — Question 3: Contact Card

**Difficulty:** 🟡 Medium

---

## Problem

Given the contact information below, display every key-value pair in a clear format.

```python
contact = {
    "name": "Bob Smith",
    "phone": "081-234-5678",
    "city": "Bangkok",
    "email": "bob@email.com"
}
```

**Output:**
```
=== Contact Info ===
name: Bob Smith
phone: 081-234-5678
city: Bangkok
email: bob@email.com
```

---

## 💡 Hint

Use `for key in contact:` and print `key` and `contact[key]`.
