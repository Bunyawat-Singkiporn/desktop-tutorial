# Homework: elif — ข้อ 3: ระดับอากาศ

**Difficulty:** 🟢 Easy

---

## โจทย์

สถานีอากาศจัดระดับอุณหภูมิเป็น 3 ชั้น:

| เงื่อนไข | แสดง |
|----------|------|
| `t >= 35` | `Hot` |
| `t >= 20` (แต่ยังไม่ถึง 35) | `Warm` |
| นอกนั้น | `Cold` |

**ตัวอย่าง** Input `22` → `Warm` / Input `10` → `Cold`

---

## 💡 Hint

เรียง if → elif → else จากเงื่อนไขเข้มไปหลวม

---

## Starter Code

```python
t = int(input())
if t >= 35:
    # เขียนโค้ดตรงนี้
elif t >= 20:
    # เขียนโค้ดตรงนี้
else:
    # เขียนโค้ดตรงนี้
```
