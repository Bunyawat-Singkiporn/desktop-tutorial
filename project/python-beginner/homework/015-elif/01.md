---

## โจทย์

รับจำนวนเต็ม: มากกว่า 0 → `Pos`, น้อยกว่า 0 → `Neg`, เท่า 0 → `Zero`

**ตัวอย่าง** Input `-1` → `Neg`

---

## 💡 Hint

if / elif / else

---

## Starter Code

```python
n = int(input())
if n > 0:
    # เขียนโค้ดตรงนี้
elif n < 0:
    # เขียนโค้ดตรงนี้
else:
    # เขียนโค้ดตรงนี้
```
