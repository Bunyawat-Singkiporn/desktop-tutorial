# Homework: elif — ข้อ 4: เลเวลผู้เล่น

**Difficulty:** 🟢 Easy

---

## โจทย์

รับเลเวล: `>=10` High, `>=5` Mid, อื่นๆ Low

**ตัวอย่าง** Input `5` → `Mid`

---

## 💡 Hint

`>=` กับ elif

---

## Starter Code

```python
n = int(input())
if n >= 10:
    # เขียนโค้ดตรงนี้
elif n >= 5:
    # เขียนโค้ดตรงนี้
else:
    # เขียนโค้ดตรงนี้
```
