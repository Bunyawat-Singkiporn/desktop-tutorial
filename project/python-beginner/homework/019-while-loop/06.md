# Homework: while Loop — ข้อ 6: อ่านจนเจอศูนย์

**Difficulty:** 🟢 Easy

---

## โจทย์

รับจำนวนซ้ำ แสดงทุกจำนวนที่อ่านได้ จนกระทั่งอ่านได้ 0 (ไม่ต้องพิมพ์ 0)

**ตัวอย่าง**
Input:
```
4
5
0
```
Output:
```
4
5
```

---

## 💡 Hint

`while n != 0`

---

## Starter Code

```python
n = int(input())
while n != 0:
    # เขียนโค้ดตรงนี้
```
