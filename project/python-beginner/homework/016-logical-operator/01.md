## โจทย์

รับจำนวนสองตัว ถ้าทั้งคู่ `> 0` แสดง `Both` ไม่เช่นนั้น `No`

**ตัวอย่าง**
Input:
```
2
5
```
Output: `Both`

---

## 💡 Hint

ใช้ `and`

    # เขียนโค้ดตรงนี้
