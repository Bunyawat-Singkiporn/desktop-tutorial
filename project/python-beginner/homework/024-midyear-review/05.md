# Homework: Midyear Review — ข้อ 5: เกรดคร่าวๆ

**Difficulty:** 🟢 Easy

---

## โจทย์

ตัดเกรดแบบหยาบ 3 ระดับ:

| คะแนน | เกรด |
|--------|------|
| `>= 80` | `A` |
| `>= 60` | `B` |
| นอกนั้น | `C` |

**ตัวอย่าง** Input `75` → `B`

---

## 💡 Hint

เรียง if → elif → else

---

```python
    # เขียนโค้ดตรงนี้

    # เขียนโค้ดตรงนี้
```
