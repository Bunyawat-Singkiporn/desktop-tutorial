# Homework: Input — ข้อ 2: รับตัวเลขแล้วแสดง

**Difficulty:** 🟢 Easy

---

## โจทย์

เครื่องอ่านรหัสต้องการรับจำนวนเต็มแล้วแสดงกลับทันที

รับจำนวนเต็มหนึ่งค่าแล้วแสดงค่านั้น

**Input:**
```
42
```

**Output:**
```
42
```
