# Homework: Input — ข้อ 10: แสดงชื่อเมือง

**Difficulty:** 🟢 Easy

---

## โจทย์

แอปพยากรณ์อากาศถามชื่อเมืองแล้วแสดงกลับแบบมีป้ายกำกับ

รับชื่อเมือง แล้วแสดงในรูปแบบ `City: ...`

**Input:**
```
Chiang Mai
```

**Output:**
```
City: Chiang Mai
```

---

## 💡 Hint

ใช้ `print("City:", city)` เพื่อให้มีช่องว่างหลังโคลอน

---

## Starter Code

```python
city = input()
# แสดงผลตรงนี้
```
