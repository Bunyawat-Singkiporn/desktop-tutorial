# Homework: Input — ข้อ 7: ผลต่างสองจำนวน

**Difficulty:** 🟢 Easy

---

## โจทย์

เครื่องคิดเงินคำนวณส่วนต่างระหว่างสองยอด

รับจำนวนเต็มสองค่าคนละบรรทัด แล้วแสดงผลลบ `a - b`

**Input:**
```
10
3
```

**Output:**
```
7
```

---

## 💡 Hint

รับ `a` ก่อน `b` แล้ว `print(a - b)`

---

## Starter Code

```python
a = int(input())
b = int(input())
# แสดงผลตรงนี้
```
