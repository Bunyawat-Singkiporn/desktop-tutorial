# Homework: Input — ข้อ 9: ผลรวมสองจำนวน

**Difficulty:** 🟢 Easy

---

## โจทย์

รับจำนวนเต็มสองค่า แล้วแสดงผลบวก

**Input:**
```
4

```

**Output:**
```
9
```
