# Homework: Input — ข้อ 1: ทักทายจากชื่อที่พิมพ์

**Difficulty:** 🟢 Easy

---

## โจทย์

โปรแกรมต้อนรับแขกถามชื่อแล้วทักทายกลับ

รับชื่อจากแป้นพิมพ์ แล้วแสดง Hello, ตามด้วยชื่อนั้น

**Input:**
```
Mina
```

**Output:**
```
Hello, Mina
```

---

## 💡 Hint

ใช้ `input()` เก็บชื่อ แล้ว `print("Hello,", name)`

---

## Starter Code

```python
name = input()
# แสดงผลตรงนี้
```
