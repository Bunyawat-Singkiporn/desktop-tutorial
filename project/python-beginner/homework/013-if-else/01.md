# Homework: if/else — ข้อ 1: จำนวนบวกหรือไม่

**Difficulty:** 🟢 Easy

---

## โจทย์

รับจำนวนเต็ม ถ้ามากกว่า 0 แสดง `Positive` ไม่เช่นนั้นแสดง `Non-positive`

**ตัวอย่าง** Input `5` → `Positive` / Input `0` → `Non-positive`

---

## 💡 Hint

`if n > 0:` ... `else:`

---

## Starter Code

```python
n = int(input())
if n > 0:
    # เขียนโค้ดตรงนี้
else:
    # เขียนโค้ดตรงนี้
```
