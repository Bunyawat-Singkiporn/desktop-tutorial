# Homework: Output Formatting — ข้อ 4: แสดงจำนวนเต็มเป็นทศนิยมสองตำแหน่ง

**Difficulty:** 🟢 Easy

---

## โจทย์

รายงานการเงินต้องการให้เลข 2 แสดงแบบทศนิยมสองตำแหน่ง

กำหนด `y = 2` แล้วแสดงเป็นทศนิยม 2 ตำแหน่ง

**Output:**
```
2.00
```

---

## 💡 Hint

ใช้ `f"{y:.2f}"` แม้ค่าเดิมเป็นจำนวนเต็ม

y = 2
# แสดงผลตรงนี้
