# Homework: Comments — ข้อ 8: คั่นด้วยคอมเมนต์กลางทาง

**Difficulty:** 🟢 Easy

---

## โจทย์

โปรแกรมแสดง A แล้วมีคอมเมนต์คั่น ก่อนแสดง B

แสดง A และ B คนละบรรทัด โดยมี `# บรรทัดถัดไป` คั่นกลาง

**Output:**
```
A
B
```

---

## 💡 Hint

ลำดับคือ print A → คอมเมนต์ → print B

---

## Starter Code

```python
print("A")
# บรรทัดถัดไป
# แสดงผลตรงนี้
```
