# Homework: Review — ข้อ 10: ทบทวนรวมทักษะ

**Difficulty:** 🟢 Easy

---

## โจทย์

รับตัวเลขจากผู้ใช้ แล้วแสดงพร้อมป้ายกำกับด้วย f-string

รับจำนวนเต็มหนึ่งค่า แล้วแสดงในรูปแบบ `Value: ...`

**Input:**
```
25
```

**Output:**
```
Value: 25
```

---

## 💡 Hint

ใช้ `int(input())` ร่วมกับ `f"Value: {n}"`

---

# แสดงผลตรงนี้
