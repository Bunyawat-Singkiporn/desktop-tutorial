# Starter (copy this)

Copy the whole `starter/` folder into a project under `../projects/`:

```bash
# from curriculum-48/
cp -r starter projects/p01-taskboard
# Windows PowerShell:
# Copy-Item -Recurse starter projects\p01-taskboard
```

Then follow:

1. [backend/README.md](backend/README.md)
2. [frontend/README.md](frontend/README.md)

Run **both** servers every class: `:8000` + `:5173`.
