# Starter frontend — React + Vite + Tailwind

## Setup

```bash
cd frontend
npm install
npm run dev
```

Open http://127.0.0.1:5173

Optional: create `.env` with:

```
VITE_API_BASE=http://127.0.0.1:8000
```

## Included

- Layout + nav
- `src/api/client.js` — fetch helper + Bearer token hook
- `/tasks` page — list + create (Block B starting point)
