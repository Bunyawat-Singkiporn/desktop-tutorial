# S04 — Database: Table, Row, PK, FK

## Goal

Name the building blocks of a relational database.

## Concept (5 min)

**Table** = one entity (User, Task)
**Row** = one record
**Column** = one field
**PK** = unique id of a row
**FK** = points to another table's PK
