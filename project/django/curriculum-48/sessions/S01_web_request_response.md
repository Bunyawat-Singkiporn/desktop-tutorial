# S01 — Web: Browser, Server, Request/Response

## Goal

Explain how a browser talks to a server and what comes back.

## Concept (5 min)

A website is a conversation:
1. Browser sends a **request**
2. Server runs code / reads DB
3. Server sends a **response** (HTML, JSON, or error).

Django lives on the **server**, not in the browser.
