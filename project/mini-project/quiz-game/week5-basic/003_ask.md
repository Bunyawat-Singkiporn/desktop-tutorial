## เป้าหมาย

เก็บคำถาม ตัวเลือก 4 ข้อ และเฉลยใน 3 lists

---

## แนวคิด

`answers` เก็บ **index** ของตัวเลือกที่ถูก (ไม่ใช่คำตอบโดยตรง)

```
questions[0] = "What is 2 + 2?"
choices[0]   = ["2", "3", "4", "5"]
answers[0]   = 2    ← แปลว่า choices[0][2] = "4" คือเฉลย
```

---

## 📝 เพิ่มใน quiz.py

เพิ่ม **หลัง** `font_c = ...` ก่อน `running = True`:

```python
questions = [
    "What is 2 + 2?",
    "What color is the sky?",
    "How many days in a week?",
    "Capital of Thailand?",
    "How many months in a year?"
]

choices = [
    ["2", "3", "4", "5"],
    ["red", "blue", "green", "yellow"],
    ["5", "6", "7", "8"],
    ["Bangkok", "Chiang Mai", "Phuket", "Pattaya"],
    ["10", "11", "12", "13"]
]

answers = [2, 1, 2, 0, 2]   # index ของตัวเลือกที่ถูก

current_q = 0
feedback  = ""
```
