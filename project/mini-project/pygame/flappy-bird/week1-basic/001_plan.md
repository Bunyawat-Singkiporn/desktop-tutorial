# Week 1 — Flappy Bird (นกบิน)

## วันนี้จะสร้างอะไร

เกม Flappy Bird แบบง่าย — กด **Space** ให้นกกระโดด

---

## Recap จาก Quiz Game

| โค้ด | ความหมาย |
|------|----------|
| `pygame.init()` | เปิดระบบเกม |
| `screen` | หน้าจอที่เราวาดรูป |
| `while running:` | เกมทำงานวนซ้ำตลอด |
| `pygame.KEYDOWN` | ตรวจว่ากดปุ่มอะไร |
| `pygame.draw.circle()` | วาดวงกลม (นก) |

---

## เป้าหมายวันนี้

1. สร้างหน้าต่างเกม
2. วาดนก (วงกลมสีเหลือง)
3. นกตกลงด้วยแรงโน้มถ่วง
4. กด Space → นกกระโดด

---

## ผลลัพธ์ที่จะได้

```
[หน้าต่างสีฟ้า]

     🟡 ← นก

[กด Space → นกกระโดดขึ้น]
[ปล่อย → นกตกลง]
```
