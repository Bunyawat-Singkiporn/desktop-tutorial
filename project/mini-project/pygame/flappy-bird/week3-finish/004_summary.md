---

## โครงสร้างเกม (Game Loop)

```text
ตัวแปร (bird, pipe, score)
↓
while running:          ← วนซ้ำตลอด
  → รับ Input (Space)  ← ผู้เล่นกดปุ่ม
  → อัปเดต (ตก, ท่อ, ชน) ← โปรแกรมคิด
  → วาด (นก, ท่อ, คะแนน) ← แสดงผล
  → clock.tick(60)       ← จำกัดความเร็ว
```

เหมือน Quiz Game: **Input → Process → Output**

---

## สิ่งที่เราใช้

| โค้ด | ทำอะไร |
|------|--------|
| `pygame.draw.circle()` | วาดนก |
| `pygame.draw.rect()` | วาดท่อ |
| `clock.tick(60)` | ควบคุมความเร็วเกม |
| `bird_speed += GRAVITY` | นกตก (เร็วขึ้นเรื่อยๆ) |
| `pipe_x -= 3` | ท่อเลื่อนซ้าย |
| `if` ซ้อน `if` | ตรวจชน (ถาม 2 คำถาม) |
| `score += 1` | เพิ่มคะแนน |
| `if / else` | กระโดด หรือ เล่นใหม่ |
