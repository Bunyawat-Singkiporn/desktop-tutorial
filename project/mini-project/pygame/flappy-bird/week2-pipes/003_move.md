## เป้าหมาย

ขยับท่อไปทางซ้าย + สุ่มความสูงเมื่อท่อวนกลับ

---

## แนวคิด

```python
pipe_x -= 3    # ลดค่า x = เลื่อนซ้าย (←)
```

`-=` หมายถึง **ลดค่าลง** เช่น `800 → 797 → 794 → ...`

```python
if pipe_x < -pipe_w:              # ท่อหายไปทางซ้ายแล้ว
    pipe_x = 800                  # ส่งกลับไปขวา
    pipe_h = random.randint(100, 320)   # สุ่มความสูงใหม่
```

`random.randint(100, 320)` = สุ่มเลขระหว่าง 100 ถึง 320 (ท่อสูงไม่เท่ากันทุกรอบ)

---

## อธิบาย import random

```python
import random    # เรียกใช้ระบบสุ่มเลข
```

ต้องอยู่ **บนสุด** ของไฟล์ ข้าง `import pygame`

## 📝 เพิ่มใน flappy.py

**1.** เพิ่มบรรทัดแรกของไฟล์ (ข้าง `import pygame`):

```python
import random
```

**2.** เพิ่ม **ก่อน** `screen.fill("skyblue")` ใน game loop:

```python
    pipe_x -= 3
    if pipe_x < -pipe_w:
        pipe_x = 800
        pipe_h = random.randint(100, 320)
```

> รันดู — ท่อควรเลื่อนซ้าย แล้วกลับมาขวาพร้อมความสูงใหม่
