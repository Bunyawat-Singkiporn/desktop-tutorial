# Week 1 — Guessing Game (เดาเลข)

## วันนี้จะสร้างอะไร

เกมเดาเลข — กดเลข **1-5** แล้วเกมบอกว่า Too Low / Too High / Correct!

---

## ขั้นตอนแรก: วาด Flowchart ก่อนเขียนโค้ด

> ทุกเกมที่สร้าง — **คิดก่อนเขียนเสมอ**

เปิดสไลด์ `002_flowchart.md` แล้วทำกิจกรรม Flowchart ก่อน

---

## เป้าหมายวันนี้

1. วาด Flowchart ของเกม
2. สร้างหน้าต่างเกม
3. แสดงข้อความบนหน้าจอ
4. รับการกดปุ่ม 1-5
5. ตรวจคำตอบ → Too Low / Too High / Correct!
6. เก็บคะแนน

---

## ผลลัพธ์ที่จะได้

```
┌──────────────────────────────┐
│  Score: 2                    │
│                              │
│     Correct!                 │
│                              │
└──────────────────────────────┘

กด 1-5 เพื่อเดา
```

---

## Python ที่จะใช้วันนี้

| Python | ใช้ทำอะไร |
|--------|-----------|
| `variable = value` | เก็บเลขลับ, คะแนน, ข้อความ |
| `if / elif / else` | ตรวจว่าเดาถูกหรือเปล่า |
| `score += 1` | เพิ่มคะแนน |
| `f"Score: {score}"` | แสดงตัวเลขในข้อความ |

---

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|------|-----------|
| `00X_....md` | **สไลด์** — เปิดให้เด็กดู แล้วพิมพ์ตาม |
| `game.py` | **เฉลย** — ครูใช้เช็ก / เด็กเทียบตอนจบคาบ |

> เด็กสร้างไฟล์ `game.py` ของตัวเอง แล้วพิมพ์ตามสไลด์
