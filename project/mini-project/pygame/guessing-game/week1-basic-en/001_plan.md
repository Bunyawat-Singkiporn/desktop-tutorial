# Week 1 — Guessing Game

## What We're Building

A number guessing game — press **1-5** and the game tells you Too Low / Too High / Correct!

---

## First Step: Draw a Flowchart Before Coding

> Every game starts with a plan, not code.

Open `002_flowchart.md` and do the Flowchart activity first.

---

## Goals for Today

1. Draw the game Flowchart
2. Create the game window
3. Display text on screen
4. Accept key presses 1-5
5. Check the answer → Too Low / Too High / Correct!
6. Keep score

---

## What You'll Build

```
┌──────────────────────────────┐
│  Score: 2                    │
│                              │
│     Correct!                 │
│                              │
└──────────────────────────────┘

Press 1-5 to guess
```

---

## Python Concepts Used Today

| Python | What it does |
|--------|--------------|
| `variable = value` | Store secret number, score, message |
| `if / elif / else` | Check if the guess is correct |
| `score += 1` | Increase score |
| `f"Score: {score}"` | Show a number inside a string |
