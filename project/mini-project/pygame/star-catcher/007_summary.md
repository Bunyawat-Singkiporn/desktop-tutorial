# 🎉 สรุป Star Catcher

## เช็คลิสต์

- [ ] หน้าต่างสีกรมท่าเปิดได้
- [ ] ตะกร้าเลื่อนซ้าย-ขวาด้วยลูกศร
- [ ] ดาวตกลงมาจากด้านบน
- [ ] จับดาวได้ = คะแนน +1
- [ ] พลาดดาว = ชีวิต -1
- [ ] ดาว 3 ดวงพร้อมกัน ความเร็วต่างกัน
- [ ] Game Over เมื่อชีวิตหมด

## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|----------|
| `if` | เช็คจับดาว, เช็คพลาด, เช็ค Game Over |
| `list` | `stars = [[x, y, speed], ...]` |
| `random.randint()` | สุ่มตำแหน่ง x และความเร็ว |
| `score += 1` | บวกคะแนน |
| `lives -= 1` | ลดชีวิต |
| `for star in stars:` | วนลูปดาวทุกดวง |
| `abs(a - b)` | หาระยะห่างซ้าย-ขวา |
| `star[1] += star[2]` | ดาวตกลงมา (y เพิ่ม) |

## เปรียบเทียบ Fruit Collector vs Star Catcher

| | Fruit Collector 🍎 | Star Catcher ⭐ |
|--|---------|---------|
| ผู้เล่นเคลื่อนที่ | 4 ทิศทาง | ซ้าย-ขวาเท่านั้น |
| object | อยู่นิ่ง | ตกลงมาทุก frame |
| collision | `distance < 30` | `sy > 530` + `abs(x) < 50` |
| ถ้าพลาด | ไม่มีผล | เสียชีวิต |
| Game Over | ไม่มี | ชีวิตหมด |

## Input → Process → Output

```
Input           Process                  Output
──────────────────────────────────────────────────
กดซ้าย/ขวา →   basket_x ± speed      →  ตะกร้าขยับ
ทุก frame   →   star[1] += star[2]    →  ดาวตกลงมา
ตะกร้ารับ  →   score += 1 + respawn  →  คะแนนขึ้น
พลาด        →   lives -= 1 + respawn  →  ชีวิตลด
lives = 0   →   running = False       →  Game Over
```

## ต่อยอดได้

- ใส่เสียง `pygame.mixer` เมื่อจับดาวได้
