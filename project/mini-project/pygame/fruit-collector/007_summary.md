# 🎉 สรุป Fruit Collector

## เช็คลิสต์

- [ ] หน้าต่างสีเขียวเปิดได้
- [ ] ผู้เล่นเดินได้ 4 ทิศด้วยลูกศร
- [ ] ผลไม้วาดที่ตำแหน่งสุ่ม
- [ ] เดินชนผลไม้แล้วคะแนนขึ้น
- [ ] ผลไม้เกิดใหม่ที่ตำแหน่งสุ่มหลังเก็บ
- [ ] ผลไม้ 3 ชนิด สีต่างกัน คะแนนต่างกัน

## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|----------|
| `if` | เช็คการชนผลไม้, เช็คทิศทางเดิน |
| `list` | `fruits = [[x,y,type], ...]` |
| `random.randint()` | สุ่มตำแหน่ง x, y และประเภทผลไม้ |
| `score += n` | บวกคะแนนตามประเภทผลไม้ |
| `for fruit in fruits[:]:` | วนลูปผลไม้ทุกลูกอย่างปลอดภัย |
| `fruits.remove(fruit)` | ลบผลไม้ที่เก็บได้ |
| `fruits.append([x, y, t])` | เพิ่มผลไม้ใหม่ |
| `math.sqrt(...)` | คำนวณระยะห่าง (collision) |

## Input → Process → Output

```
Input           Process                Output
────────────────────────────────────────────────
กดลูกศร    →   player_x/y ± speed  →  ผู้เล่นขยับ
ชนผลไม้    →   distance < 30       →  (ตรวจพบ)
               score += points      →  คะแนนขึ้น
               remove + spawn       →  ผลไม้ใหม่โผล่
```
