# 🔴 วาดวงกลม

## เป้าหมาย
วาดวงกลมสีแดงที่ตำแหน่งสุ่มบนหน้าจอ

## แนวคิด

| โค้ด | ทำอะไร |
|------|--------|
| `import random` | โหลด module random |
| `dot_x = random.randint(50, 750)` | สุ่ม x ระหว่าง 50–750 |
| `dot_y = random.randint(50, 550)` | สุ่ม y ระหว่าง 50–550 |
| `pygame.draw.circle(screen, "red", (dot_x, dot_y), 30)` | วาดวงกลมรัศมี 30 |

## 📝 เพิ่มใน 002_window.py

**1.** เพิ่ม **บรรทัดบนสุด** หลัง `import pygame`:

```python
import random
```

**2.** เพิ่ม **ก่อน** `running = True`:

```python
# วงกลม
dot_x = random.randint(50, 750)
dot_y = random.randint(50, 550)
```

**3.** เพิ่ม **หลัง** `screen.fill("white")`:

```python
    pygame.draw.circle(screen, "red", (dot_x, dot_y), 30)
```

> รันดู — เห็นวงกลมสีแดง
> รันซ้ำอีกครั้ง — วงกลมอยู่คนละที่! 🎯
