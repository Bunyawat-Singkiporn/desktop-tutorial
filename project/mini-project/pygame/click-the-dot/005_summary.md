# 🎉 สรุป Click the Dot

## เช็คลิสต์

- [ ] หน้าต่างเปิดได้
- [ ] วงกลมปรากฏที่ตำแหน่งสุ่ม
- [ ] คลิกโดนวงกลม → คะแนนขึ้น
- [ ] วงกลมย้ายไปที่ใหม่หลังโดนคลิก

## เปรียบเทียบ 3 เกม

| | Click the Dot 🎯 | Fruit Collector 🍎 | Star Catcher ⭐ |
|--|--|--|--|
| input | mouse click | keyboard 4 ทิศ | keyboard 2 ทิศ |
| object | อยู่นิ่ง | อยู่นิ่ง | ตกลงมา |
| list | ไม่ใช้ | ใช้ | ใช้ |
| โค้ด (บรรทัด) | ~30 | ~60 | ~60 |

## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|----------|
| `pygame.MOUSEBUTTONDOWN` | ตรวจจับ mouse click |
| `event.pos` | ตำแหน่งที่คลิก (x, y) |
| `math.sqrt(...)` | วัดระยะห่าง |
| `if distance < 30` | เช็คคลิกโดนหรือเปล่า |
| `random.randint()` | ย้ายวงกลมไปที่ใหม่ |
| `score += 1` | บวกคะแนน |

## Input → Process → Output

```
Input              Process                 Output
──────────────────────────────────────────────────────
คลิกเมาส์  →   event.pos รับตำแหน่ง   →  (ตรวจพบ)
               distance < 30?           →  ถ้าโดน:
               score += 1               →  คะแนนขึ้น
               dot ย้ายตำแหน่งใหม่     →  วงกลมหาย-โผล่ใหม่
```

## ต่อยอดได้

- เพิ่ม timer นับถอยหลัง 30 วินาที แล้วหยุด
- ทำวงกลมเล็กลงเรื่อยๆ เมื่อคะแนนสูงขึ้น
- เพิ่ม miss counter (คลิกนอก = +miss)
- เปลี่ยนสีวงกลม random ทุกครั้ง
