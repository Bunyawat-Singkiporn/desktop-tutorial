## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `words[level][0]` | หยิบข้อมูลจาก list ซ้อน list |
| `len(words)` | จำนวนด่านทั้งหมด |
| `level += 1` | ไปด่านถัดไป |
| รีเซ็ตตัวแปรของด่าน | `guessed = []`, `lives = MAX_LIVES` |
| แยก `stage_over` / `game_over` | จบด่าน vs จบเกม |
| guard (`if not stage_over:`) | กันโค้ดทำงานซ้ำทุกเฟรม |
| สูตรคะแนน | `len(word) + lives * 2` |
| `text.get_width()` | จัดข้อความกึ่งกลาง |

---

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| ด่านใหม่เปิดตัวอักษรไว้แล้ว | ลืม `guessed = []` | รีเซ็ตตอนขึ้นด่าน |
| คะแนนวิ่งพรวดๆ | บวกในลูปวาดทุกเฟรม | ใส่ guard `if not stage_over` |
| `IndexError` ตอนด่านสุดท้าย | `level` เกิน `len(words)` | เช็ก `if level >= len(words)` |
| คำยาวล้นจอ | วาดที่ตำแหน่งตายตัว | จัดกลางด้วย `get_width() // 2` |
| กด R แล้วยังอยู่ด่านเดิม | ลืม `level = 0` | รีเซ็ตให้ครบทุกตัว |

## ต่อยอดได้

- เพิ่มคำเป็น 10-15 คำ (แค่เพิ่มใน list!)
- ให้ผู้เล่นเลือกหมวดก่อนเล่น
- ด่านหลังชีวิตน้อยลง: `lives = MAX_LIVES - level`
- โบนัสถ้าทายถูกโดยไม่พลาดเลย
