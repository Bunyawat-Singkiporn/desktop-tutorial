# 3) คะแนนตามฝีมือ

## เป้าหมาย
ชนะด่านแล้วได้คะแนนตาม **ชีวิตที่เหลือ** และ **ความยาวของคำ**

---

## แนวคิด — สูตรคะแนน

```python
if win:
    points = len(word) + lives * 2
    score += points
```

| คำ | ยาว | ชีวิตเหลือ | คะแนน |
|----|-----|-----------|-------|
| DOG | 3 | 6 | 3 + 12 = 15 |
| DOG | 3 | 1 | 3 + 2 = 5 |
| ELEPHANT | 8 | 4 | 8 + 8 = 16 |

> คำยาว = ยากกว่า = ได้เยอะกว่า / เดาแม่น = เหลือชีวิตเยอะ = ได้เยอะกว่า
> **การออกแบบสูตรคะแนนคือการออกแบบว่า "อยากให้ผู้เล่นเก่งเรื่องอะไร"** 🎯

---

## ⚠️ กับดัก: คะแนนบวกซ้ำทุกเฟรม

```python
# ❌ ผิด — อยู่ในลูปวาด ทำงาน 60 ครั้ง/วินาที
if win:
    score += points
```

```python
# ✅ ถูก — บวกครั้งเดียวตอนเพิ่งชนะ
if win and not stage_over:
    score += len(word) + lives * 2
    stage_over = True
```

> เงื่อนไข `not stage_over` ทำให้บวกได้แค่ครั้งเดียว เพราะบวกเสร็จก็ตั้ง `stage_over = True` ทันที
> เทคนิคนี้เรียกว่า **guard** (ยาม) — กันไม่ให้โค้ดทำงานซ้ำ

---

## แนวคิด — จอสรุปตอนจบเกม

```python
if game_over:
    if level >= len(words) - 1 and win:
        title = "ผ่านทุกด่าน! สุดยอด"
    else:
        title = "เกมจบ"
    screen.blit(font_big.render(title, True, "white"), (...))
    screen.blit(font_mid.render(f"คะแนนรวม {score}", True, "gold"), (...))
    screen.blit(font_sml.render("กด R เพื่อเล่นใหม่", True, GREY), (...))
```

---

## 📝 แก้ `game.py`

1. เพิ่ม `score = 0` ก่อนลูป (นอกลูป!)
2. บวกคะแนนตอนชนะด่าน พร้อม guard
3. วาดคะแนนมุมซ้ายบน
4. เพิ่มจอสรุปตอน `game_over`
5. ปุ่ม R ต้องรีเซ็ต `level`, `score`, `guessed`, `lives` ให้ครบ
