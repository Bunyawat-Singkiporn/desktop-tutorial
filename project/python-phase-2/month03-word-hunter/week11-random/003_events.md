# 2) ตารางเหตุการณ์

## เป้าหมาย
ทุกด่านสุ่มเหตุการณ์ 1 อย่าง แล้วโชว์ข้อความ

---

## แนวคิด — เก็บเหตุการณ์ไว้ใน list

```python
events = [
    ["lucky", "โชคดี! เปิดให้ 1 ตัวฟรี"],
    ["bless", "ได้รับพร! ชีวิต +1"],
    ["trap",  "กับดัก! ชีวิต -1"],
    ["bonus", "โบนัส! ด่านนี้คะแนนคูณ 2"],
    ["none",  "ด่านธรรมดา ไม่มีอะไรพิเศษ"],
]
```

แต่ละอันเก็บ 2 อย่าง: **รหัส** (ให้โค้ดอ่าน) กับ **ข้อความ** (ให้คนอ่าน)

```python
event = random.choice(events)
event_code = event[0]        # "lucky"
event_text = event[1]        # "โชคดี! เปิดให้ 1 ตัวฟรี"
```

> ทำไมต้องแยกรหัสกับข้อความ? เพราะถ้าเทียบข้อความยาวๆ ตรงๆ พิมพ์ผิดนิดเดียวก็พังทันที
> รหัสสั้นๆ ปลอดภัยกว่าเยอะ 👍

## แนวคิด — น้ำหนักความน่าจะเป็น

ถ้าอยากให้ "ปกติ" ออกบ่อยกว่าอย่างอื่น แค่ใส่ซ้ำหลายอัน!

```python
events = [
    ["lucky", "..."],
    ["bless", "..."],
    ["trap",  "..."],
    ["bonus", "..."],
    ["none",  "..."],
    ["none",  "..."],      # ใส่ซ้ำ = โอกาสออกมากขึ้น
    ["none",  "..."],
]
```

```text
มี 7 อัน  →  "none" มี 3 อัน  →  โอกาสออก 3/7 ≈ 43%
             อย่างอื่นอันละ 1/7 ≈ 14%
```

---

## อีกวิธี — `random.random()`

```python
r = random.random()          # ได้ทศนิยม 0.0 ถึง 0.999...

if r < 0.1:
    print("หายากมาก 10%")
elif r < 0.4:
    print("ปานกลาง 30%")
else:
    print("ธรรมดา 60%")
```

> นี่คือวิธีที่ระบบ **กาชา / ตู้สุ่ม** ในเกมใช้จริงๆ 🎰

## ⚠️ ระวังชื่อตัวแปรชนกัน!

เราตั้งตัวแปรชื่อ `event` เก็บเหตุการณ์ แต่ในลูปก็มี

```python
for event in pygame.event.get():     # ← ทับตัวแปรของเรา!
```

**ทางแก้:** เปลี่ยนชื่อตัวแปรในลูปเป็น `event_pg`

```python
for event_pg in pygame.event.get():
    if event_pg.type == pygame.QUIT:
        ...
    if event_pg.type == pygame.KEYDOWN:
        ...
```

> บั๊กแบบนี้เรียกว่า **name collision** (ชื่อชนกัน) — หายากมากเพราะไม่มี error!
> โปรแกรมรันได้ปกติ แต่ข้อมูลเพี้ยน 😱 ตั้งชื่อตัวแปรให้ชัดเจนช่วยได้เยอะ
