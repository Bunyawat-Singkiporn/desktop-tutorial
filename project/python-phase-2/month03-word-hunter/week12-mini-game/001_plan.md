## แผน state ทั้งเกม

```mermaid
stateDiagram-v2
    [*] --> หน้าเริ่ม
    หน้าเริ่ม --> เล่นด่าน: Space
    เล่นด่าน --> จบด่าน: ทายครบ / ชีวิตหมด
    จบด่าน --> เล่นด่าน: Space (ยังมีด่าน)
    จบด่าน --> สรุปผล: ด่านสุดท้าย / ชีวิตหมด
    สรุปผล --> หน้าเริ่ม: R
```
