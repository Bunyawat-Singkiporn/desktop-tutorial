# 2) แป้นตัวอักษร A-Z บนจอ

## เป้าหมาย
โชว์ A-Z ทั้ง 26 ตัว ตัวที่เดาแล้วให้จาง / สีเขียว-แดงตามถูก-ผิด

---

## แนวคิด — วาด 26 ตัวด้วย `for` + `enumerate`

```python
ALPHA = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

for i in range(len(ALPHA)):
    ch = ALPHA[i]
    x = 60 + (i % 13) * 55        # 13 ตัวต่อแถว
    y = 370 + (i // 13) * 45      # แถวที่ 0 หรือ 1
```

**เลขคณิตของการจัดกริด** 🧮

| `i` | `i % 13` (คอลัมน์) | `i // 13` (แถว) |
|-----|--------------------|------------------|
| 0 (A) | 0 | 0 |
| 12 (M) | 12 | 0 |
| 13 (N) | 0 | 1 |
| 25 (Z) | 12 | 1 |

| ตัวดำเนินการ | ชื่อ | ตัวอย่าง |
|--------------|------|----------|
| `%` | หารเอาเศษ (modulo) | `15 % 13` = 2 |
| `//` | หารปัดลง | `15 // 13` = 1 |

> สูตร `x = เริ่ม + (i % คอลัมน์) * ระยะห่าง` ใช้จัดกริดได้ทุกเกม
> (ตารางไอเทม, กระดานหมากรุก, ช่องเก็บของ)
