## 🧠 บทเรียนใหญ่ 5 ข้อที่ต้องจำ

1. **ทุกเกมคือ Input → Process → Output วนซ้ำ**
2. **ตัวแปรสะสมอยู่นอกลูป / ตัวแปรของรอบอยู่ในลูป**
3. **state คือหัวใจของเกม** — เมนู / เล่น / จบ
4. **ข้อมูลแยกจากโค้ด** — เพิ่มคำถามหรือคำใหม่ ไม่ต้องแก้ logic เลย
5. **บั๊กเป็นเรื่องปกติ** — อ่าน error จากล่างขึ้นบน แล้ว `print` หาสาเหตุ
