## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `random.shuffle(words)` | สลับลำดับด่าน |
| `random.choice(events)` | สุ่มเหตุการณ์ |
| `random.choice("RAINBOW")` | สุ่มตัวอักษรจากคำ |
| `random.random()` | ทำ % โอกาส (ทางเลือก) |
| ใส่ซ้ำใน list | เพิ่มน้ำหนักความน่าจะเป็น |
| แยกรหัส / ข้อความ | `event[0]` ให้โค้ด, `event[1]` ให้คน |
| `multiplier` | ตัวคูณคะแนน |
| ธง `new_stage` | เขียนโค้ดเริ่มด่านที่เดียว |

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| ค่ารีเซ็ตทุกเฟรม | ลืม `new_stage = False` บรรทัดแรก | เพิ่มเป็นบรรทัดแรกในบล็อก |
| โบนัสคูณ 2 ติดตลอดเกม | ลืมรีเซ็ต `multiplier = 1` | รีเซ็ตตอนเริ่มด่าน |
| `TypeError: 'NoneType'` | เขียน `words = random.shuffle(words)` | เรียก `random.shuffle(words)` เฉยๆ |
| ชีวิตเกินจำนวนวงกลม | เหตุการณ์ "พร" ทำให้เกิน MAX | วาดวงกลม `MAX_LIVES + 1` วง |
| เหตุการณ์เดิมทุกด่าน | สุ่มแค่ครั้งเดียวก่อนลูป | สุ่มใหม่ทุกครั้งที่ `new_stage` |

## ต่อยอดได้

- เหตุการณ์ "คำสั้นพิเศษ" — ด่านนี้เจอคำสั้นที่สุดในคลัง
- เหตุการณ์ "ตาบอด" — ไม่แสดงคำใบ้ แต่ได้คะแนน 3 เท่า

- ใช้ `random.random()` ให้เหตุการณ์หายากจริงๆ (5%)
