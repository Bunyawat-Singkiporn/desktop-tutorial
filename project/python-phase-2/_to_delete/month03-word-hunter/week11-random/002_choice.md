# 1) สุ่มคำจากคลัง

## เป้าหมาย
ทุกครั้งที่เล่น ลำดับคำต้องไม่ซ้ำเดิม

---

## แนวคิด — 3 วิธีสุ่มที่ใช้บ่อย

```python
import random

random.randint(1, 10)                    # สุ่มเลข 1-10
random.choice(["A", "B", "C"])           # สุ่มหยิบ 1 ตัว → "B"
random.shuffle(words)                    # สลับลำดับใน list เลย
```

| คำสั่ง | คืนค่าไหม | เหมาะกับ |
|--------|-----------|----------|
| `randint(a, b)` | ✅ คืนตัวเลข | สุ่มตำแหน่ง, สุ่มความเสียหาย |
| `choice(list)` | ✅ คืน 1 สมาชิก | สุ่มไอเทม, สุ่มเหตุการณ์ |
| `shuffle(list)` | ❌ ไม่คืน (แก้ list เลย) | สลับด่าน, สลับไพ่ |

> `x = random.shuffle(mylist)` = ❌ ได้ `None` ทุกครั้ง! (บั๊กยอดฮิต)

---

## เลือกใช้อันไหนดี?

| อยากได้ | ใช้ |
|---------|-----|
| เล่นครบทุกคำ แต่ลำดับสุ่ม | `shuffle` ✅ |
| สุ่มคำมาเรื่อยๆ อาจซ้ำได้ | `choice` |

เกมเราเล่นครบทุกคำ → ใช้ `shuffle`

```python
import random

random.shuffle(words)      # ใส่ก่อนเริ่มเกม และตอนกด R
```
