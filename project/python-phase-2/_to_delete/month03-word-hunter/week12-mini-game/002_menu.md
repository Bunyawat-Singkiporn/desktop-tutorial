## เป้าหมาย
เพิ่ม state "หน้าเริ่ม" และเก็บคะแนนสูงสุดข้ามรอบ

---

## แนวคิด — เพิ่ม state ที่ 1

ตอนนี้เกมมี 3 state → เพิ่มเป็น 4

```python
started = False          # ยังอยู่หน้าเริ่ม
```

**ส่วน INPUT**

```python
        if event_pg.type == pygame.KEYDOWN:
            if not started:
                if event_pg.key == pygame.K_SPACE:
                    started = True
                    new_stage = True        # ให้ตั้งค่าด่านแรก
            elif ...
```

**ส่วน OUTPUT**

```python
    if not started:
        ...วาดหน้าเริ่ม...
    elif game_over:
        ...วาดจอสรุป...
    else:
        ...วาดจอเล่น...
```

## แนวคิด — สถิติสูงสุด

```python
best = 0                       # อยู่นอกทุกการรีเซ็ต

# ตอนจบเกม (ในบล็อกที่ตั้ง game_over = True)
if score > best:
    best = score
```

⚠️ ต้องเช็ก **ตอนเพิ่งจบ** ไม่ใช่ทุกเฟรม (ใช้ guard เหมือน Week 10)

## 📝 แก้ `game.py` ของ Week 11

1. เพิ่ม `started = False` และ `best = 0`
2. เพิ่มการรับ Space ที่หน้าเริ่ม
3. เพิ่มการวาดหน้าเริ่ม (กล่อง + ชื่อเกม + วิธีเล่น + best)
4. อัปเดต `best` ตอนจบเกม
5. กด R → กลับไป `started = False` (กลับหน้าเริ่ม)
