## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `menu_items` เป็น list | เพิ่ม/ลดเมนูโดยไม่แตะ logic |
| `i == selected` | วาดข้อที่เลือกให้ต่างจากข้ออื่น |
| `(selected + 1) % len(...)` | เลื่อนแบบวนรอบ |
| state 3 แบบ | `menu` / `howto` / `playing` |
| ปุ่มเดียวหลายหน้าที่ | Esc = กลับเมนู หรือ ออกโปรแกรม |
| `def reset_game():` | ล้างกระดาน เรียกซ้ำได้หลายที่ |
| local variable | ทำไมสร้าง list ใหม่ในฟังก์ชันถึงไม่ได้ผล |

---

## 🧩 โครงเมนูนี้ใช้ซ้ำได้ทุกเกม

```python
menu_items = [...]        # 1. รายการ
selected = 0              # 2. ตัวชี้
state = "menu"            # 3. หน้าไหน

# เลื่อน
selected = (selected + 1) % len(menu_items)

# เลือก
if selected == 0: state = "playing"
```

> เก็บ 3 บรรทัดนี้ไว้ให้ดี — เดือน 5 (Flappy Bird) และเดือน 7 (Space Shooter)
> จะใช้โครงเดียวกันเป๊ะ แค่เปลี่ยนรายการเมนู ♻️

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| กดลูกศรแล้ว `IndexError` | ไม่ได้ใช้ `%` วนรอบ | `(selected + 1) % len(menu_items)` |
| กด Esc ที่เมนูแล้วไม่ออก | เช็ก state ไม่ครบ | แยกเคส `menu` ออกจากเคสอื่น |
| เริ่มใหม่แล้วกระดานยังเต็ม | ลืมเรียก `reset_game()` | เรียกก่อนเปลี่ยน state |
| `reset_game()` ไม่ทำงาน | สร้าง list ใหม่ในฟังก์ชัน | แก้ค่าทีละช่องแทน |
| คลิกในเมนูแล้วลง X | ไม่ได้เช็ก state ตอนคลิก | `if ... and state == "playing":` |
