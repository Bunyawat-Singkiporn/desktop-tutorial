# 3) ฟังก์ชันเริ่มเกมใหม่

## เป้าหมาย
เลือก "เริ่มเกมใหม่" แล้วกระดานต้องว่างเสมอ

---

## ปัญหาตอนนี้

เล่นจนกระดานเต็ม → กด Esc กลับเมนู → เลือกเริ่มเกมใหม่
กระดานยังเต็มเหมือนเดิม 😱 เพราะไม่มีใครล้างมัน

---

## แนวคิด — ฟังก์ชันล้างกระดาน

```python
def reset_game():
    for r in range(3):
        for c in range(3):
            board[r][c] = ""
```

เรียกใช้ตอนเริ่มเกม

```python
if selected == 0:
    reset_game()
    state = "playing"
```

> นี่คือประโยชน์ชัดๆ ของ `def` — โค้ดล้างกระดานจะถูกเรียกอีกหลายที่
> (ตอนกดเริ่มใหม่ระหว่างเล่น, ตอนจบเกม) เขียนครั้งเดียวใช้ได้ตลอด

---

## ⚠️ กับดักใหญ่: ทำไมไม่เขียนแบบนี้

```python
def reset_game():
    board = [["", "", ""], ["", "", ""], ["", "", ""]]   # ❌ ไม่ได้ผล!
```

โค้ดนี้สร้างกระดานใหม่ **ที่อยู่แค่ในฟังก์ชัน** พอจบฟังก์ชันก็หายไป
กระดานข้างนอกไม่ได้เปลี่ยนเลย

```text
def reset_game():
    board = [...]     ← ตัวแปรใหม่ในฟังก์ชัน (local)
                        ไม่ใช่ board ข้างนอก
```

**ทางแก้** — แก้ค่าข้างในทีละช่องแทนการสร้างใหม่ (ตามโค้ดด้านบน)

> เรื่องนี้เรียกว่า **scope** จะได้เรียนเต็มๆ ใน Phase 1 บท 041
> ตอนนี้จำกฎง่ายๆ ไว้ก่อน: *แก้ของข้างใน list ได้ แต่สร้าง list ใหม่ไม่ได้*

---

## แนวคิด — ปุ่มลัดเริ่มใหม่ระหว่างเล่น

```python
if state == "playing" and event.key == pygame.K_r:
    reset_game()
```

> ผู้เล่นไม่ต้องกลับเมนูเพื่อเริ่มใหม่ — ลดขั้นตอนให้เหลือปุ่มเดียว
