# 1) สลับตาผู้เล่น

## เป้าหมาย
คลิกครั้งแรกได้ X ครั้งต่อไปได้ O สลับกันไปเรื่อยๆ

---

## แนวคิด — ตัวแปรเดียวจำว่าตาใคร

```python
turn = "X"          # เริ่มที่ X เสมอ
```

ตอนวางเครื่องหมาย ใช้ `turn` แทนการเขียน `"X"` ตายตัว

```python
if r >= 0 and board[r][c] == "":
    board[r][c] = turn          # ← วางของคนที่ถึงตา
```

---

## แนวคิด — สลับตา

```python
    if turn == "X":
        turn = "O"
    else:
        turn = "X"
```

```text
turn = "X"  →  คลิก  →  วาง X  →  turn = "O"
turn = "O"  →  คลิก  →  วาง O  →  turn = "X"
turn = "X"  →  คลิก  →  วาง X  →  turn = "O"
```

---

## ⚠️ กับดักใหญ่ที่สุดของข้อนี้

```python
board[r][c] = turn
if turn == "X":           # ❌ ผิด! อยู่นอก if ที่เช็กช่องว่าง
    turn = "O"
else:
    turn = "X"
```

ถ้าวางโค้ดสลับตาไว้ **นอก** เงื่อนไข `board[r][c] == ""`
คลิกช่องที่มีเครื่องหมายแล้วก็จะสลับตา → **เสียตาฟรี** 😱

```python
if r >= 0 and board[r][c] == "":
    board[r][c] = turn
    if turn == "X":       # ✅ ถูก! อยู่ข้างในทั้งคู่
        turn = "O"
    else:
        turn = "X"
```

> กฎ: **สลับตาเฉพาะเมื่อวางสำเร็จเท่านั้น**

## แนวคิด — บอกผู้เล่นว่าตาใคร

```python
def draw_turn():
    if turn == "X":
        text = "ตาของ ผู้เล่น 1 (X)"
        color = XCOL
    else:
        text = "ตาของ ผู้เล่น 2 (O)"
        color = OCOL
    t = font_mid.render(text, True, color)
    screen.blit(t, (300 - t.get_width() // 2, 88))
```

> ใช้ **สีเดียวกับเครื่องหมาย** ผู้เล่นจะรู้ทันทีโดยไม่ต้องอ่าน

## 📝 แก้ `xo.py`

1. เพิ่ม `turn = "X"` ไว้กับตัวแปรอื่น
2. เปลี่ยน `board[r][c] = "X"` เป็น `board[r][c] = turn`
3. เพิ่มการสลับตา **ข้างใน** `if` เดียวกัน
4. เพิ่ม `turn = "X"` ใน `reset_game()` — ต้องเริ่มที่ X เสมอ
5. เพิ่มฟังก์ชัน `draw_turn()`
