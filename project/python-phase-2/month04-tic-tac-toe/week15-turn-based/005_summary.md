## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `turn` | จำว่าตอนนี้ตาใคร |
| สลับตาใน `if` เดียวกับการวาง | กันเสียตาฟรี |
| `def check_winner():` | ตรวจ 8 แนว |
| `return` ออกจากฟังก์ชันทันที | เจอผู้ชนะแล้วหยุดตรวจ |
| `board[r][0] != ""` | กันช่องว่าง 3 ช่องถูกนับว่าชนะ |
| `def board_full():` | ตรวจเสมอ |
| ลำดับ `if winner` → `elif board_full()` | ป้องกันบั๊กเสมอทับชนะ |
| `global` | ให้ฟังก์ชันแก้ตัวแปรข้างนอกได้ |

## 🧠 บทเรียนสำคัญ: ลำดับเงื่อนไขเปลี่ยนผลลัพธ์

```text
กระดานเหลือช่องสุดท้าย แล้ว X วางลงไปแล้วเรียงครบพอดี

ตรวจเสมอก่อน     →  กระดานเต็ม  →  ประกาศ "เสมอ"  ❌
ตรวจผู้ชนะก่อน   →  X เรียงครบ  →  ประกาศ "X ชนะ" ✅
```

> เรื่องเดียวกับที่เจอตอนเรียงลำดับเหรียญใน Number Quest (Week 3)
> **`if` เรียงผิดลำดับ = โปรแกรมไม่ error แต่ผลลัพธ์ผิด** ซึ่งหาบั๊กยากกว่าเยอะ

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| คลิกช่องเดิมแล้วเสียตา | สลับตาอยู่นอก `if` เช็กช่องว่าง | ย้ายเข้าไปข้างใน |
| เริ่มเกมมาก็ประกาศผู้ชนะทันที | ลืมเช็ก `!= ""` | ช่องว่าง 3 ช่องเท่ากันหมด |
| ชนะแล้วยังคลิกต่อได้ | ไม่ได้เปลี่ยน state | ตั้ง `state = "result"` |
| ชนะช่องสุดท้ายแต่ขึ้นเสมอ | ตรวจเสมอก่อนผู้ชนะ | สลับลำดับเงื่อนไข |
| เริ่มใหม่แล้วตาไม่กลับเป็น X | ลืมรีเซ็ต `turn` | เพิ่มใน `reset_game()` |
| `UnboundLocalError: turn` | ฟังก์ชันแก้ตัวแปรข้างนอกโดยไม่ประกาศ | ใส่ `global turn, winner` |
