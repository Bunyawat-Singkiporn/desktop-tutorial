# 2) ตรวจผู้ชนะ

## เป้าหมาย
รู้ว่ามีใครเรียงครบ 3 ช่องหรือยัง

---

## แนวคิด — ตรวจทีละแนว

**แนวนอน** — แถวเดียวกัน คอลัมน์ไล่ 0-2

```python
for r in range(3):
    if board[r][0] != "" and board[r][0] == board[r][1] and board[r][1] == board[r][2]:
        return board[r][0]
```

> `board[r][0] != ""` สำคัญมาก! ถ้าไม่เช็ก ช่องว่าง 3 ช่องจะถือว่า "เรียงครบ" ทันที 😅

**แนวตั้ง** — คอลัมน์เดียวกัน แถวไล่ 0-2

```python
for c in range(3):
    if board[0][c] != "" and board[0][c] == board[1][c] and board[1][c] == board[2][c]:
        return board[0][c]
```

**แนวทแยง** — มีแค่ 2 แนว เขียนตรงๆ ได้เลย

```python
if board[0][0] != "" and board[0][0] == board[1][1] and board[1][1] == board[2][2]:
    return board[0][0]
if board[0][2] != "" and board[0][2] == board[1][1] and board[1][1] == board[2][0]:
    return board[0][2]
```

## แนวคิด — ฟังก์ชันที่คืนค่ากลับ

```python
def check_winner():
    ...ตรวจทั้ง 8 แนว...
    return ""            # ไม่มีใครชนะ
```

| คืนค่า | หมายถึง |
|--------|---------|
| `"X"` | ผู้เล่น 1 ชนะ |
| `"O"` | ผู้เล่น 2 ชนะ |
| `""` | ยังไม่มีใครชนะ |

> `return` หยุดฟังก์ชันทันที — เจอผู้ชนะแนวแรกก็ไม่ต้องตรวจแนวที่เหลือ
> (เรื่อง `return` จะได้เรียนเต็มๆ ใน Phase 1 บท 039)

## แนวคิด — เรียกตรวจหลังวางทุกครั้ง

```python
if r >= 0 and board[r][c] == "":
    board[r][c] = turn

    winner = check_winner()
    if winner == "":
        ...สลับตา...
    else:
        state = "result"        # มีคนชนะแล้ว หยุดเกม
```

> ตรวจ **หลังวาง** เท่านั้น — ตรวจก่อนวางไม่มีประโยชน์ เพราะกระดานยังไม่เปลี่ยน
