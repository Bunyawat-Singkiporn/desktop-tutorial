## 🧠 บทเรียนใหญ่ของเดือนนี้: บั๊กที่ไม่ error คือบั๊กที่แพงที่สุด

| บั๊กเดือนนี้ | error ไหม | อาการ |
|--------------|-----------|-------|
| สลับตาอยู่นอก `if` | ❌ ไม่ | เสียตาฟรี |
| ลืมเช็ก `!= ""` | ❌ ไม่ | ชนะตั้งแต่ยังไม่เล่น |
| แนวทแยงผิดช่อง | ❌ ไม่ | ชนะแล้วไม่นับ |
| ตรวจเสมอก่อนชนะ | ❌ ไม่ | ชนะกลายเป็นเสมอ |
| ลืมรีเซ็ต `turn` | ❌ ไม่ | รอบสองเริ่มผิดคน |

> **5 บั๊ก ไม่มี error สักตัว** — นี่คือเหตุผลที่ต้อง **ทดสอบด้วยการเล่นจริง** ทุกครั้ง
> ไม่ใช่แค่ "รันผ่านแล้วจบ"

## ✅ เช็กลิสต์ทดสอบเกม (เก็บไว้ใช้ตลอด)

1. เริ่มเกมใหม่ → สภาพเริ่มต้นถูกไหม
2. ทำสิ่งที่ถูกต้อง → ได้ผลที่ควรได้ไหม
3. ทำสิ่งที่ผิด (คลิกช่องที่มีแล้ว, คลิกนอกจอ) → เกมพังไหม
4. เล่นจนจบทุกแบบ (ชนะ X, ชนะ O, เสมอ)
5. เล่นรอบสอง → ทุกอย่างรีเซ็ตครบไหม
6. **กรณีขอบ** — ชนะในช่องสุดท้ายพอดี
