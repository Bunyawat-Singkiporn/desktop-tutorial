## 1) ขีดเส้นทับ 3 ช่องที่ชนะ

ตอนนี้เกมบอกแค่ว่าใครชนะ แต่ไม่บอกว่า **ชนะตรงไหน**
ผู้เล่นที่แพ้จะงงว่าแพ้เพราะแถวไหน

**เก็บตำแหน่งไว้ตอนตรวจ**

```python
win_line = []        # เก็บ [(r, c), (r, c), (r, c)]

def check_winner():
    global win_line
    for r in range(3):
        if board[r][0] != "" and board[r][0] == board[r][1] and board[r][1] == board[r][2]:
            win_line = [(r, 0), (r, 1), (r, 2)]
            return board[r][0]
    ...
```

**วาดเส้นจากช่องแรกถึงช่องสุดท้าย**

```python
def draw_win_line():
    if len(win_line) == 3:
        r1, c1 = win_line[0]
        r2, c2 = win_line[2]
        x1 = BX + c1 * CELL + CELL // 2
        y1 = BY + r1 * CELL + CELL // 2
        x2 = BX + c2 * CELL + CELL // 2
        y2 = BY + r2 * CELL + CELL // 2
        pygame.draw.line(screen, (250, 220, 90), (x1, y1), (x2, y2), 10)
```

> `win_line` เก็บเป็น list ของคู่ `(แถว, คอลัมน์)` — ใช้แค่ช่องแรกกับช่องสุดท้ายก็ลากเส้นได้

## 2) ไฮไลต์ช่องที่เมาส์ชี้อยู่

```python
def draw_hover():
    mx, my = pygame.mouse.get_pos()
    r, c = cell_from_mouse(mx, my)
    if r >= 0 and board[r][c] == "":
        x = BX + c * CELL
        y = BY + r * CELL
        pygame.draw.rect(screen, (40, 55, 74), (x + 4, y + 4, CELL - 8, CELL - 8), border_radius=8)
```

| ทำไมต้องมี | เพราะอะไร |
|------------|-----------|
| ผู้เล่นรู้ว่ากำลังจะคลิกช่องไหน | ลดการคลิกพลาด |
| ช่องที่มีเครื่องหมายแล้วไม่ไฮไลต์ | บอกว่าคลิกไม่ได้ โดยไม่ต้องเขียนอธิบาย |

> `pygame.mouse.get_pos()` ต่างจาก `event.pos` ตรงที่ **ถามได้ตลอดเวลา** ไม่ต้องรอคลิก
> (เหมือน `key.get_pressed()` เทียบกับ `KEYDOWN`)
