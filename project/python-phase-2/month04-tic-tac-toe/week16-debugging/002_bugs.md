## วิธีทำ

1. เปิด `buggy.py` แล้วรัน `python buggy.py`
2. เลือกเมนู "เริ่มเกมใหม่" แล้วลองเล่นตามอาการข้างล่าง
3. จดอาการ → หาบรรทัดที่ผิด → แก้ → รันใหม่

---

## 🐞 บั๊ก 1 — เริ่มเกมมาก็ประกาศผู้ชนะทันที

```
กดเริ่มเกมใหม่ปุ๊บ ขึ้นว่ามีคนชนะทั้งที่ยังไม่ได้คลิกเลยสักครั้ง
```

**คำใบ้:** กระดานตอนเริ่มเกมมีค่าอะไรอยู่ทุกช่อง?
แล้วช่องว่าง 3 ช่องเรียงกัน ถือว่า "เหมือนกัน" ไหม?

---

## 🐞 บั๊ก 2 — คลิกช่องที่มีเครื่องหมายแล้ว เสียตาฟรี

```
ตาของ X → คลิกช่องที่มี O อยู่ → ไม่มีอะไรลง แต่กลายเป็นตาของ O
```

**คำใบ้:** การสลับตาควรเกิดขึ้น **เฉพาะเมื่อวางสำเร็จ** เท่านั้น
ลองดูว่าโค้ดสลับตาอยู่ข้างในหรือข้างนอกเงื่อนไขที่เช็กช่องว่าง

---

## 🐞 บั๊ก 3 — ชนะแนวทแยงจากขวาบนไปซ้ายล่างไม่ได้

```
เรียง O ที่ช่องขวาบน กลาง ซ้ายล่าง ครบแล้ว แต่เกมไม่ประกาศว่าชนะ
```

**คำใบ้:** แนวทแยงมี 2 แนว
แนวแรกคือ `[0][0] [1][1] [2][2]`
แล้วแนวที่สองควรเป็นช่องไหนบ้าง?

---

## 🐞 บั๊ก 4 — ชนะในช่องสุดท้าย แต่ขึ้นว่าเสมอ

```
กระดานเหลือช่องเดียว X วางลงไปแล้วเรียงครบพอดี
แต่เกมประกาศว่า "เสมอ"
```

**คำใบ้:** เกมตรวจอะไรก่อนอะไร? ลำดับของ `if` / `elif` สำคัญมาก

---

## 🐞 บั๊ก 5 — เล่นรอบสองแล้วตาเริ่มผิด

```
รอบแรกจบลงตอนตาของ O
กด R เริ่มใหม่ → รอบใหม่กลับเริ่มที่ O แทนที่จะเป็น X
```

**คำใบ้:** ฟังก์ชันเริ่มเกมใหม่ล้างอะไรบ้าง? ครบทุกตัวแปรหรือยัง?
