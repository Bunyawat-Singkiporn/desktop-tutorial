# ✅ เฉลยบั๊กทั้ง 5

## 🐞 บั๊ก 1 — ประกาศผู้ชนะทันทีที่เริ่ม

```python
for r in range(3):
    if board[r][0] == board[r][1] and board[r][1] == board[r][2]:    # ❌
        return board[r][0]
```

ตอนเริ่มเกมทุกช่องเป็น `""` → `"" == "" == ""` เป็นจริง → คืนค่า `""`
แต่เงื่อนไขที่เรียกใช้เขียนว่า `if winner != "":` ... **ซึ่งดูเหมือนจะกันได้**

ปัญหาจริงคือมันทำให้ผลเพี้ยนในหลายที่ ทางที่ถูกคือกันตั้งแต่ต้น

**แก้:**

```python
    if board[r][0] != "" and board[r][0] == board[r][1] and board[r][1] == board[r][2]:
```

> กฎ: **ตรวจว่ามีค่าก่อน แล้วค่อยตรวจว่าเท่ากัน** เสมอ

## 🐞 บั๊ก 2 — เสียตาฟรี

```python
if r >= 0 and board[r][c] == "":
    board[r][c] = turn
if r >= 0:                      # ❌ บล็อกนี้ทำงานแม้ช่องไม่ว่าง
    ...สลับตา...
```

**แก้:** รวมให้อยู่ใน `if` เดียวกัน

```python
if r >= 0 and board[r][c] == "":
    board[r][c] = turn
    ...ตรวจผู้ชนะ...
    ...สลับตา...
```

> บั๊กประเภท **indent/ขอบเขตของ if ผิด** เจอบ่อยมากและไม่มี error ให้ดูเลย

## 🐞 บั๊ก 3 — แนวทแยงที่สองผิด

```python
if board[0][2] != "" and board[0][2] == board[1][1] and board[1][1] == board[2][2]:   # ❌
```

`[0][2]` `[1][1]` `[2][2]` ไม่ใช่เส้นตรง — มันหักมุม

```text
แนวที่ถูก                  ที่เขียนผิด
. . █                      . . █
. █ .                      . █ .
█ . .                      . . █   ← หักมุม
```

**แก้:**

```python
if board[0][2] != "" and board[0][2] == board[1][1] and board[1][1] == board[2][0]:
```

> บั๊กแบบนี้เรียกว่า **copy-paste bug** — ก๊อปบรรทัดบนมาแก้ไม่ครบ

## 🐞 บั๊ก 5 — ตาเริ่มผิดในรอบสอง

```python
def reset_game():
    global winner
    for r in range(3):
        for c in range(3):
            board[r][c] = ""
    winner = ""              # ❌ ลืม turn
```

**แก้:**

```python
def reset_game():
    global turn, winner
    ...
    turn = "X"
    winner = ""
```
