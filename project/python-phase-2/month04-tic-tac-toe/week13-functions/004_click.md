# 3) คลิกวางเครื่องหมาย

## เป้าหมาย
คลิกช่องไหน ให้ `X` ไปลงช่องนั้น

---

## แนวคิด — จับการคลิกเมาส์

```python
for event in pygame.event.get():
    if event.type == pygame.MOUSEBUTTONDOWN:
        mx, my = event.pos          # พิกัดที่คลิก
```

| Event | เกิดเมื่อ |
|-------|-----------|
| `pygame.KEYDOWN` | กดปุ่มคีย์บอร์ด |
| `pygame.MOUSEBUTTONDOWN` | กดปุ่มเมาส์ |
| `event.pos` | พิกัด `(x, y)` ที่คลิก |

---

## แนวคิด — แปลงพิกัดเมาส์เป็นช่องตาราง 🧮

นี่คือหัวใจของข้อนี้ — เมาส์ให้ pixel มา แต่เราต้องการเลขแถว/คอลัมน์

```python
c = (mx - BX) // CELL        # คอลัมน์
r = (my - BY) // CELL        # แถว
```

```text
BX = 60, CELL = 160

คลิกที่ mx = 250
  mx - BX = 190
  190 // 160 = 1      →  คอลัมน์ที่ 1 ✅

    60      220      380      540
    │<-160-->│<-160-->│<-160-->│
    │  c=0   │  c=1   │  c=2   │
              ▲ mx=250 อยู่ตรงนี้
```

> `//` คือหารปัดลง (เรียนตอนบทที่ 11 ของ Phase 1)
> เทคนิคนี้ใช้ได้กับ **ทุกเกมที่มีตาราง** — หมากรุก, ช่องเก็บของ, Minesweeper

---

## แนวคิด — กันคลิกนอกกระดาน

```python
def cell_from_mouse(mx, my):
    c = (mx - BX) // CELL
    r = (my - BY) // CELL
    if r < 0 or r > 2 or c < 0 or c > 2:
        return -1, -1          # คลิกนอกกระดาน
    return r, c
```

> ฟังก์ชันนี้ **คืนค่ากลับมา 2 ค่า** ด้วย `return r, c`
> ถ้าไม่กัน คลิกข้างนอกจะได้ `board[-1][5]` → `IndexError` พัง

---

## แนวคิด — ห้ามวางทับช่องที่มีแล้ว

```python
if r >= 0 and board[r][c] == "":
    board[r][c] = "X"
```

> `board[r][c] == ""` แปลว่าช่องนั้นยังว่าง
> ถ้าไม่เช็ก ผู้เล่นจะทับเครื่องหมายของอีกฝ่ายได้ — เกมพังทันที

---

## 📝 เพิ่มใน `xo.py`

1. ลบค่าทดสอบ `board[0][0] = "X"` ออก
2. เพิ่มฟังก์ชัน `cell_from_mouse(mx, my)`
3. ในลูป event เพิ่มการจับคลิกแล้ววาง `X`

---

> รันดู — คลิกช่องไหนต้องได้ X ช่องนั้น คลิกซ้ำที่เดิมต้องไม่มีอะไรเกิดขึ้น ✅
> คลิกนอกกระดานต้องไม่ error
