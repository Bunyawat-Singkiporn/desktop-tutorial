## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `def ชื่อ():` | `draw_grid()`, `draw_marks()` |
| `def ชื่อ(a, b):` | `cell_from_mouse(mx, my)` |
| `return a, b` | คืนค่ากลับ 2 ค่าพร้อมกัน |
| `board[r][c]` | ตาราง 3×3 |
| ลูปซ้อนลูป | วน 3 แถว × 3 คอลัมน์ |
| `MOUSEBUTTONDOWN` + `event.pos` | จับการคลิก |
| `(mx - BX) // CELL` | แปลง pixel เป็นช่องตาราง |

## ก่อนมี `def` เทียบกับ หลังมี `def`

```text
ก่อน                              หลัง
─────────────────────────────────────────────────
while running:                    while running:
    ...30 บรรทัดวาดเส้น...            draw_grid()
    ...25 บรรทัดวาด X O...            draw_marks()
    ...15 บรรทัดวาดหัวเรื่อง...        draw_title()
```

> ลูปหลักอ่านเหมือน **สารบัญ** — รู้ทันทีว่าเกมทำอะไรบ้าง

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| `NameError: draw_grid` | เรียกฟังก์ชันก่อนนิยาม | ย้าย `def` ขึ้นไปไว้บนลูป |
| คลิกแล้วไม่มีอะไรเกิด | ลืม `screen.fill` + `flip` | ตรวจท้ายลูป |
| `IndexError` ตอนคลิกขอบจอ | ไม่ได้กันคลิกนอกกระดาน | เช็ก `r < 0 or r > 2` |
| X ไปลงผิดช่อง | สลับ `r` กับ `c` | `x` → คอลัมน์, `y` → แถว |
| ทับเครื่องหมายเดิมได้ | ไม่ได้เช็กช่องว่าง | เช็ก `board[r][c] == ""` |
