# 1) รู้จัก `def`

## เป้าหมาย
เข้าใจว่าฟังก์ชันคืออะไร ก่อนเอาไปใช้ในเกมจริง

---

## แนวคิด — ฟังก์ชันคือ "ตั้งชื่อให้โค้ดก้อนหนึ่ง"

```python
def say_hello():
    print("=================")
    print("   WELCOME!")
    print("=================")
```

ตอนนี้โค้ด 3 บรรทัดนั้นมีชื่อว่า `say_hello` แล้ว เรียกใช้เมื่อไหร่ก็ได้

```python
say_hello()
say_hello()
say_hello()
```

> เขียนก้อนเดียว เรียกกี่ครั้งก็ได้ — **หลักการเดียวกับ `while` แต่คุมได้ว่าจะทำตอนไหน**

---

## ⚠️ กฎ 3 ข้อของ `def`

| กฎ | ตัวอย่าง |
|-----|----------|
| ต้องมี `:` ท้ายบรรทัด | `def say_hello():` |
| โค้ดข้างในต้องเว้น 4 ช่อง | `    print(...)` |
| ต้อง **นิยามก่อน** ถึงจะเรียกได้ | `def` ไว้บนสุดของไฟล์เสมอ |

```python
say_hello()          # ❌ NameError — ยังไม่มีใครรู้จัก
def say_hello():
    print("hi")
```

## แนวคิด — ฟังก์ชันที่รับค่า (parameter)

```python
def greet(name):
    print("Hello,", name)

greet("Mint")        # Hello, Mint
greet("Beam")        # Hello, Beam
```

`name` คือ **ช่องรับของ** — ส่งอะไรเข้าไป ข้างในก็ใช้ค่านั้น

```text
greet("Mint")
       │
       ▼
def greet(name):        name = "Mint"
    print("Hello,", name)
```

## แนวคิด — รับหลายค่า

```python
def draw_box(width, title):
    line = "=" * width
    print(line)
    print(title)
    print(line)

draw_box(20, "  MENU")
draw_box(30, "     GAME OVER")
```

> เปลี่ยนค่าที่ส่งเข้าไป = ได้ผลต่างกัน โดยไม่ต้องเขียนโค้ดใหม่
