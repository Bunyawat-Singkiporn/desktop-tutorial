# 2) กระดาน 3×3 + วาดด้วยฟังก์ชัน

## เป้าหมาย
สร้างข้อมูลกระดาน แล้ววาดเส้นตารางด้วยฟังก์ชัน

---

## แนวคิด — กระดานคือ list ซ้อน list

```python
board = [
    ["", "", ""],
    ["", "", ""],
    ["", "", ""],
]
```

```text
            คอลัมน์ 0   1   2
   แถว 0        │   │   │
   แถว 1        │   │   │
   แถว 2        │   │   │

board[1][2] = "X"      → แถวที่ 1 คอลัมน์ที่ 2
```

| เขียน | หมายถึง |
|-------|---------|
| `board[0]` | ทั้งแถวบนสุด |
| `board[0][0]` | ช่องซ้ายบน |
| `board[2][2]` | ช่องขวาล่าง |
| `board[r][c]` | แถว `r` คอลัมน์ `c` |

> จำโครงสร้างนี้ได้ไหม? เหมือน `fruits = [[x, y], ...]` ของเดือนที่แล้วเลย
> ต่างแค่คราวนี้เป็นตาราง **สี่เหลี่ยม** 3×3

---

## แนวคิด — แยกการวาดออกเป็นฟังก์ชัน

```python
def draw_grid():
    for i in range(1, 3):
        pygame.draw.line(screen, LINE, (BX + i * CELL, BY), (BX + i * CELL, BY + 3 * CELL), 6)
        pygame.draw.line(screen, LINE, (BX, BY + i * CELL), (BX + 3 * CELL, BY + i * CELL), 6)
```

ในลูปหลักเหลือแค่บรรทัดเดียว

```python
    screen.fill(BG)
    draw_grid()             # ← อ่านแล้วรู้เลยว่าทำอะไร
    pygame.display.flip()
```

> ลูปหลักอ่านเหมือน **สารบัญ** ไม่ใช่กองโค้ด
> อยากแก้เส้นตาราง = เข้าไปแก้ในฟังก์ชันเดียว ไม่ต้องหาในลูป

---

## แนวคิด — ฟังก์ชันวาดเครื่องหมาย

```python
def draw_marks():
    for r in range(3):
        for c in range(3):
            if board[r][c] == "X":
                ...วาด X...
            if board[r][c] == "O":
                ...วาด O...
```

> ลูปซ้อนลูป (เรียนไปแล้วตอนเดือน 1) วน 3 แถว × 3 คอลัมน์ = 9 ช่อง

## 📝 สร้างไฟล์ `xo.py`

ดูโค้ดเต็มใน `003_board.py` — โครงคือ

1. ตั้งค่าหน้าจอ + ค่าคงที่ `CELL`, `BX`, `BY`
2. `board` 3×3
3. `def draw_grid():`
4. `def draw_marks():`
5. ลูปหลักที่เรียกทั้งสองฟังก์ชัน

ลองใส่ค่าทดสอบลงกระดานก่อน เช่น `board[0][0] = "X"` และ `board[1][1] = "O"`
