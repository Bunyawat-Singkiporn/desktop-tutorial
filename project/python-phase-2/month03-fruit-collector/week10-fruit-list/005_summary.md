## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `list` ซ้อน `list` | `fruits = [[x, y], ...]` |
| `for fruit in fruits:` | วนผลไม้ทุกลูก |
| `fruit[0]` / `fruit[1]` | หยิบ x และ y |
| `fruit[1] = fruit[1] + 3` | แก้ค่าใน list จริงๆ |
| `len(fruits)` | นับจำนวนผลไม้ |
| `pygame.key.get_pressed()` | กดค้างแล้วเดินต่อเนื่อง |
| การกันหลุดขอบจอ | `if basket_x < 0: basket_x = 0` |

---

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| ผลไม้นิ่งสนิท | เขียน `y = fruit[1] + 3` แทน `fruit[1] = ...` | ต้องเขียนกลับเข้า list |
| ตะกร้าวิ่งหายออกนอกจอ | ไม่ได้กันขอบ | เพิ่ม `if` กันทั้งสองฝั่ง |
| ตะกร้ากระตุก ต้องกดรัวๆ | ใช้ `KEYDOWN` แทน `get_pressed()` | เปลี่ยนเป็น `get_pressed()` |
| ผลไม้ตกแล้วหายหมด | ลืมย้ายกลับขึ้นบน | เพิ่ม `if fruit[1] > 620:` |
| `IndexError` | ใช้ `fruit[2]` ทั้งที่มีแค่ 2 ช่อง | ตอนนี้ผลไม้เก็บแค่ x กับ y |
