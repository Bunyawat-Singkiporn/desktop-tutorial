# 3) ทำให้ผลไม้หล่นลงมา

## เป้าหมาย
ผลไม้ทุกลูกเลื่อนลงทีละนิดทุกเฟรม ตกพ้นจอแล้ววนกลับขึ้นไปใหม่

---

## แนวคิด — การเคลื่อนที่ = เปลี่ยนตำแหน่งทุกเฟรม

```python
for fruit in fruits:
    fruit[1] = fruit[1] + 3      # y เพิ่มขึ้น = เลื่อนลง
```

```text
เฟรมที่ 1   y = 40
เฟรมที่ 2   y = 43
เฟรมที่ 3   y = 46
...
เฟรมที่ 60  y = 220     ← ผ่านไป 1 วินาที ตกลงมา 180 pixel
```

> ที่ 60 เฟรม/วินาที บวกทีละ 3 = ตกลง 180 pixel ต่อวินาที
> **ยิ่งบวกเยอะ ยิ่งตกเร็ว** นี่คือวิธีคุมความยากของเกม

---

## ⚠️ จุดที่ต้องระวังมาก

```python
for fruit in fruits:
    y = fruit[1]
    y = y + 3          # ❌ เปลี่ยนแค่ตัวแปร y ไม่ได้เปลี่ยนใน list
```

```python
for fruit in fruits:
    fruit[1] = fruit[1] + 3    # ✅ เปลี่ยนค่าใน list จริงๆ
```

> ต้องเขียนกลับเข้า `fruit[1]` เสมอ ไม่งั้นผลไม้จะนิ่งสนิท
> เป็นบั๊กที่หาไม่เจอง่ายๆ เพราะโปรแกรมไม่ error เลย

---

## แนวคิด — วนกลับขึ้นไปใหม่

ผลไม้ตกพ้นจอแล้วต้องไม่หายไปเฉยๆ ให้ย้ายกลับไปเริ่มใหม่ด้านบน

```python
    if fruit[1] > 620:          # พ้นขอบล่าง (จอสูง 600)
        fruit[1] = -20          # ย้ายไปเหนือจอ
```

```text
        ┌─────────────┐
 y = -20│   ← เกิดใหม่ตรงนี้
        │             │
        │      ●      │
        │             │
        └─────────────┘
 y = 620    ← ตกถึงตรงนี้แล้วย้ายกลับขึ้นไป
```

> เทคนิคนี้เรียกว่า **recycle** — ใช้ผลไม้ลูกเดิมวนไปเรื่อยๆ
> ดีกว่าสร้างลูกใหม่ตลอดเวลา เพราะเกมไม่หน่วง

    for fruit in fruits:
