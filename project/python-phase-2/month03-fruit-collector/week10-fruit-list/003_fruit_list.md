# 2) list ของผลไม้

## เป้าหมาย
เก็บผลไม้หลายลูกไว้ใน list เดียว แล้ววาดทุกลูกด้วย `for`

---

## แนวคิด — ผลไม้ 1 ลูกเก็บ 2 ค่า

ผลไม้ลูกหนึ่งต้องรู้ว่าอยู่ตรงไหน = ต้องเก็บ `x` กับ `y`

```python
fruit = [120, 40]     # x = 120, y = 40
```

หลายลูก = เอา list มาใส่ list อีกชั้น

```python
fruits = [
    [120, 40],
    [300, 150],
    [520, 90],
    [680, 220],
]
```

| เขียน | ได้ |
|-------|-----|
| `fruits[0]` | `[120, 40]` ผลไม้ลูกแรกทั้งลูก |
| `fruits[0][0]` | `120` ← ค่า x |
| `fruits[0][1]` | `40` ← ค่า y |
| `len(fruits)` | `4` มีผลไม้ 4 ลูก |

---

## แนวคิด — วาดทุกลูกด้วย `for`

```python
for fruit in fruits:
    x = fruit[0]
    y = fruit[1]
    pygame.draw.circle(screen, (230, 70, 70), (x, y), 16)
```

```text
รอบที่ 1: fruit = [120, 40]   → วาดวงกลมที่ (120, 40)
รอบที่ 2: fruit = [300, 150]  → วาดวงกลมที่ (300, 150)
รอบที่ 3: fruit = [520, 90]   → วาดวงกลมที่ (520, 90)
รอบที่ 4: fruit = [680, 220]  → วาดวงกลมที่ (680, 220)
```

> เขียนโค้ดวาด **ครั้งเดียว** แต่ได้ผลไม้กี่ลูกก็ได้
> เพิ่มผลไม้ = เพิ่มใน list เท่านั้น ไม่ต้องแตะโค้ดวาดเลย 🎯

---
