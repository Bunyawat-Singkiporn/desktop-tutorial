## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `for ch in word:` | วนดูตัวอักษรทีละตัว |
| `letter in word` | เช็กว่ามีในคำไหม |
| `letter not in guessed` | กันเดาซ้ำ |
| `guessed.append(letter)` | เพิ่มเข้า list |
| `" ".join(guessed)` | list → ข้อความ |
| `shown += ch` | ต่อข้อความ |
| `pygame.key.name(event.key)` | ปุ่ม → ตัวอักษร |
| `.upper()` | เป็นตัวพิมพ์ใหญ่ |
| `len(letter) == 1` | กรองปุ่มที่ไม่ใช่ตัวอักษร |
| "สมมติจริงก่อน" | เช็กชนะด้วย `win = True` แล้วหาข้อขัดแย้ง |

---

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| กด Space แล้วเสียชีวิต | ไม่ได้กรองปุ่ม | เช็ก `len(letter) == 1` |
| เดาถูกแต่ยังเสียชีวิต | เช็ก `letter not in guessed` ผิดที่ | หักชีวิตเฉพาะเมื่อ `letter not in word` |
| กดตัวเดิมซ้ำเสียชีวิตอีก | ไม่ได้เช็กว่าเดาแล้ว | ครอบด้วย `if letter not in guessed:` |
| ชนะทันทีตั้งแต่เริ่ม | ลืม `win = False` ตอนเจอตัวที่ยังไม่เดา | ตรวจลูปเช็กชนะ |
| ตัวเล็ก-ใหญ่ไม่ตรงกัน | คำลับเป็นตัวใหญ่ แต่ปุ่มให้ตัวเล็ก | ใช้ `.upper()` |
