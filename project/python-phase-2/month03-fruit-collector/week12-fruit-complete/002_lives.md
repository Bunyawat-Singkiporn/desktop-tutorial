# 1) ระบบชีวิต

## เป้าหมาย
ปล่อยผลไม้ดีตกพื้น = เสียชีวิต 1 ดวง ชีวิตหมด = จบเกม

---

## แนวคิด — แยก "พลาด" ออกเป็น 2 กรณี

Week 11 ผลไม้ตกพื้นแล้วเกิดใหม่เฉยๆ ไม่มีบทลงโทษ → เล่นแบบไม่ต้องขยับก็ได้ 😴

ตอนนี้ต้องแยกว่าของที่ตกพื้นคืออะไร

```python
if missed:
    if fruit[3] == 3:
        pass                 # ระเบิดตกพื้น = ดีแล้ว ไม่เสียอะไร
    else:
        lives = lives - 1    # ผลไม้ดีตกพื้น = เสียชีวิต
```

| ของที่ตกพื้น | ผลที่เกิด |
|--------------|-----------|
| 🍎🍊🍉 ผลไม้ | เสียชีวิต 1 ดวง |
| 💣 ระเบิด | ไม่เป็นไร (ควรปล่อยให้ตกอยู่แล้ว) |

> กติกานี้ทำให้เกม **มีการตัดสินใจ** — จะวิ่งไปรับผลไม้ไกลๆ หรือหลบระเบิดที่ใกล้กว่า? 🤔

## แนวคิด — วาดชีวิตเป็นหัวใจ

```python
for i in range(3):
    if i < lives:
        color = (230, 70, 90)      # ♥ เต็ม
    else:
        color = (70, 80, 95)       # ♡ หมดแล้ว
    pygame.draw.circle(screen, color, (640 + i * 34, 30), 11)
```

```text
lives = 3   ♥ ♥ ♥
lives = 2   ♥ ♥ ♡
lives = 0   ♡ ♡ ♡   ← จบเกม
```

> วาดครบ 3 ดวงเสมอ แต่เปลี่ยน **สี** ตามจำนวนที่เหลือ
> ผู้เล่นจะเห็นทันทีว่าเหลือกี่ดวงจากทั้งหมดกี่ดวง

## แนวคิด — หยุดเกมเมื่อชีวิตหมด

```python
if lives <= 0:
    game_over = True
```

แล้วครอบส่วนที่ทำงานของเกมด้วย

```python
if not game_over:
    ...ขยับตะกร้า...
    ...ผลไม้ตก...
```

> ถ้าไม่ครอบ ผลไม้จะยังตกต่อและชีวิตจะติดลบเรื่อยๆ
