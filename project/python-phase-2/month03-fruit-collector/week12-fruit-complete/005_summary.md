## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| กดเริ่มแล้วหมดเวลาทันที | ลืม `start_time = get_ticks()` ตอนรีเซ็ต | เพิ่มในบล็อกเริ่มเกม |
| เริ่มรอบใหม่แล้วแพ้เลย | ลืม `lives = MAX_LIVES` | ไล่รีเซ็ตให้ครบทุกตัวแปร |
| ผลไม้ค้างกลางจอตอนเริ่มใหม่ | ไม่ได้สร้าง `fruits` ใหม่ | `fruits = []` แล้ว append ใหม่ |
| ชีวิตติดลบ | ไม่ได้หยุด logic ตอนจบเกม | เช็ก `if state == "playing":` ครอบไว้ |
| เวลาเดินต่อในจอจบเกม | คำนวณเวลานอกเงื่อนไข state | ย้ายเข้าไปใน `if state == "playing":` |
| สถิติสูงสุดหาย | เขียน `best = 0` ในบล็อกรีเซ็ต | ต้องอยู่นอกสุด ไม่รีเซ็ตเด็ดขาด |
