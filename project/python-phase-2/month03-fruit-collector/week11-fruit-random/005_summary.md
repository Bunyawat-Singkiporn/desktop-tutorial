## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `random.randint(a, b)` | สุ่มตำแหน่ง / ความเร็ว |
| `random.choice(list)` | สุ่มชนิดของที่ตกลงมา |
| ใส่ซ้ำใน list | ถ่วงน้ำหนักความน่าจะเป็น |
| `fruits.append([...])` | สร้างผลไม้ลูกใหม่ |
| `and` | เช็กการชนพร้อมกัน 2 แกน |
| `or` | เกิดใหม่ทั้งตอนรับได้และตกพื้น |
| ตารางข้อมูล `COLORS` `POINTS` | data-driven — แก้เลขไม่ต้องแก้ logic |
| `POINTS[fruit[3]]` | ใช้ค่าในตัวผลไม้เป็นหมายเลขอ้างอิง |

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| คะแนนพุ่ง 60 แต้ม/วินาที | รับได้แล้วไม่ย้ายผลไม้ออก | ต้องเกิดใหม่ทันทีที่รับได้ |
| รับไม่ได้เลยสักลูก | เช็กแค่แกนเดียว | ต้องเช็กทั้ง x และ y ด้วย `and` |
| ผลไม้ตกลงมาพร้อมกันเป็นแถว | สุ่ม y ช่วงแคบไป | สุ่มช่วงกว้าง เช่น `-400` ถึง `-20` |
| `IndexError: list index out of range` | ลืมเพิ่มช่องที่ 4 ตอนเกิดใหม่ | ทุกจุดที่สร้างผลไม้ต้องมีครบ 4 ค่า |
| เจอระเบิดบ่อยเกินไป | สุ่ม 0-3 เท่ากันหมด | ใช้ `random.choice` กับ list ที่ใส่ซ้ำ |
