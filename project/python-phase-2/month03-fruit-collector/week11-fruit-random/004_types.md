# 3) ผลไม้หลายชนิด + ระเบิด

## เป้าหมาย
ของที่ตกลงมามี 4 แบบ คะแนนไม่เท่ากัน และมีระเบิดที่ต้องหลบ

---

## แนวคิด — เพิ่มช่องที่ 4 เก็บ "ชนิด"

```python
fruit = [x, y, speed, kind]
#        0  1    2     3
```

`kind` เป็นเลข 0-3 ใช้เป็น **หมายเลขอ้างอิง** ไปยังตารางข้อมูล

```python
#              0 แอปเปิล   1 ส้ม        2 แตงโม      3 ระเบิด
COLORS  = [(230, 70, 70), (240, 150, 40), (80, 190, 90), (60, 60, 70)]
POINTS  = [1,             2,              3,            -5]
LABELS  = ["+1",          "+2",           "+3",         "BOMB"]
```

```python
kind = fruit[3]
pygame.draw.circle(screen, COLORS[kind], (fruit[0], fruit[1]), 16)
score = score + POINTS[kind]
```

| ผลไม้ | kind | สี | คะแนน |
|-------|------|-----|-------|
| 🍎 แอปเปิล | 0 | แดง | +1 |
| 🍊 ส้ม | 1 | ส้ม | +2 |
| 🍉 แตงโม | 2 | เขียว | +3 |
| 💣 ระเบิด | 3 | ดำ | **-5** |

> วิธีนี้เรียกว่า **data-driven** — เปลี่ยนคะแนนแค่แก้เลขในตาราง ไม่ต้องแตะ logic เลย
> (เดือน 5 จะได้เรียนแบบเต็มรูปแบบ)

---

## แนวคิด — สุ่มชนิดแบบถ่วงน้ำหนัก

ถ้าสุ่ม 0-3 เท่ากันหมด จะเจอระเบิด 25% ซึ่งเยอะไป

```python
kind = random.choice([0, 0, 0, 1, 1, 2, 3])
```

```text
มี 7 ตัวเลือก  →  แอปเปิล 3/7 ≈ 43%
                  ส้ม     2/7 ≈ 29%
                  แตงโม   1/7 ≈ 14%
                  ระเบิด  1/7 ≈ 14%
```

> ใส่ซ้ำหลายตัว = โอกาสออกเยอะขึ้น — เทคนิคเดียวกับระบบกาชาในเกมจริง 🎰

---

## แนวคิด — กันคะแนนติดลบ

```python
if score < 0:
    score = 0
```

> โดนระเบิดจนคะแนนติดลบแล้วเด็กจะถอดใจ — เกมที่ดีต้องให้โอกาสกลับตัวเสมอ

---

## 📝 แก้ `fruit.py`

1. เพิ่มตาราง `COLORS` `POINTS` `LABELS` ไว้บนสุด
2. ตอนสร้าง/เกิดใหม่ ให้เพิ่มช่องที่ 4: `random.choice([0, 0, 0, 1, 1, 2, 3])`
3. ตอนรับได้: `score = score + POINTS[fruit[3]]` แล้วกันคะแนนติดลบ
4. ตอนวาด: ใช้ `COLORS[fruit[3]]` และวาดป้าย `LABELS[fruit[3]]` ใต้ลูก
