## รูปแบบไฟล์ในแต่ละสัปดาห์

```
weekXX-ชื่อบท/
  001_plan.md      → แผนของสัปดาห์ + flowchart + สิ่งที่จะได้
  002_xxx.md       → สไลด์ที่ 1 (เปิดให้เด็กดู → พิมพ์ตาม)
  002_xxx.py       → เช็คพอยต์ (โค้ด ณ จุดนั้น ต้องรันได้)
  003_xxx.md/.py   → สไลด์ถัดไป
  005_summary.md   → สรุป + เช็กลิสต์ + ตารางบั๊กที่เจอบ่อย + ต่อยอด
  game.py          → เฉลยสมบูรณ์ (ครูใช้เช็ก)
```

**วิธีใช้ในคาบ**

1. เปิด `001_plan.md` — บอกเด็กว่าวันนี้จะได้เกมหน้าตาแบบไหน
2. เด็กสร้างไฟล์ของตัวเอง แล้วพิมพ์ตามสไลด์ทีละหน้า
3. ทุกสไลด์จบ = **รันได้** → เห็นความเปลี่ยนแปลงทันที
4. จบคาบเทียบกับ `game.py`

## ความสัมพันธ์กับ `mini-project/`

โฟลเดอร์ `mini-project/pygame/` มีเกมที่เคยสอนไปแล้ว — หลักสูตรนี้เอามา **ทำเป็นเวอร์ชันเต็ม**

| mini-project เดิม | ใน Phase 2 | ต่างกันยังไง |
|-------------------|------------|--------------|
| `guessing-game/` | เดือน 1 | เพิ่มคะแนน เหรียญ และเล่นหลายด่าน |
| `quiz-game/` | เดือน 2 | เพิ่ม timer โบนัสความเร็ว หน้าเริ่ม สถิติ |
| `fruit-collector/` | **เดือน 3** | **ผลไม้หล่นลงมา** (เดิมอยู่นิ่ง) + ระเบิด + ชีวิต + เวลา |
| `flappy-bird/` | **เดือน 5** | เพิ่ม `dict` เก็บ stats + บันทึกสถิติลงไฟล์ |

> เด็กที่เคยเล่นเวอร์ชัน mini-project มาแล้วจะรู้สึกว่า "เกมเดิมแต่โตขึ้น"
> ซึ่งดีกว่าเริ่มเกมใหม่จากศูนย์ เพราะเทียบได้ว่าตัวเองเก่งขึ้นตรงไหน
