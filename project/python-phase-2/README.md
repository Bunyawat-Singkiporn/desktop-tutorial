## รูปแบบการสอน (เหมือน flappy-bird / fruit-collector)

```
weekXX-ชื่อบท/
  001_plan.md      → แผนของสัปดาห์ + flowchart + เป้าหมาย
  002_xxx.md       → สไลด์ที่ 1 (เปิดให้เด็กดู → พิมพ์ตาม)
  002_xxx.py       → เช็คพอยต์ (โค้ด ณ จุดนี้ ต้องรันได้)
  003_xxx.md/.py   → สไลด์ถัดไป
  ...
  00N_summary.md   → สรุป + เช็คลิสต์ + ต่อยอด
  game.py          → เฉลยสมบูรณ์ (ครูใช้เช็ก)
```

**วิธีใช้ในคาบ**
1. เปิด `001_plan.md` — บอกเด็กว่าวันนี้จะได้อะไร
2. เด็กสร้างไฟล์ของตัวเอง แล้วพิมพ์ตามสไลด์ทีละหน้า
3. ทุกสไลด์จบ = **รันได้** → เห็นความเปลี่ยนแปลงทันที
4. จบคาบเทียบกับ `game.py`

## เตรียมเครื่อง

```bash
python --version      # ต้อง 3.10 ขึ้นไป
pip install pygame
```

ทดสอบว่า pygame ใช้ได้:

```bash
python -c "import pygame; print(pygame.version.ver)"
```
