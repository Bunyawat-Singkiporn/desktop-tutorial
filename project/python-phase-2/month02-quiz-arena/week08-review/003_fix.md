## 🐞 บั๊ก 1 — คะแนนไม่ขึ้น

```python
running = True
while running:
    score = 0        # ❌ ล้างคะแนนทุกเฟรม (60 ครั้ง/วินาที!)
```

**แก้:** ลบบรรทัดนี้ทิ้ง (มี `score = 0` อยู่ก่อนลูปแล้ว)

| ประเภทตัวแปร | ต้องอยู่ไหน |
|--------------|-------------|
| สะสมทั้งเกม (`score`, `correct`) | **นอก** ลูป |
| ของข้อปัจจุบัน (`q`, `choices`) | **ใน** ลูป (คำนวณใหม่ทุกเฟรมได้) |

## 🐞 บั๊ก 2 — ตอบถูกกลายเป็นผิด

```python
if picked == questions[index][1]:      # ❌ [1] คือ list ตัวเลือก
```

`picked` เป็นตัวเลข แต่ `questions[index][1]` เป็น list → เทียบยังไงก็ไม่มีวันเท่ากัน

**แก้:**

```python
if picked == questions[index][2]:      # ✅ [2] คือเฉลย
```

> เทคนิคจับบั๊กแบบนี้: `print(questions[index][1])` ดู แล้วจะเห็นว่ามันคือ `['4','5','6','7']`

## 🐞 บั๊ก 3 — IndexError ที่ข้อสุดท้าย

```python
if index > len(questions):       # ❌ 5 > 5 เป็นเท็จ → ไม่จบเกม → หยิบ questions[5] → พัง
```

**แก้:**

```python
if index >= len(questions):      # ✅ 5 >= 5 เป็นจริง → จบเกม
```

```text
คำถาม 5 ข้อ → index ที่ใช้ได้ = 0, 1, 2, 3, 4
index กลายเป็น 5 = เกินแล้ว ต้องจบเกม
```

> บั๊กประเภทนี้เรียกว่า **off-by-one** — พลาดไปหนึ่ง เจอบ่อยที่สุดในโลกโปรแกรมมิ่ง
