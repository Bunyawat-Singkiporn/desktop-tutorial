# 🐞 ใบงาน: ล่าบั๊ก 4 ตัว

## วิธีทำ

1. เปิดไฟล์ `buggy.py`
2. รัน `python buggy.py` แล้วลองเล่น
3. จดอาการ → หาบรรทัดที่ผิด → แก้ → รันใหม่
4. แก้ครบ 4 ตัวถึงจะผ่าน!

---

## อาการที่ต้องเจอ

### 🐞 บั๊ก 1 — คะแนนไม่เคยขึ้นเลย

```
ตอบถูกกี่ข้อ คะแนนก็ยังเป็น 0
```

**คำใบ้:** ตัวแปรที่ต้อง "สะสม" ควรอยู่ตรงไหนของโค้ด?
(นึกถึง Week 4 — "ของที่สะสมต้องอยู่นอกลูป")

---

### 🐞 บั๊ก 2 — ตอบถูกก็ยังบอกว่าผิด

```
เลือกข้อที่เฉลยบอกว่าถูก แต่กรอบก็ยังแดง
```

**คำใบ้:** โครงคำถามคือ `[โจทย์, [ตัวเลือก], เฉลย]`
`q[0]` `q[1]` `q[2]` อันไหนคือเฉลย?

---

### 🐞 บั๊ก 3 — ตอบข้อสุดท้ายแล้วโปรแกรมเด้ง

```
IndexError: list index out of range
```

**คำใบ้:** ถ้ามีคำถาม 5 ข้อ index ที่ใช้ได้คือ 0-4
แล้วเงื่อนไข "หมดคำถามแล้ว" ควรเป็น `>` หรือ `>=` ?

---

### 🐞 บั๊ก 4 — ข้อที่ 2 เวลาเหลือน้อยผิดปกติ

```
ข้อแรกมี 10 วิ แต่ข้อต่อไปเหลือแค่ 2-3 วิ (หรือหมดเวลาทันที)
```

**คำใบ้:** ตอนขึ้นข้อใหม่ ต้องบอกนาฬิกาว่า "เริ่มจับเวลาใหม่นะ"
บรรทัดนั้นหายไปไหน?
