---

## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `pygame.init()` / `quit()` | เปิด-ปิดระบบเกม |
| `set_mode((800,600))` | สร้างหน้าต่าง |
| `while running:` | game loop |
| `event.type == pygame.QUIT` | ปิดหน้าต่าง |
| `event.type == pygame.KEYDOWN` | กดปุ่ม |
| `SysFont("tahoma", 30)` | ฟอนต์ไทย |
| `font.render()` + `screen.blit()` | วาดตัวหนังสือ |
| `pygame.draw.rect()` | วาดกล่อง |
| `list` ซ้อน `list` | คลังคำถาม |
| `questions[index][0]` | หยิบข้อมูลในลิสต์ซ้อน |
| `len()` | นับจำนวนคำถาม |
| `for i in range(4)` | วาดตัวเลือกทั้ง 4 |
| `finished` | state ของเกม |

---

## Input → Process → Output

```
Input             Process                    Output
──────────────────────────────────────────────────────────
กด 1-4       →   picked = เลขที่กด       →
                 index += 1              →  คำถามข้อใหม่
                 index >= len(questions) →  จอ "จบเกม!"
```

---

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| หน้าต่างขาวค้าง / ไม่ตอบสนอง | ไม่มี `pygame.event.get()` ในลูป | ต้องเรียกทุกเฟรม |
| วาดแล้วไม่เห็นอะไร | ลืม `pygame.display.flip()` | เพิ่มท้ายลูป |
| ภาษาไทยเป็น □□□ | ใช้ `SysFont(None, 30)` | เปลี่ยนเป็น `"tahoma"` |
| `IndexError: list index out of range` | index เกินจำนวนคำถาม | เช็ก `if index >= len(questions)` |
| ภาพซ้อนกันเละ | ลืม `screen.fill()` | เติมสีทับก่อนวาดทุกเฟรม |
| กด 1 ครั้งแต่ข้ามหลายข้อ | เช็กปุ่มนอก `KEYDOWN` | ต้องอยู่ใน `if event.type == pygame.KEYDOWN` |
