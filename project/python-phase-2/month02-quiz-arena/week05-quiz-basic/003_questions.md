# 2) คลังคำถาม + แสดงข้อแรก

## เป้าหมาย
เก็บคำถาม 4 ข้อไว้ใน list แล้ววาดข้อแรกขึ้นจอ

---

## แนวคิด — list ซ้อน list

**1 คำถาม** ต้องเก็บ 3 อย่าง: โจทย์ / ตัวเลือก 4 ข้อ / เฉลย

```python
["2 + 3 เท่ากับเท่าไร?", ["4", "5", "6", "7"], 2]
#  ↑ โจทย์                ↑ ตัวเลือก             ↑ เฉลยคือข้อ 2
```

เอาหลายๆ คำถามมาใส่ list อีกชั้น:

```python
questions = [
    ["2 + 3 เท่ากับเท่าไร?",          ["4", "5", "6", "7"],                    2],
    ["สีของท้องฟ้าตอนกลางวัน?",       ["แดง", "ฟ้า", "เขียว", "ดำ"],           2],
    ["Python ใช้คำสั่งใดแสดงผล?",      ["show", "echo", "print", "say"],        3],
    ["1 สัปดาห์มีกี่วัน?",             ["5", "6", "7", "8"],                    3],
]
```

---

## หยิบข้อมูลออกมาใช้

```python
index = 0                          # ตอนนี้อยู่ข้อที่ 0 (ข้อแรก)
q = questions[index]               # หยิบทั้งก้อนของข้อนั้น

text    = q[0]                     # โจทย์
choices = q[1]                     # list ตัวเลือก
answer  = q[2]                     # เฉลย (1-4)
```

| เขียน | ได้อะไร |
|-------|---------|
| `questions[0]` | คำถามข้อแรกทั้งก้อน |
| `questions[0][0]` | โจทย์ของข้อแรก |
| `questions[0][1][0]` | ตัวเลือกที่ 1 ของข้อแรก = `"4"` |
| `len(questions)` | จำนวนคำถามทั้งหมด = 4 |

> **จำไว้** Python นับเริ่มที่ **0** — ข้อแรกคือ index 0

---

## แนวคิด — `for` วาดตัวเลือกทั้ง 4

```python
for i in range(4):                       # i = 0, 1, 2, 3
    y = 220 + i * 70                     # กล่องละ 70 pixel
    pygame.draw.rect(screen, (45, 55, 90), (100, y, 600, 55), border_radius=8)
    line = font_mid.render(f"{i+1})  {choices[i]}", True, "white")
    screen.blit(line, (125, y + 12))
```

```text
i = 0  →  y = 220   →  "1) 4"
i = 1  →  y = 290   →  "2) 5"
i = 2  →  y = 360   →  "3) 6"
i = 3  →  y = 430   →  "4) 7"
```

> เขียนครั้งเดียว ได้ 4 กล่อง — เหมือน `while` ใน Week 4 แต่ `for` เหมาะกับ "รู้จำนวนรอบแน่นอน"
