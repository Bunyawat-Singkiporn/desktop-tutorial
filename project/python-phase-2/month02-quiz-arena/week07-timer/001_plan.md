## ของใหม่วันนี้

| ของใหม่ | ทำอะไร |
|---------|--------|
| `pygame.time.get_ticks()` | ขอเวลาปัจจุบัน (มิลลิวินาที) |
| จำเวลาเริ่มข้อ | `question_start` |
| คำนวณเวลาที่เหลือ | `TIME_LIMIT - ผ่านไปกี่วิ` |
| แถบเวลา | `pygame.draw.rect` ที่ความกว้างเปลี่ยนได้ |
| โบนัสความเร็ว | ตอบไวได้คะแนนเยอะ |

---

## Flowchart

```mermaid
flowchart TD
    A[เริ่มข้อใหม่: question_start = เวลาปัจจุบัน] --> B[ทุกเฟรม: คำนวณเวลาที่เหลือ]
    B --> C{กด 1-4?}
    C -- ใช่ --> D[เช็กคำตอบ + โบนัสเวลา]
    C -- ไม่ --> E{เวลาเหลือ <= 0?}
    E -- ไม่ --> B
    E -- ใช่ --> F[หมดเวลา = ตอบผิด]
    D --> G[โชว์เฉลย]
    F --> G
```
