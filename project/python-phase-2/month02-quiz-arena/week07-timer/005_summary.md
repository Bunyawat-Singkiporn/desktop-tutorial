## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `pygame.time.get_ticks()` | ขอเวลาปัจจุบัน (ms) |
| `(now - start) / 1000` | แปลงเป็นวินาที |
| `TIME_LIMIT - passed` | เวลาที่เหลือ |
| `ratio = time_left / TIME_LIMIT` | สัดส่วนความกว้างแถบ |
| `int(BAR_W * ratio)` | ความกว้างแถบเป็น pixel |
| `int(time_left)` | โบนัสความเร็ว |
| `round(x, 1)` | ปัดทศนิยมโชว์บนจอ |
| `last_picked = 0` | รหัสพิเศษ "หมดเวลา" |

---

## Input → Process → Output

```
Input              Process                          Output
────────────────────────────────────────────────────────────────
(เวลาเดิน)    →   time_left = LIMIT - passed    →  แถบสั้นลง + เปลี่ยนสี
              →   time_left <= 0                →  "หมดเวลา!" + เฉลย
กด 1-4        →   เช็กคำตอบ + int(time_left)    →  "+10 (โบนัสเร็ว +7)"
Space         →   question_start = ตอนนี้        →  ข้อใหม่ เวลาเต็ม
```

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| เด้งข้ามข้อเองตอนอ่านเฉลย | เวลายังเดินตอน `showing_result` | ครอบด้วย `if not showing_result:` |
| ข้อ 2 เวลาเหลือน้อยมาก | ลืมรีเซ็ต `question_start` | เซ็ตใหม่ทุกครั้งที่ขึ้นข้อใหม่ |
| แถบยาวเกินกรอบ | `ratio` ติดลบหรือเกิน 1 | จำกัดค่าด้วย `if ratio < 0: ratio = 0` |
| `TypeError: rect` | ส่งทศนิยมให้ `draw.rect` | ใช้ `int(BAR_W * ratio)` |
| หมดเวลาแล้วขึ้นว่า "ผิด" | เช็ก `last_picked == answer` ก่อน | เช็ก `last_picked == 0` ก่อนเสมอ |
| กด R แล้วหมดเวลาทันที | ลืมรีเซ็ต `question_start` ตอน R | เพิ่มในบล็อกรีเซ็ต |
