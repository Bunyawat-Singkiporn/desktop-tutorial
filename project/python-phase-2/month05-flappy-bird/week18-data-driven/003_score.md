# 2) คะแนนจากการผ่านท่อ

## เป้าหมาย
บินผ่านท่อได้ 1 อัน = 1 คะแนน และต้องไม่นับซ้ำ

---

## แนวคิด — "ผ่านท่อ" คือตอนไหน

ผ่าน = **ท่อเลื่อนไปอยู่ทางซ้ายของนกแล้ว**

```python
if pipe["x"] + PIPE_W < bird["x"]:
    score = score + 1
```

```text
   ท่อยังอยู่ขวา          ท่อผ่านไปแล้ว
        🟡  ┌──┐          ┌──┐  🟡
            │  │          │  │
      ยังไม่นับ              นับ +1
```

---

## ⚠️ ปัญหา: นับรัวทุกเฟรม

เงื่อนไขข้างบนเป็นจริง **ทุกเฟรมหลังจากท่อผ่านไป**
ท่อ 1 อัน = ได้ 100 คะแนน 😱

**ทางแก้** — ใช้คีย์ `scored` ที่เตรียมไว้ตั้งแต่ Week 17

```python
if pipe["scored"] == False and pipe["x"] + PIPE_W < bird["x"]:
    score = score + 1
    pipe["scored"] = True          # ← ปักธงว่านับแล้ว
```

```text
เฟรม 1: scored = False, ท่อผ่าน  →  +1 คะแนน, scored = True
เฟรม 2: scored = True            →  ไม่นับ ✅
เฟรม 3: scored = True            →  ไม่นับ ✅
```

> เทคนิคนี้เรียกว่า **flag** (ธง) — เจอครั้งแรกตอนเดือน 3 (`new_stage`)
> ใช้ทุกครั้งที่อยากให้อะไร "เกิดครั้งเดียว"

---

## แนวคิด — อย่าลืมรีเซ็ตธง

```python
if pipe["x"] < -PIPE_W:
    pipe["x"] = 800
    pipe["gap_y"] = random.randint(150, 420)
    pipe["scored"] = False         # ← สำคัญ!
```

> ท่อวนกลับมาใหม่ = ท่ออันใหม่ ต้องนับคะแนนได้อีก

---

## แนวคิด — แสดงคะแนนให้เด่น

```python
t = font_big.render(str(score), True, "white")
screen.blit(t, (400 - t.get_width() // 2, 60))
```

> Flappy Bird ต้นฉบับโชว์คะแนนตัวใหญ่กลางจอด้านบน
> เพราะผู้เล่นไม่มีเวลาละสายตาไปมองมุมจอ
