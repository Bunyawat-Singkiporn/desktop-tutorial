## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| การชนสี่เหลี่ยม | `near_x and not in_gap` |
| `not` | "ไม่ได้อยู่ในช่องว่าง" |
| flag `scored` | กันนับคะแนนซ้ำทุกเฟรม |
| `LEVELS` (list ของ dict) | ตารางความยาก |
| `current_level()` | เลือกระดับจากคะแนน |
| ค่าที่ดึงจากตาราง | `gap`, `speed` |

## 🧠 ทำไม Data-Driven ถึงสำคัญ

```text
ธรรมดา:  อยากปรับความยาก → แก้โค้ดกลางไฟล์ → เสี่ยงพัง
Data:     อยากปรับความยาก → แก้ตัวเลขในตาราง → ปลอดภัย
```

| ใครได้ประโยชน์ | ยังไง |
|----------------|-------|
| ครู | ปรับให้เหมาะกับเด็กแต่ละห้องได้ทันที |
| เด็ก | ทดลองค่าต่างๆ แล้วเห็นผลทันที ไม่กลัวโค้ดพัง |
| คนทำเกมจริง | ปรับสมดุลเกมโดยไม่ต้องเขียนโค้ดใหม่ |

> เดือนหน้าจะได้เห็นพลังจริงของมัน — เมื่อตารางนี้ถูก **เก็บลงไฟล์** ได้ 💾

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| ผ่านท่อได้ 100 คะแนน | ไม่ได้ใช้ flag | เพิ่ม `pipe["scored"]` |
| ท่อวนกลับแล้วไม่ได้คะแนน | ลืมรีเซ็ต `scored = False` | เพิ่มตอน recycle |
| ชนท่อทั้งที่บินผ่านช่องว่าง | `in_gap` คำนวณผิด | ต้องเทียบ `by - r` และ `by + r` |
| ระดับไม่เปลี่ยนเลย | ตาราง `at` เรียงผิด | เรียงจากง่าย (`at` น้อย) ไปยาก |
| ตายทันทีที่เริ่ม | ท่อแรกอยู่ใกล้เกินไป | เริ่มท่อแรกที่ x = 500 ขึ้นไป |
| ยิ่งเล่นยิ่งง่าย | ใน `current_level` ใช้ `break` เร็วไป | ต้องไล่จนจบแล้วเก็บตัวท้ายสุด |
