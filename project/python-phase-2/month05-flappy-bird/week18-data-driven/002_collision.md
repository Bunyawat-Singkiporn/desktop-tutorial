# 1) ชนท่อแล้วตาย

## เป้าหมาย
นกชนท่อหรือชนพื้น = จบเกม

---

## แนวคิด — การชนสี่เหลี่ยม

นกจะชนท่อก็ต่อเมื่อ **ทับกันทั้งแนวนอนและแนวตั้ง**

```text
แนวนอน (x)                      แนวตั้ง (y)
 นกอยู่ในช่วงความกว้างท่อ         นกอยู่นอกช่องว่าง

   ┌──┐                            ┌──┐  ← ท่อนบน
   │  │                            └──┘
  🟡  │   ← ทับแนวนอน              🟡      ← อยู่ในช่องว่าง ปลอดภัย
   │  │                            ┌──┐
   └──┘                            │  │  ← ท่อนล่าง
```

```python
def hit_pipe(pipe):
    bx = bird["x"]
    by = bird["y"]
    r = bird["size"]

    near_x = bx + r > pipe["x"] and bx - r < pipe["x"] + PIPE_W
    in_gap = by - r > pipe["gap_y"] - gap // 2 and by + r < pipe["gap_y"] + gap // 2

    return near_x and not in_gap
```

| ตัวแปร | หมายถึง |
|--------|---------|
| `near_x` | นกอยู่ในช่วงความกว้างท่อ |
| `in_gap` | นกอยู่ในช่องว่างพอดี (ปลอดภัย) |
| `near_x and not in_gap` | อยู่ตรงท่อ แต่ไม่ได้อยู่ในช่องว่าง = **ชน** |

> `not` อ่านว่า "ไม่" — `not in_gap` แปลว่า "ไม่ได้อยู่ในช่องว่าง"
> การใช้ `and` / `not` แบบนี้ทำให้เงื่อนไขอ่านเหมือนภาษาคน 👍

## แนวคิด — ชนพื้นก็ตาย

```python
if bird["y"] + bird["size"] >= 540:
    state = "gameover"
```

> แต่ **ชนเพดานไม่ตาย** แค่เด้งกลับ — นี่คือกติกาของ Flappy Bird ต้นฉบับ
> กติกาเล็กๆ แบบนี้แหละที่ทำให้เกมรู้สึกแฟร์

---

## แนวคิด — วนเช็กท่อทุกอัน

```python
for pipe in pipes:
    if hit_pipe(pipe):
        state = "gameover"
```
