# 2) บันทึกสถิติสูงสุด

## เป้าหมาย
เกมจบแล้วถ้าทำสถิติใหม่ ให้บันทึกลงไฟล์

---

## แนวคิด — ฟังก์ชันบันทึก

```python
SAVE_FILE = "flappy_save.txt"

def save_best():
    with open(SAVE_FILE, "w", encoding="utf-8") as f:
        f.write(str(best))
```

> ใส่ `encoding="utf-8"` ไว้เสมอ — กันปัญหาภาษาไทยเพี้ยนบน Windows 🇹🇭

---

## แนวคิด — เรียกตอนไหน

```python
if state == "playing":
    ...
    if bird ชนอะไรสักอย่าง:
        state = "gameover"
        if score > best:
            best = score
            save_best()          # ← บันทึกเฉพาะตอนทำสถิติใหม่
```

| เขียนตอนไหน | ผลที่ได้ |
|-------------|----------|
| ทุกเฟรม | ❌ เขียนดิสก์ 60 ครั้ง/วินาที เกมกระตุก |
| ตอนจบเกมทุกครั้ง | 🟡 ใช้ได้ แต่เขียนเกินจำเป็น |
| **เฉพาะตอนทำสถิติใหม่** | ✅ ดีที่สุด |

> กฎ: **เขียนไฟล์เท่าที่จำเป็น** เพราะช้ากว่าการใช้ตัวแปรเป็นพันเท่า

---

## แนวคิด — ไฟล์ไปอยู่ไหน

```python
with open("flappy_save.txt", "w") as f:
```

ชื่อไฟล์แบบนี้ = สร้างไว้ใน **โฟลเดอร์ที่รันโปรแกรม**

```text
flappy/
├── game.py
└── flappy_save.txt    ← เกิดขึ้นตรงนี้หลังเล่นจบรอบแรก
```

> ถ้ารันจากโฟลเดอร์อื่น ไฟล์จะไปอยู่โฟลเดอร์นั้นแทน
> เป็นสาเหตุที่เด็กมักงงว่า "สถิติหายไปไหน" 🤔

---

## 📝 แก้ `flappy.py`

1. เพิ่ม `SAVE_FILE = "flappy_save.txt"` และ `best = 0`
2. เพิ่มฟังก์ชัน `save_best()`
3. เรียกตอนทำสถิติใหม่
4. แสดง `best` บนจอ

---

> เล่นให้ได้คะแนนสูงๆ แล้วดูว่ามีไฟล์ `flappy_save.txt` เกิดขึ้นไหม ✅
> เปิดไฟล์ดู ต้องมีตัวเลขอยู่ข้างใน
