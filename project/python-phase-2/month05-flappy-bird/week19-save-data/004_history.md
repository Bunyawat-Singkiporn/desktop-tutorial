# 3) บันทึกประวัติทุกรอบ

## เป้าหมาย
เก็บคะแนนของทุกรอบที่เล่น ไม่ใช่แค่สถิติสูงสุด

---

## แนวคิด — โหมด `"a"` เขียนต่อท้าย

```python
HISTORY_FILE = "flappy_history.txt"

def save_history():
    with open(HISTORY_FILE, "a", encoding="utf-8") as f:
        f.write(str(score) + "\n")
```

```text
โหมด "w"                    โหมด "a"
รอบ 1 เขียน 5   → ไฟล์: 5    รอบ 1 เขียน 5   → ไฟล์: 5
รอบ 2 เขียน 12  → ไฟล์: 12   รอบ 2 เขียน 12  → ไฟล์: 5
                  (5 หายไป!)                          12
```

| โหมด | ใช้กับ |
|------|--------|
| `"w"` | สถิติสูงสุด (มีค่าเดียว ทับได้) |
| `"a"` | ประวัติการเล่น (สะสมไปเรื่อยๆ) |

---

## แนวคิด — เก็บข้อมูลให้มีประโยชน์

เก็บแค่คะแนนก็ได้ แต่เก็บเพิ่มนิดหน่อยจะวิเคราะห์ได้เยอะกว่า

```python
def save_history():
    with open(HISTORY_FILE, "a", encoding="utf-8") as f:
        f.write(str(score) + "," + level["name"] + "\n")
```

ไฟล์จะหน้าตาแบบนี้

```text
5,ปกติ
12,ยาก
3,ง่าย
21,โหด
```

> รูปแบบ "คั่นด้วยจุลภาค" แบบนี้เรียกว่า **CSV**
> เปิดด้วย Excel ได้เลย และโปรแกรมอื่นอ่านต่อได้ 📊
