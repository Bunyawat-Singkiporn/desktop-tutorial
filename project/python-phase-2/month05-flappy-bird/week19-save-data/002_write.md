# 1) เขียนไฟล์ครั้งแรก

## เป้าหมาย
เข้าใจการเขียนไฟล์ ด้วยโปรแกรมเล็กๆ ก่อน

---

## แนวคิด — 3 ขั้นตอนของการเขียนไฟล์

```python
f = open("test.txt", "w")      # 1. เปิดไฟล์
f.write("สวัสดี")               # 2. เขียน
f.close()                      # 3. ปิด
```

> ลืม `close()` = ข้อมูลอาจไม่ถูกเขียนลงดิสก์จริง
> เหมือนเซฟงานแล้วไม่กดปิดโปรแกรม แล้วไฟดับ 💡

---

## แนวคิด — `with` ปิดให้อัตโนมัติ

```python
with open("test.txt", "w") as f:
    f.write("สวัสดี")
# ออกจากบล็อก = ปิดไฟล์ให้เอง ✅
```

| เขียนแบบ | ข้อดี |
|----------|-------|
| `open` + `close` | เห็นขั้นตอนชัดเจน |
| `with open(...)` | ปิดให้อัตโนมัติ **แม้โปรแกรมพังกลางทาง** |

> ใช้ `with` เป็นหลัก — โปรแกรมเมอร์จริงเขียนแบบนี้กันหมด

---

## ⚠️ เขียนได้เฉพาะข้อความ

```python
score = 14
with open("test.txt", "w") as f:
    f.write(score)          # ❌ TypeError!
```

ต้องแปลงเป็นข้อความก่อน

```python
    f.write(str(score))     # ✅
```

> ไฟล์เก็บได้แต่ **ตัวอักษร** เลข 14 ในไฟล์คือตัวอักษร `"1"` กับ `"4"`

---

## แนวคิด — เขียนหลายบรรทัด

```python
with open("test.txt", "w") as f:
    f.write("บรรทัดแรก\n")
    f.write("บรรทัดสอง\n")
```

> `\n` คือ **ขึ้นบรรทัดใหม่** ถ้าไม่ใส่ ทุกอย่างจะต่อกันเป็นบรรทัดเดียว

---

## 📝 สร้างไฟล์ `write_test.py`

```python
name = "Mint"
score = 14

with open("test.txt", "w") as f:
    f.write("ชื่อ: " + name + "\n")
    f.write("คะแนน: " + str(score) + "\n")

print("เขียนไฟล์เสร็จแล้ว")
print("ลองเปิดไฟล์ test.txt ดู")
```

---

> รันดู แล้วเปิดไฟล์ `test.txt` ในโฟลเดอร์เดียวกัน ✅
> ต้องเห็น 2 บรรทัด
> ลองรันใหม่โดยเปลี่ยนคะแนนเป็น 20 — ของเดิมต้องถูกทับ
