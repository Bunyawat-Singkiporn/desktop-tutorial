## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `with open(ไฟล์, "w") as f:` | เขียนทับ — สถิติสูงสุด |
| `with open(ไฟล์, "a") as f:` | เขียนต่อท้าย — ประวัติ |
| `f.write(str(x))` | ต้องแปลงเป็นข้อความก่อน |
| `\n` | ขึ้นบรรทัดใหม่ |
| `encoding="utf-8"` | กันภาษาไทยเพี้ยน |
| บันทึกเท่าที่จำเป็น | ไม่เขียนไฟล์ทุกเฟรม |
| CSV | `12,ยาก` เปิดด้วย Excel ได้ |

## 🧠 RAM กับดิสก์ ต่างกันยังไง

```text
ตัวแปร (RAM)              ไฟล์ (ดิสก์)
เร็วมาก                    ช้ากว่าเป็นพันเท่า
ปิดโปรแกรม = หาย           อยู่ถาวร
ใช้ระหว่างเล่น             ใช้ตอนเซฟ/โหลด
```

> เกมจริงเก็บทุกอย่างใน RAM ระหว่างเล่น แล้วเซฟลงดิสก์เป็นระยะ
> ไม่มีเกมไหนเขียนไฟล์ทุกเฟรม เพราะจะกระตุกจนเล่นไม่ได้

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| `TypeError: write() argument must be str` | เขียนตัวเลขตรงๆ | ใช้ `str(score)` |
| ประวัติมีบรรทัดเดียวเสมอ | ใช้โหมด `"w"` | เปลี่ยนเป็น `"a"` |
| ทุกอย่างต่อกันเป็นบรรทัดเดียว | ลืม `\n` | เติมท้ายทุกครั้งที่เขียน |
| ภาษาไทยเป็นตัวประหลาด | ไม่ได้ใส่ encoding | `encoding="utf-8"` |
| เกมกระตุก | เขียนไฟล์ทุกเฟรม | เขียนเฉพาะตอนจบเกม |
| หาไฟล์ไม่เจอ | รันจากคนละโฟลเดอร์ | ดูว่า terminal อยู่โฟลเดอร์ไหน |

## ⚠️ ข้อควรระวังที่สุด

```python
with open("flappy_save.txt", "w") as f:
```
