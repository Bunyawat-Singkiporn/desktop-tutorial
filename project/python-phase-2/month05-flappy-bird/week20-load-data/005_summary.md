## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| `FileNotFoundError` ตอนเปิดครั้งแรก | ไม่ได้เช็กว่ามีไฟล์ | `if os.path.exists(...)` |
| `ValueError: invalid literal for int()` | ลืม `strip()` | `int(line.strip())` |
| `ValueError` ตอนไฟล์ว่าง | ไฟล์มีแต่ไม่มีข้อมูล | เช็ก `if text != "":` |
| `ZeroDivisionError` | หาเฉลี่ยตอนยังไม่เคยเล่น | เช็ก `if rounds > 0:` |
| สถิติหายทุกครั้งที่เปิด | ลืมเรียก `load_best()` | เรียกก่อนเข้า game loop |
| ประวัติมีบรรทัดเดียว | ใช้โหมด `"w"` แทน `"a"` | เปลี่ยนโหมด |
| ทศนิยมยาวเป็นพรืด | ไม่ได้จัดรูปแบบ | `{average:.1f}` |
