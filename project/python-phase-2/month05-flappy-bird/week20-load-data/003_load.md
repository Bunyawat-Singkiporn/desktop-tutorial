# 2) โหลดสถิติตอนเปิดเกม

## เป้าหมาย
เปิดเกมมาต้องเห็นสถิติเดิมทันที

---

## แนวคิด — ฟังก์ชันโหลด

```python
def load_best():
    if os.path.exists(SAVE_FILE):
        with open(SAVE_FILE, "r", encoding="utf-8") as f:
            text = f.read().strip()
            if text != "":
                return int(text)
    return 0
```

**เช็ก 2 ชั้น** เพราะไฟล์อาจมีปัญหาได้ 2 แบบ

| กรณี | เกิดจาก | ผลถ้าไม่เช็ก |
|------|---------|---------------|
| ไม่มีไฟล์ | เปิดเกมครั้งแรก | `FileNotFoundError` |
| ไฟล์ว่าง | เซฟไม่สำเร็จ / ไฟดับ | `ValueError` |

> เขียนโค้ดที่ **เผื่อกรณีแย่ที่สุดไว้เสมอ** = โค้ดที่ไม่พังใส่ผู้ใช้

---

## แนวคิด — เรียกตอนเปิดโปรแกรม

```python
best = load_best()        # ← บรรทัดเดียว ก่อนเข้า game loop
```

```text
เปิดโปรแกรม
   ↓
load_best()  →  อ่านไฟล์  →  best = 21
   ↓
game loop เริ่มทำงานโดยมีสถิติเดิมอยู่แล้ว ✅
```
