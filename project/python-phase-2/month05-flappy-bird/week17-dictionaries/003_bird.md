# 2) นกกับแรงโน้มถ่วง

## เป้าหมาย
นกตกลงเรื่อยๆ กด Space แล้วกระโดดขึ้น

---

## แนวคิด — นกคือ dict

```python
bird = {
    "x": 150,
    "y": 300,
    "speed": 0,      # ความเร็วแนวดิ่ง (บวก = ลง, ลบ = ขึ้น)
    "size": 18,
}
```

---

## แนวคิด — แรงโน้มถ่วงทำงานยังไง 🍎

แรงโน้มถ่วงไม่ได้ทำให้ y เพิ่ม — มันทำให้ **ความเร็ว** เพิ่ม

```python
GRAVITY = 0.5

bird["speed"] = bird["speed"] + GRAVITY      # ตกเร็วขึ้นเรื่อยๆ
bird["y"] = bird["y"] + bird["speed"]        # แล้วค่อยขยับตามความเร็ว
```

```text
เฟรม   speed    y       สังเกต
  1     0.5    300.5
  2     1.0    301.5    ตกเร็วขึ้น
  3     1.5    303.0
  4     2.0    305.0    ยิ่งนานยิ่งเร็ว
 10     5.0    327.5
```

> ถ้าเขียน `bird["y"] += 3` เฉยๆ นกจะตกด้วยความเร็วคงที่ — **ดูเหมือนลิฟต์ ไม่เหมือนของตก**
> ความรู้สึก "หนัก" ของ Flappy Bird มาจากบรรทัด `speed = speed + GRAVITY` นี่แหละ 🎯

---

## แนวคิด — กระโดด = ตั้งความเร็วเป็นลบ

```python
JUMP = -9

if event.key == pygame.K_SPACE:
    bird["speed"] = JUMP          # ไม่ใช่ลบออก แต่ "ตั้งค่าใหม่"
```

| เขียนแบบ | ผลที่ได้ |
|----------|----------|
| `bird["speed"] = JUMP` | ✅ กระโดดสูงเท่ากันทุกครั้ง |
| `bird["speed"] = bird["speed"] + JUMP` | ❌ กดรัวๆ แล้วพุ่งทะลุจอ |

> เกมจริงใช้แบบแรกเสมอ — เรียกว่า **reset velocity**

---

## แนวคิด — กันนกหลุดขอบบน

```python
if bird["y"] < bird["size"]:
    bird["y"] = bird["size"]
    bird["speed"] = 0
```

> ชนเพดานแล้วความเร็วต้องเป็น 0 ไม่งั้นนกจะ "ติดเพดาน" แล้วค้าง

---

## 📝 สร้างไฟล์ `flappy.py`

ดูโค้ดเต็มใน `003_bird.py` โครงคือ

1. ค่าคงที่ `GRAVITY`, `JUMP`
2. `bird` เป็น dict
3. ในลูป: เพิ่มความเร็ว → ขยับ y → กันขอบ
4. `KEYDOWN` + `K_SPACE` → ตั้งความเร็วกระโดด
5. วาดนกเป็นวงกลมสีเหลือง
