## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `{"key": value}` | `bird` และแต่ละท่อ |
| `d["key"]` | อ่าน/เขียนค่า |
| `d["new"] = x` | เพิ่มคีย์ใหม่ |
| `for key in d:` | วนดูทุกคีย์ |
| `list` ของ `dict` | `pipes` |
| `speed = speed + GRAVITY` | แรงโน้มถ่วง |
| `speed = JUMP` (ตั้งค่า ไม่ใช่บวก) | กระโดดสูงเท่ากันทุกครั้ง |
| recycle | ท่อพ้นจอแล้ววนกลับ |

## 🧠 เลือกใช้ list หรือ dict ยังไง

```text
ของหลายชิ้น แบบเดียวกัน        →  list
   ผลไม้ 8 ลูก, ท่อ 3 อัน, คำถาม 6 ข้อ

ของชิ้นเดียว หลายคุณสมบัติ     →  dict
   นก 1 ตัว (x, y, speed, size)

ของหลายชิ้น แต่ละชิ้นมีหลายคุณสมบัติ  →  list ของ dict  ⭐
   ท่อหลายอัน แต่ละอันมี x, gap_y, scored
```

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| `KeyError: 'y'` | สะกดคีย์ผิด หรือยังไม่มีคีย์นั้น | เช็กชื่อคีย์ให้ตรง |
| นกตกแบบลิฟต์ ไม่มีน้ำหนัก | `bird["y"] += 3` ตรงๆ | ต้องเพิ่มที่ `speed` ก่อน |
| กดรัวแล้วนกพุ่งทะลุจอ | `speed = speed + JUMP` | เปลี่ยนเป็น `speed = JUMP` |
| นกติดเพดาน | ชนขอบบนแล้วไม่ตั้ง `speed = 0` | เพิ่มบรรทัดรีเซ็ตความเร็ว |
| `TypeError` ตอนวาด | `y` เป็นทศนิยม | ใช้ `int(bird["y"])` ตอนวาด |
| ท่อวนกลับแต่ไม่ให้คะแนน | ลืมรีเซ็ต `scored` | เพิ่มตอน recycle |
