# 3) ท่อ — `list` ของ `dict`

## เป้าหมาย
สร้างท่อที่เลื่อนเข้ามาจากขวา และวนกลับเมื่อพ้นจอ

---

## แนวคิด — รวมพลัง list + dict

ท่อมีหลายอัน → ใช้ `list`
ท่อ 1 อันมีหลายคุณสมบัติ → ใช้ `dict`

```python
pipes = [
    {"x": 500, "gap_y": 250, "scored": False},
    {"x": 800, "gap_y": 350, "scored": False},
]
```

```text
pipes[0]["x"]        → 500
pipes[1]["gap_y"]    → 350
```

| คีย์ | หมายถึง |
|------|---------|
| `x` | ตำแหน่งแนวนอนของท่อ |
| `gap_y` | จุดกึ่งกลางของช่องว่าง |
| `scored` | ท่อนี้นับคะแนนไปหรือยัง |

> โครงสร้าง **list ของ dict** คือรูปแบบที่ใช้เยอะที่สุดในเกมจริง
> เก็บศัตรู เก็บไอเทม เก็บกระสุน — ใช้แบบนี้หมด 🎯

---

## แนวคิด — วาดท่อ 2 ท่อนจาก dict เดียว

ท่อ 1 อัน = ท่อนบน + ท่อนล่าง โดยเว้นช่องว่างตรงกลาง

```python
GAP = 160
PIPE_W = 70

for pipe in pipes:
    top_h = pipe["gap_y"] - GAP // 2
    bottom_y = pipe["gap_y"] + GAP // 2
    pygame.draw.rect(screen, GREEN, (pipe["x"], 0, PIPE_W, top_h))
    pygame.draw.rect(screen, GREEN, (pipe["x"], bottom_y, PIPE_W, 600 - bottom_y))
```

```text
        ┌────┐   ← ท่อนบน สูง = gap_y - GAP/2
        │    │
        └────┘
                 ← ช่องว่าง GAP
        ┌────┐
        │    │   ← ท่อนล่าง เริ่มที่ gap_y + GAP/2
        └────┘
```

---

## แนวคิด — ท่อเลื่อนและวนกลับ

```python
import random

SPEED = 3

for pipe in pipes:
    pipe["x"] = pipe["x"] - SPEED
    if pipe["x"] < -PIPE_W:
        pipe["x"] = 800
        pipe["gap_y"] = random.randint(150, 450)
        pipe["scored"] = False
```

> เทคนิค **recycle** เดียวกับผลไม้ในเดือน 3 — แค่เปลี่ยนจากตกลงล่างเป็นวิ่งไปซ้าย ♻️
> อย่าลืมรีเซ็ต `scored` ไม่งั้นท่อที่วนกลับมาจะไม่ให้คะแนนอีก
