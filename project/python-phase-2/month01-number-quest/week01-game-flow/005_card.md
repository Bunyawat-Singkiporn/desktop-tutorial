## เป้าหมาย
แสดงผลสรุปสวยๆ = จบ 1 รอบของ Input → Process → Output

---

## แนวคิด — จัดหน้าจอด้วย print

```python
print("-" * 30)
print(f"  ฮีโร่: {name}")
print(f"  อาชีพ: {job_name}")
print("-" * 30)
```

| เทคนิค | ตัวอย่าง | ได้อะไร |
|--------|----------|---------|
| เส้นคั่น | `print("-" * 30)` | `------------------------------` |
| แทรกตัวแปร | `f"HP: {hp}"` | `HP: 100` |
| เว้นบรรทัด | `print()` | บรรทัดว่าง |
