## Concepts ที่ใช้ไป

| Concept | ใช้ทำอะไร |
|---------|-----------|
| `print()` | Output — ให้เกมพูด |
| `input()` | Input — รับจากผู้เล่น |
| `int()` | แปลงข้อความเป็นตัวเลข |
| ตัวแปร | กล่องเก็บ `name`, `hp`, `attack` |
| `if / elif / else` | Process — ตัดสินใจ |
| `f"{...}"` | แทรกตัวแปรกลางข้อความ |
| indent 4 ช่อง | บอกว่าโค้ดอยู่ใน `if` |

---

## Input → Process → Output ของเกมนี้

```
Input                Process                   Output
──────────────────────────────────────────────────────────
พิมพ์ชื่อ        →   เก็บใน name           →  "ยินดีต้อนรับ Mint!"
พิมพ์ 1-3       →   int() แปลงเป็นเลข      →
                    if เลือกค่า attack/hp  →  การ์ดฮีโร่
```

---

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| `ValueError: invalid literal for int()` | ผู้เล่นพิมพ์ตัวอักษรแทนเลข | พิมพ์เลข 1-3 เท่านั้น |
| `IndentationError` | ลืมเว้น 4 ช่องใต้ `if` | กด Tab / Space 4 ครั้ง |
| `NameError: job_name` | สะกดชื่อตัวแปรไม่ตรงกัน | เช็กตัวพิมพ์เล็ก-ใหญ่ |
| `if job = 1` พัง | ใช้ `=` แทน `==` | เปลี่ยนเป็น `==` |
