## แนวคิด — `print()`

`print()` = สั่งให้คอมพิวเตอร์ **พูดออกมาทางหน้าจอ**

```python
print("สวัสดี")        # พูดข้อความ
print(10 + 5)          # พูดผลลัพธ์ = 15
print()                # เว้นบรรทัดว่าง
```

| โค้ด | ผลบนหน้าจอ |
|------|-------------|
| `print("Hi")` | `Hi` |
| `print("A", "B")` | `A B` |
| `print("=" * 10)` | `==========` |

> `"=" * 10` คือเอา `=` มาต่อกัน 10 ตัว — ใช้ทำเส้นคั่นสวยๆ
