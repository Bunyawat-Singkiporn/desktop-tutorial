# 2) INPUT — ให้ผู้เล่นตอบ

## เป้าหมาย
ถามชื่อฮีโร่ แล้วจำไว้

---

## แนวคิด — `input()`

`input()` = **หยุดรอ** ให้ผู้เล่นพิมพ์ แล้วเก็บสิ่งที่พิมพ์ไว้ในตัวแปร

```python
name = input("ชื่อฮีโร่ของเธอ: ")
#  ↑        ↑
#  กล่องเก็บ  ข้อความที่ถาม
```

```text
เครื่องพิมพ์ว่า : ชื่อฮีโร่ของเธอ:
ผู้เล่นพิมพ์    : Mint
ผลลัพธ์         : name เก็บคำว่า "Mint"
```

---

## เอาตัวแปรมาใช้ใน print

```python
print("สวัสดี", name)          # สวัสดี Mint
print(f"สวัสดี {name}!")       # สวัสดี Mint!
```

> `f"..."` เรียกว่า **f-string** — เขียน `{ชื่อตัวแปร}` แทรกกลางข้อความได้เลย

---

## 📝 เพิ่มใน `hero.py` (ต่อท้ายบรรทัดเดิม)

```python
name = input("ชื่อฮีโร่ของเธอ: ")
print(f"ยินดีต้อนรับ {name}!")
```

---

> รันดู — โปรแกรมจะ **หยุดรอ** ให้เราพิมพ์ชื่อ แล้วทักกลับ ✅
