# Week 2 — Guess the Number 🔢

## วันนี้จะสร้างอะไร

**เกมทายเลข** — คอมพิวเตอร์แอบคิดเลข 1-10 เรามี **3 ครั้ง** ในการทาย

```
=== GUESS THE NUMBER ===
ฉันแอบคิดเลข 1 ถึง 10 ไว้...
เธอมี 3 ครั้ง!

ครั้งที่ 1 - ทายเลข: 5
มากไป! ลองต่ำกว่านี้

ครั้งที่ 2 - ทายเลข: 3
น้อยไป! ลองสูงกว่านี้

ครั้งที่ 3 - ทายเลข: 4
ถูกต้อง! เก่งมาก
```

## ของใหม่วันนี้

| ของใหม่ | ทำอะไร |
|---------|--------|
| `import random` | เรียกใช้ความสามารถ "สุ่ม" |

## Flowchart

```mermaid
flowchart TD
    A[สุ่มเลขลับ 1-10] --> B[ผู้เล่นทาย]
    B --> C{ทาย == เลขลับ?}
    C -- ใช่ --> D[ถูกต้อง! จบเกม]
    C -- ไม่ --> E{ทาย > เลขลับ?}
    E -- ใช่ --> F[มากไป]
    E -- ไม่ --> G[น้อยไป]
    F --> B
    G --> B
```
