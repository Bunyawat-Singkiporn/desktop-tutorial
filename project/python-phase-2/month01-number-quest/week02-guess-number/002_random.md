## แนวคิด — `random`

Python มี "กล่องเครื่องมือ" ให้ยืมใช้ เรียกว่า **module**
กล่องชื่อ `random` มีเครื่องมือสุ่ม

```python
import random                    # ยืมกล่องมาก่อน (บรรทัดบนสุดของไฟล์)

secret = random.randint(1, 10)   # สุ่มเลข 1 ถึง 10 (รวม 1 และ 10)
```

| โค้ด | ผลลัพธ์ |
|------|---------|
| `random.randint(1, 6)` | เลข 1-6 เหมือนทอยลูกเต๋า 🎲 |
| `random.randint(1, 100)` | เลข 1-100 |
| `random.choice(["ก", "ข"])` | สุ่มเลือก 1 ตัวจากลิสต์ |

> รันใหม่ทุกครั้ง = ได้เลขใหม่ทุกครั้ง นี่แหละที่ทำให้เกม **ไม่น่าเบื่อ**

## 📝 สร้างไฟล์ `guess.py`

```python
import random

print("=== GUESS THE NUMBER ===")
print("ฉันแอบคิดเลข 1 ถึง 10 ไว้...")

secret = random.randint(1, 10)

print("(แอบดู เลขลับคือ", secret, ")")   # <-- บรรทัดนี้ไว้ทดสอบ เดี๋ยวลบทิ้ง
```

---

> รัน 3 ครั้ง — เลขที่แอบดูต้องเปลี่ยนไปเรื่อยๆ ✅
> การ print ค่าออกมาดูแบบนี้เรียกว่า **debug** — เทคนิคที่โปรแกรมเมอร์ใช้ทุกวัน
