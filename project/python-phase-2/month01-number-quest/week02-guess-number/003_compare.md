# 2) ทาย 1 ครั้ง + บอกใบ้

## เป้าหมาย
รับเลขที่ผู้เล่นทาย แล้วบอกว่า "มากไป / น้อยไป / ถูกต้อง"

---

## แนวคิด — เปรียบเทียบตัวเลข

| ตัวดำเนินการ | อ่านว่า | ตัวอย่างจริง |
|--------------|---------|--------------|
| `==` | เท่ากับ | `guess == secret` |
| `>` | มากกว่า | `guess > secret` |
| `<` | น้อยกว่า | `guess < secret` |
| `!=` | ไม่เท่ากับ | `guess != secret` |

```python
guess = int(input("ทายเลข: "))

if guess == secret:
    print("ถูกต้อง!")
elif guess > secret:
    print("มากไป! ลองต่ำกว่านี้")
else:
    print("น้อยไป! ลองสูงกว่านี้")
```

```text
secret = 4

guess = 7  →  7 == 4 ? ไม่   →  7 > 4 ? ใช่  →  "มากไป"
guess = 2  →  2 == 4 ? ไม่   →  2 > 4 ? ไม่  →  "น้อยไป"
guess = 4  →  4 == 4 ? ใช่   →  "ถูกต้อง!"
```

> Python เช็ก `if` → `elif` → `else` **จากบนลงล่าง** เจออันแรกที่จริงแล้วหยุดทันที
