## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `import random` | ยืมกล่องเครื่องมือสุ่ม |
| `random.randint(1, 10)` | สุ่มเลขลับ |
| `>` `<` `==` | เปรียบเทียบคำตอบ |
| `True` / `False` | จำว่าชนะหรือยัง |
| `not won` | "ถ้ายังไม่ชนะ" |
| `if` ซ้อน `if` | เช็กหลายชั้น |

---

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| ทายถูกแล้วยังถามต่อ | ลืมเซ็ต `won = True` | เพิ่มบรรทัดใน `if guess == secret` |
| บอกใบ้กลับด้าน | สลับ `>` กับ `<` | `guess > secret` = มากไป |
| ทายถูกแต่บอกว่าผิด | เทียบ `"5" == 5` | ต้อง `int(input(...))` |
| `true` แดง | ต้องเป็น `True` ตัวใหญ่ | แก้ตัวพิมพ์ |
