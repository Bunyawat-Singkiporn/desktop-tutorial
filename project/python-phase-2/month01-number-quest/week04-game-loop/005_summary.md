## Concepts ที่ใช้ไป (ทั้งเดือน 1)

| Concept | สัปดาห์ | ใช้ทำอะไร |
|---------|---------|-----------|
| `print()` / `input()` | 1 | Output / Input |
| `int()` | 1 | แปลงข้อความ → ตัวเลข |
| `if / elif / else` | 1-2 | ตัดสินใจ |
| `random.randint()` | 2 | สุ่มเลขลับ |
| `True` / `False` | 2 | จำสถานะ |
| `score += 10` | 3 | สะสมคะแนน |
| `>=` เรียงลำดับ | 3 | จัดอันดับเหรียญ |
| `while` | 4 | วนซ้ำ |
| `break` | 4 | ออกจากลูป |
| ลูปซ้อนลูป | 4 | ด่าน ครอบ การทาย |

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| พิมพ์ไม่หยุด | ลืม `tries += 1` | เพิ่มบรรทัดนับในลูป |
| คะแนนกลับเป็น 0 ทุกด่าน | `score = 0` อยู่ในลูป | ย้ายออกไปนอกลูป |
| เลขลับเดิมทุกด่าน | `secret = random...` อยู่นอกลูป | ย้ายเข้าไปในลูปนอก |
| ทายถูกแล้วยังถามต่อ | ลืม `break` | เพิ่ม `break` |
| ตอบ `Y` ตัวใหญ่แล้วจบเกม | เทียบ `!= "y"` | ใช้ `answer.lower() != "y"` |

## Input → Process → Output ของ Number Quest

```
Input              Process                        Output
──────────────────────────────────────────────────────────────
ทายเลข        →   เทียบกับ secret             →  มากไป / น้อยไป
                  ถูก → break + คิดคะแนน       →  +คะแนน
y / n         →   playing = True / False      →  ด่านใหม่ / สรุปผล
```
