# 1) รู้จัก `while`

## เป้าหมาย
เข้าใจการวนซ้ำ ก่อนเอาไปใช้ในเกม

---

## แนวคิด — `while`

อ่านว่า **"ตราบใดที่ ... ยังจริง ให้ทำต่อไป"**

```python
count = 1
while count <= 3:
    print("รอบที่", count)
    count += 1
print("จบลูป")
```

ผลลัพธ์:
```
รอบที่ 1
รอบที่ 2
รอบที่ 3
จบลูป
```

---

## ไล่ทีละรอบ 🧠

| รอบ | `count` | `count <= 3` | ทำอะไร |
|-----|---------|--------------|--------|
| 1 | 1 | จริง ✅ | พิมพ์ 1 แล้ว count → 2 |
| 2 | 2 | จริง ✅ | พิมพ์ 2 แล้ว count → 3 |
| 3 | 3 | จริง ✅ | พิมพ์ 3 แล้ว count → 4 |
| - | 4 | เท็จ ❌ | ออกจากลูป |

---

## ⚠️ ลูปอมตะ (infinite loop)

```python
count = 1
while count <= 3:
    print("รอบที่", count)   # ← ลืม count += 1
```

count ไม่เคยเปลี่ยน → เงื่อนไขจริงตลอด → พิมพ์ไม่หยุด 😱

> **กด `Ctrl + C` เพื่อหยุด**
> กฎเหล็ก: ในลูปต้องมีอะไรบางอย่างที่ทำให้เงื่อนไข **เข้าใกล้การเป็นเท็จ**

---

## 📝 สร้างไฟล์ `quest.py` แล้วลอง

count = 1
while count <= 3:
