## ของใหม่วันนี้

| ของใหม่ | ทำอะไร |
|---------|--------|
| `while เงื่อนไข:` | วนซ้ำตราบใดที่เงื่อนไขยังจริง |
| `break` | ออกจากลูปทันที |
| loop ซ้อน loop | ลูปด่าน ครอบ ลูปการทาย |

## Flowchart

```mermaid
flowchart TD
    A[score = 0] --> B[เริ่มด่านใหม่: สุ่มเลขลับ]
    B --> C[ผู้เล่นทาย]
    C --> D{ถูกไหม?}
    D -- ไม่ --> E{เหลือโอกาสไหม?}
    E -- เหลือ --> C
    E -- หมด --> F[แพ้ด่านนี้]
    D -- ใช่ --> G[ชนะ! +คะแนน]
    F --> H{เล่นต่อไหม?}
    G --> H
    H -- y --> B
    H -- n --> I[สรุปผล]
```
