# 🎉 สรุป Week 3

## เช็คลิสต์

- [ ] `score = 0` ตั้งไว้ **ก่อน** ด่านแรก
- [ ] ตอบถูก → `score += 10` และ `correct += 1`
- [ ] คะแนนสะสมข้ามด่าน (ไม่รีเซ็ตกลางทาง)
- [ ] สรุปคะแนนตอนจบ + จำนวนข้อที่ถูก
- [ ] ได้เหรียญตรงตามคะแนน

---

## Concepts ที่ใช้ไป

| Concept | ใช้ที่ไหน |
|---------|-----------|
| `score = 0` | ตั้งค่าเริ่มต้น (initialize) |
| `score += 10` | สะสมคะแนน |
| `correct += 1` | ตัวนับ |
| `>=` | เทียบขั้นเหรียญ |
| ลำดับของ `elif` | ต้องเรียงจากมาก → น้อย |

---

## Input → Process → Output ของเกมนี้

```
Input           Process                    Output
────────────────────────────────────────────────────────
ทายเลข     →   เทียบกับ secret        →  ถูก/ผิด
              score += 10 (ถ้าถูก)     →  คะแนนตอนนี้
              เทียบ score กับขั้น      →  เหรียญ
```

---

## บั๊กที่เจอบ่อย 🐞

| อาการ | สาเหตุ | แก้ยังไง |
|-------|--------|----------|
| คะแนนเป็น 0 ตลอด | เขียน `score = 10` แทน `score += 10` | ใส่ `+=` |
| คะแนนรีเซ็ตทุกด่าน | ตั้ง `score = 0` ซ้ำในแต่ละด่าน | ตั้งครั้งเดียวบนสุด |
| ทุกคนได้ BRONZE | เรียง `elif` ผิดลำดับ | เรียงจากคะแนนสูงลงต่ำ |
| `NameError: correct` | ลืมตั้ง `correct = 0` | เพิ่มบนสุด |
