# 1) ตัวแปรสะสม — `+=`

## เป้าหมาย
เข้าใจว่าคะแนน "บวกเพิ่ม" ทำงานยังไง

---

## แนวคิด — `score += 10`

```python
score = 0        # เริ่มที่ 0
score = score + 10   # เอาค่าเดิม 0 มาบวก 10 → เก็บกลับเข้า score
```

เขียนสั้นได้เป็น

```python
score += 10      # ความหมายเดียวกันเป๊ะ
```

| เขียนสั้น | ความหมาย |
|-----------|----------|
| `score += 10` | `score = score + 10` |
| `score -= 5` | `score = score - 5` |
| `lives -= 1` | เสียชีวิต 1 ดวง |
| `correct += 1` | นับคำตอบถูกเพิ่ม 1 |

---

## ภาพในหัว 🧠

```text
score = 0        [ 0 ]
score += 10      [ 10 ]     ← ค่าเดิม 0 + 10
score += 10      [ 20 ]     ← ค่าเดิม 10 + 10
score -= 5       [ 15 ]
```

> **สำคัญ** ต้อง `score = 0` ก่อนเสมอ ไม่งั้น Python จะบอกว่า
> `NameError: name 'score' is not defined` — เพราะยังไม่มีกล่องให้บวก!

## 📝 สร้างไฟล์ `score.py` แล้วลองเล่น

```python
score = 0
print("เริ่มเกม คะแนน =", score)

score += 10
print("เก็บเหรียญ! คะแนน =", score)

score += 10
print("เก็บเหรียญ! คะแนน =", score)

score -= 5
print("โดนกับดัก! คะแนน =", score)
```

---

> รันดู — ต้องได้ 0 → 10 → 20 → 15 ✅
> ลองเพิ่ม `score += 100` ต่อท้ายดู
